Rapid exam refresher

User-user/item-item CF aggregates neighbours in a sparse interaction matrix; model-based CF learns latent factors. Separate candidates from ranking. Cold start uses onboarding/content/popularity. Evaluate temporal accuracy, coverage and diversity.

Adapted exam practice - Build movie recommendations with cold start. [15]

(a) [7-9 marks]

(a) Demand: show signal flow/fallback. Quickest route: matrix -> neighbours -> weighted prediction -> onboarding. Answer: predict unseen movies from similar users/items, centred if rating scales differ; ask new users for seeds and use content/popularity until history. Trap: recommend an interacted item.

(b) [7-8 marks]

(b) Demand: evaluate beyond clicks. Quickest route: temporal holdout -> NDCG/recall -> coverage/diversity -> online caution. Answer: compare rank metrics, catalogue coverage, novelty and intra-list diversity; monitor popularity feedback bias in online tests. Trap: call clicks unbiased relevance.
