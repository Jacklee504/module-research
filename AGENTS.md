# Collaboration instructions

## Confirming substantial work

Before starting a substantial implementation, first state a concise interpretation of the request and the intended deliverable. If a reasonable misinterpretation could create meaningful rework, consume substantial usage, or materially change the output, wait for the user's confirmation before taking implementation actions.

For study-material work, do not infer that topical coverage is sufficient when the user asks for exam-paper-based material. Confirm whether the work must follow the local papers' wording, mark allocations, multi-part structure, and question families before drafting or rewriting pages.

Do not proceed from an open-ended invitation such as "any questions before beginning?" by silently choosing an interpretation. Either ask the necessary question or state the proposed interpretation and wait for approval.
