# CT413 - Final Year Project

## High-Level View

- Status: Computer Science final-year project module. The current GY350 Year 4 public course page lists CT413 as optional, so registration/programme guidance should be checked for whether it is mandatory for the chosen route.
- Assessment: 100% continuous assessment.
- Credits: 10
- Semester: Semester 1 and Semester 2 in practical workload terms. The public course listing may label it Semester 7, but planning should treat it as running roughly October to March.
- Current module page validity: Valid from 2024 onwards.
- Predictability: Not relevant in the same way as exam modules; this is project/dissertation/presentation based.

## Recommendation

This is the most important CA opportunity in the year: 10 credits and 100% CA. If it is part of the route, it should be treated as a major mark-banking opportunity and planned early.

The project topic should ideally reinforce other modules being taken. Good strategic pairings include:

- CT4101 / CT421: ML or AI project.
- CT4104 / CS402: security, cryptography or secure systems project.
- CT417: software architecture, testing, DevSecOps or quality-focused project.
- CT4108 / CT420: distributed, real-time, systems or performance-focused project.
- CT4100: information retrieval, recommendation or ranking project.

## Official Module Information

Source: https://www.universityofgalway.ie/course-information/module/CT413

- Title: Final Year Project
- Description: Significant individual project from conception through design, development or implementation and delivery.
- Learning outcomes include:
  - Plan and manage a significant individual project.
  - Perform literature review and critical analysis.
  - Design and develop a solution with systematic test and evaluation.
  - Produce an in-depth dissertation/report.
  - Present the work orally and respond to questions.

## Workload Notes

- 100% CA, no written exam.
- Runs across both semesters in practice, roughly October to March.
- Topic choice can be used to reduce overall cognitive load by overlapping with optional modules.
- Because the public GY350 page labels CT413 optional, confirm the exact requirement for the chosen stream/registration route.
