Linked Modules

Topic Clusters

AI / Parallel Computing

CT421, CT4108

Potential overlap around scalable AI, parallel computation, optimisation and large-data processing. CT4108 has no past-paper evidence yet.

Graphs / Networks / Traversal

CS4423, CT421, CT4108

CS4423 gives the strongest graph/network base. CT421 overlaps through BFS/search; CT4108 may overlap conceptually.

Search / Ranking / Recommendation

CT4100, CT421, CS4423

Strong overlap around PageRank, HITS, ranking, query expansion, recommenders and graph-based retrieval.

Systems / Protocols / Performance

CT420, CT4108

Timing, distributed systems, performance, protocols, real-time behaviour and implementation concerns.

Maths-Heavy Theory

CS402, CS4423, MA4102, MA490, MA3491, MA342, MA4344

Repeatable exam styles, but different forms of maths. MA3491 and MA4344 have the strongest CA split; MA490, MA342 and MA4344 are proof-heavy.

Modelling / Simulation / Systems Thinking

CT561, CT420, CT4108

System behaviour over time, performance, simulation and distributed/real-time system concepts.

Quantum / Security / Algorithms

MA4102, MA3491, CS402, CT421

MA3491 is not quantum computing, but finite fields and coding theory are the best maths-side link to MA4102.

Coding Theory / Crypto-Adjacent Maths

MA3491, CS402, MA4102

Finite fields, error correction, cryptographic theory and quantum-information-adjacent ideas. Strong algebra-heavy cluster.

Topology / Geometry / Proof Maths

MA342, MA490, MA3101, MA4344

MA3101 appears to change lecturer frequently and looks unpredictable. MA490 overlaps with MA342 through analysis-style definitions and proof writing.

Algebra / Group Theory / Crypto-Adjacent Maths

MA4344, MA3491, CS402, MA342

MA4344 covers group actions, class equation, Sylow and simple groups. It is a strong 40% CA alternative to MA3491 if group theory suits you.

Security / Crypto / Networks

CT4104, CS402, MA3491, CT420, CT4108

CT4104 is mandatory and has 40% CA, so this cluster matters even if optional security modules are skipped.

Machine Learning / AI / Retrieval

CT4101, CT421, CT4100

CT4101 is mandatory, so CT421 and CT4100 may feel easier if ML/AI topics are already being revised.

Software Architecture / Systems Implementation

CT417, CT4108, CT420, CT413

Useful for project-topic selection. CT413 can reinforce architecture, distributed, real-time or implementation modules.
