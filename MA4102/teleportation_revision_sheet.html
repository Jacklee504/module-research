MA4102 Topic Guide

Quantum Teleportation

Expand the three-qubit state, group by Alice’s two classical outcomes, then attach Bob’s correction.

Purpose

Teleportation is official scope and appears directly in the 2024/25 paper; it tests gates, Bell states and measurement together.Exam use: Qubit order, Bell convention, factor 1/2, four conditional states, corrections and no-signalling role of classical bits are shown.

Question plan

  1. Let the unknown state be |ψ⟩=α|0⟩+β|1⟩.
  2. Start with |ψ⟩⊗|Φ+⟩.
  3. Apply CNOT from the unknown qubit to Alice’s Bell qubit, then H to the unknown qubit.
  4. Group by Alice’s measured bits and state Bob’s Pauli correction.
  5. Question interpretation: For derive teleportation, keep qubit order fixed, rewrite Alice's pair in the Bell basis, and map each two-bit outcome to Bob's correction.

Notation and derivation

After the gates, the state is ½[|00⟩|ψ⟩+|01⟩X|ψ⟩+|10⟩Z|ψ⟩+|11⟩XZ|ψ⟩]. Each two-bit outcome has probability 1/4; Bob restores |ψ⟩ with I, X, Z, or ZX (convention noted).Rapid recall: With input |psi>=alpha|0>+beta|1> and Bell pair |Phi+>, outcomes Phi+,Phi-,Psi+,Psi- leave Bob with I|psi>, Z|psi>, X|psi>, XZ|psi> respectively, up to global phase.Exam workflow: Expand all eight computational-basis terms, regroup by Alice's Bell states, retain the overall factor 1/2, then verify each branch probability and correction.

Worked calculation

For |ψ⟩=|1⟩ and Alice outcome 01, Bob has X|1⟩=|0⟩. Applying X restores |1⟩.

Practice 1 — correction from a Bell-measurement outcome [9 marks]

Prompt. Use the supplied teleportation identity with input |1>; for Alice’s Ψ− outcome, determine Bob’s state and the correction that returns |1>. Question-demand diagnosis. The Bell branch, Pauli order, global phase and classical correction all matter. Fastest route. Substitute |1> into the Ψ− branch and apply the inverse Pauli correction. Topic-specific trap. A global minus changes no physical state, but it is not licence to apply the wrong Pauli order.

Using |Phi+>=(|00>+|11>)/sqrt2 and |Psi+>=(|01>+|10>)/sqrt2, the standard identity is (1/2)[|Phi+>|psi>+|Phi->Z|psi>+|Psi+>X|psi>+|Psi->XZ|psi>]. For input |1>, Alice's outcome Psi- therefore leaves Bob with XZ|1>=-|0>; applying ZX (the inverse up to global phase) returns |1>. Each Bell outcome has probability 1/4.

Graduated exam bridge

1. Give Bob’s correction for Alice’s outcome 10. Check: apply Z (up to the declared ordering convention).

2. Derive the grouped four-branch expression from α|0⟩+β|1⟩. Check: preserve all ½ factors and qubit labels.

Practice 2 — why teleportation cannot signal [8 marks]

Prompt. Explain, using Bob’s reduced state before the two classical bits arrive, why teleportation is not faster-than-light communication. Question-demand diagnosis. This requires an operational reduced-state argument, not merely the word “classical”. Fastest route. Average over the four equally likely Bell outcomes and identify I/2. Topic-specific trap. Entanglement supplies correlation; it does not let Bob choose or read Alice’s outcome locally.

Paper-style synthesis: explain why teleportation does not signal faster than light. Check before Alice's two bits arrive, Bob's averaged reduced state is I/2, independent of alpha,beta; only the classical message selects the correcting Pauli.

Mistakes

  • Claiming Bob knows |ψ⟩ before receiving the two classical bits.
  • Losing the shared Bell-pair normalisation.
  • Using a correction table with a different bit order.
  • Recovery rule: Correction tables depend on Bell-state and bit conventions; derive or state yours instead of memorising unlabeled bits.

Checklist

  • I label Alice/Bob qubits.
