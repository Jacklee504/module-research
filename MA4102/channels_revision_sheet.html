MA4102 Topic Guide

Quantum Channels and Kraus Operators

Apply every Kraus branch, add them, then explicitly check trace preservation.

Purpose

Channels connect the CPTP definition to repeated Kraus and damping/depolarising calculations.Exam use: All Kraus branches, completeness order, resulting matrix, trace and physical parameter range are shown.

Question plan

  1. Write Ε(ρ)=∑kEkρEk †.
  2. Calculate each branch before summing.
  3. Check ∑kEk †Ek=I for trace preservation.
  4. State why the map is completely positive: it has Kraus form.
  5. Question interpretation: For validate, calculate sum K_i^dagger K_i; for apply, evaluate each K_i rho K_i^dagger branch and add; for interpret, separate state change from outcome-conditioned measurement.

Notation and derivation

A quantum channel is CPTP. Trace preservation follows from Tr(∑EkρEk †)=Tr((∑Ek †Ek)ρ)=Tr(ρ).Rapid recall: A channel is completely positive and trace preserving; a Kraus form E(rho)=sum_i K_i rho K_i^dagger is trace preserving iff sum_i K_i^dagger K_i=I.Exam workflow: Keep the input matrix symbolic until each branch is visible, add entries, and audit trace and positivity on the result.

Worked calculation

For dephasing with E0=√(1−p)I and E1=√p Z, Ε(|+⟩⟨+|) has diagonal entries ½ and off-diagonals (1−2p)/2. Also E0 †E0+E1 †E1=I.

Medium/hard paper-style synthesis

For amplitude damping K0=[[1,0],[0,sqrt(1-gamma)]], K1=[[0,sqrt(gamma)],[0,0]], input |1><1| gives K0 rho K0^dagger=(1-gamma)|1><1| and K1 rho K1^dagger=gamma|0><0|. Thus E(rho)=diag(gamma,1-gamma), trace 1. Also K0^dagger K0+K1^dagger K1=I.

Graduated exam bridge

1. Verify trace preservation for the displayed dephasing Kraus pair. Check: scalars square to 1−p and p.

2. Apply amplitude damping Kraus operators to |1⟩⟨1| and interpret the result. Check: output is a mixture, with ground-state probability p.

Hard paper-style synthesis

Paper-style synthesis: apply the channel to rho=[[a,b],[b*,d]]. Check E(rho)=[[a+gamma d,sqrt(1-gamma)b],[sqrt(1-gamma)b*,(1-gamma)d]]; trace a+d is preserved.

Mistakes

  • Omitting the dagger.
  • Checking ∑EkEk † instead of the required order.
  • Calling an arbitrary linear map CPTP.
  • Recovery rule: Trace preservation checks K_i^dagger K_i, not K_i K_i^dagger; the latter tests a different unital property.
