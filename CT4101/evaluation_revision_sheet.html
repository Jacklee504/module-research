Rapid exam refresher

Precision=TP/(TP+FP), recall/TPR=TP/(TP+FN), TNR=TN/(TN+FP), FNR=FN/(FN+TP). ROC plots TPR against FPR over thresholds; AUC summarizes discrimination. MAE/MSE/RMSE target numeric outcomes.

Answer route

  1. Identify calculation, representation, comparison, design or evaluation.
  2. State the equation, algorithm or diagram before application.
  3. Finish with a specific limitation, assumption or trade-off.

Adapted exam practice - Evaluate a binary classifier. [15]

(a) [7-9 marks]

(a) Demand: map outcomes before arithmetic. Quickest route: confusion matrix then denominator-specific formulas. Answer: construct TP/FP/TN/FN and calculate requested rates, noting imbalance. Trap: confuse precision/recall.

(b) [7-8 marks]

(b) Demand: compare thresholds. Quickest route: ROC sweep, top-left, costs. Answer: compare curves/AUC and select an operating point; PR can be clearer under severe imbalance. Trap: call PR an ROC.
