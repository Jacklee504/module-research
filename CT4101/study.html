Lecture to exam route

The 2023/24 paper is the clearest local guide to current question shape. Attempt each prompt before revealing the answer plan, then try the full paper part.

  • Learning tasks

    2023/24 Q1(a) [1+2+1], Q1(b) [9] and Q1(c) [2]: identify features and target, distinguish classification, regression and clustering.

    Reveal answer plan
    • Inputs are independent features; the dependent variable is the target.
    • A discrete target calls for classification; a continuous target calls for regression. Both require labelled examples.
    • Clustering groups unlabelled examples, so remove the target column; provide a suitable algorithm and application for each task.

  • Data preparation

    2023/24 Q1(c) final [4]: explain two feature rescaling methods within the kNN scenario, then place imputation and scaling in a safe train/test workflow.

    Reveal answer plan
    • Large-unit features can dominate distance even when less informative.
    • Min-max scaling maps to a chosen range; z-normalisation centres by the training mean and divides by the training standard deviation.
    • Fit imputation and scaling on training folds only, then apply the learned transforms to validation and test data to prevent leakage.
    Canvas Week 32023/24 paperTopic guide
  • Model evaluation

    2023/24 Q2(a)–(d) [2+2, 6, 5, 10]: explain repeated stratified cross-validation, confusion-matrix measures and ROC axes.

    Reveal answer plan
    • For 5 × 5-fold cross-validation on 500 examples, each repeat has five folds of 100; train on 400 and validate on 100 per run, giving 25 fitted classifiers. Stratification preserves class balance.
    • Fix the positive class before counting TP, FP, TN and FN. Calculate only the measures requested in the part.
    • ROC plots true-positive rate against false-positive rate across thresholds; ideal performance is top left. Tune within validation, not on the held-out test set.
    Canvas Week 42023/24 paperTopic guide
  • Regression error

    2023/24 Q3(c) [4]: calculate MSE, RMSE and MAE from residuals and distinguish a continuous target from logistic classification.

    Reveal answer plan
    • For residuals ei, MAE = Σ|ei|/n; MSE = Σei2/n; RMSE = √MSE.
    • MAE and RMSE have target units; MSE has squared units and weights large errors more heavily.
    • Linear regression predicts a continuous value. Logistic regression models class probability through a sigmoid of a linear score.
    Canvas Week 52023/24 paperQuestion family
  • kNN and trees

    2023/24 Q1(c) [2+6+4] and Q4(a)–(b) [4, 4+6]: compare kNN prediction types, then show how entropy and information gain choose a split.

    Reveal answer plan
    • kNN votes among nearby labels for classification or averages nearby numeric targets for regression; justify distance, scaling and k.
    • For a tree, compute parent entropy and weighted child entropy. Information gain is their difference; choose the largest useful reduction.
    • Check validation performance: small k or deep trees can overfit; large k or shallow trees can underfit.
    Canvas Week 62023/24 paperTree question family
  • Python workflow

    Practical support for reproducible modelling. The local papers emphasise reasoning over syntax. Describe a workflow from loading data to held-out evaluation.

    Reveal answer plan
    • Inspect the data, define target and features, split before learning transformations, and establish a simple baseline.
    • Use a pipeline for preprocessing and estimator fitting; tune on training folds.
    • Evaluate once on held-out data, reporting metric, variation, assumptions and data-handling decisions.
    Canvas Week 2Module overview
  • Neural networks

    2023/24 Q4(c)–(e) [5+2+4]: draw and explain an artificial neuron, compare logistic and ReLU activation, then distinguish binary from one-hot encoding with examples.

    Reveal answer plan
    • Label inputs, weights, bias, summed score and activation. Calculate z = Σwixi + b, then output = f(z).
    • Logistic maps scores into (0, 1); ReLU outputs max(0, z). Compare output range and gradient behaviour.
    • For categorical inputs, show a compact binary code and a one-hot vector, explaining why raw category names cannot be used directly as numeric features.
