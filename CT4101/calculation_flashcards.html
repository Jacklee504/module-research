1. Evaluation And Cross-Validation

FrontBackEvidence
How do you turn yes/no results into a confusion matrix?Choose the positive class. Actual positive/predicted positive = TP; actual negative/predicted positive = FP; actual negative/predicted negative = TN; actual positive/predicted negative = FN.2021/22, 2023/24
What is the misclassification-rate formula?(FP + FN) / (TP + FP + TN + FN).2021/22
What is the precision formula?TP / (TP + FP). Denominator: every predicted positive.2021/22, 2023/24
What is the recall/TPR formula?TP / (TP + FN). Denominator: every actual positive.2021/22, 2023/24
What is the specificity/TNR formula?TN / (TN + FP). Denominator: every actual negative.2021/22, 2023/24
What are the FNR and FPR formulas?FNR = FN / (FN + TP); FPR = FP / (FP + TN).2023/24
For k-fold CV with N cases, how many train/test cases and models are used?Each fold tests N / k cases and trains on N(k - 1) / k cases. Train k models and average the k held-out scores.2021/22, 2023/24
For 5 times 5-fold CV on 500 cases, what are the key counts?Each fold has 500 / 5 = 100 cases. Each run trains on 400 and tests on 100. Total models = 5 x 5 = 25; average the 25 test scores.2023/24

2. Distance, Similarity, And Scaling

FrontBackEvidence
How is Euclidean distance calculated?d(x,y) = sqrt(sum (xi - yi)^2). Square each feature difference, add them, then take the square root.2021/22, 2023/24
How is Hamming distance calculated?Count positions where equal-length discrete representations differ. [red, small, yes] versus [blue, small, no] has distance 2.2021/22
How is z-normalisation calculated?z = (x - mean) / standard deviation. Apply it separately to every numeric feature using training-data statistics.2021/22, 2023/24
How is min-max scaling to [0,1] calculated?x' = (x - min) / (max - min).2023/24

3. Decision Trees And Regression Error

FrontBackEvidence
How is entropy calculated?H(S) = -sum p(c) log2 p(c). A pure set has entropy 0.2021/22, 2023/24
How is information gain calculated?IG(S,A) = H(S) - sum (|Sv| / |S|) H(Sv). Parent entropy minus weighted child entropies.2021/22, 2023/24
What is a residual?The prediction error for one example: actual - predicted.Regression foundation
How is MSE calculated?MSE = (1/n) sum (actual - predicted)^2.2021/22, 2023/24
How is RMSE calculated?RMSE = sqrt(MSE). It is in the same units as the dependent variable.2021/22, 2023/24
How is MAE calculated?MAE = (1/n) sum |actual - predicted|.2023/24

4. Neural-Network Calculations

FrontBackEvidence
How does an artificial neuron calculate its output?Calculate z = sum wi xi + b, then output = f(z).2023/24
How does a threshold neuron calculate its output?Calculate z. Output 1 if z is at least the threshold; otherwise output 0.2021/22
What is the logistic activation equation?sigma(z) = 1 / (1 + e^(-z)).2021/22, 2023/24
What is the ReLU activation equation?ReLU(z) = max(0, z).2021/22, 2023/24

5. Older-Paper Formula Backup

FrontBackEvidence
How can weighted kNN regression be calculated?prediction = sum(wi yi) / sum(wi), using larger weights for closer neighbours, for example wi = 1 / di.2019/20 only
How is cosine similarity calculated?cos(theta) = (x dot y) / (||x|| ||y||). It compares vector direction and is scale-invariant.2019/20 only
What is the batch-gradient-descent update for linear regression?theta_j := theta_j - alpha (1/n) sum (prediction - actual) xj. Compute all updates from the full dataset before applying them.2019/20 only
What is the perceptron weight update?wi := wi + eta (target - prediction) xi; update the bias similarly without xi.2019/20 only
What is the Naive Bayes classification rule?For each class C, compare P(C) product P(xi | C). Choose the largest value.2019/20 only
What is the Q-learning update equation?Q(s,a) := Q(s,a) + alpha [r + gamma max Q(s',a') - Q(s,a)]. Alpha is learning rate; gamma is discount factor.2019/20 only
