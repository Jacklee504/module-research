CT4101 Topic Guide

Neural-Network Basics

Follow one neuron from weighted inputs to an output, then explain how learning improves it.

Exam-use protocol

Before writing, identify the command word: calculate/trace requires an ordered derivation; explain requires a definition, mechanism and assumption; compare/design requires matched criteria, a justified choice and a limitation. The topic-specific recall and worked routes below are the material to adapt—not text to copy blindly.

Part-by-part recall: definitions, assumptions and mechanics

Equation: neuron output a=f(sum wixi+b); loss measures output-target error and backpropagation changes weights by gradients. Activations add non-linearity; one-hot encodes nominal classes. Question cue: show weighted sum, activation, loss role and a learning consequence.

Worked practice 1 — paper-style synthesis (recurring-topic pattern; not a quoted paper prompt) neuron

Question demand: x=(2,1), w=(.5,-1), b=.5; compute pre-activation. Plan/choice: sum then apply named activation. Worked answer: z=2(.5)+1(-1)+.5=.5; ReLU gives .5, sigmoid gives 1/(1+e^-.5). Mark-winning points: activation after sum. Common trap: apply it per input.

Worked practice 2 — synthesis / design

Question demand: Design output/encoding for three-class diagnosis. Plan/choice: one-hot target plus three-output softmax and cross-entropy. Worked answer: represent classes (1,0,0) etc.; softmax probabilities sum to one; train/validate separately and inspect per-class recall. Mark-winning points: target/output consistency. Common trap: ordinally encode nominal classes.

Purpose and relevance

Neural networks compose simple units into flexible functions. CT4101 basics usually concern neuron diagrams, weighted sums, activation functions, simple encoding, and the difference between a model’s output and its learned weights.

What a question really asks — answer plan

For a neuron calculation, write the weighted sum plus bias, apply the named activation, then state the output. For an explanation, identify inputs, weights, bias, activation and output in that order.

Prerequisites, vocabulary and formulas

  • Pre-activation a=Σwᵢxᵢ+b.
  • Step: output 1 when a≥0, otherwise 0. Sigmoid σ(a)=1/(1+e−a).
  • Weight: strength/direction of an input; bias: adjustable offset.
  • One-hot encoding: one active output position per mutually exclusive class.
  • Training adjusts weights to reduce a loss; backpropagation computes useful gradients through layers.

Step-by-step method

  1. Label all inputs and their weights.
  2. Multiply each x by w and add them with b.
  3. Apply the stated activation exactly; do not invent a threshold.
  4. For learning explanations: forward pass → loss → backpropagated gradients → small weight update.

Worked practice 3 — foundational calculation

Question: A step neuron has x₁=1, x₂=0, w₁=.7, w₂=−.2, b=−.5. Find output.

Model answer: a=.7(1)+(−.2)(0)−.5=.2. Since .2≥0, the step activation outputs 1. The bias shifts the boundary; it is not a third input feature.

Question interpretation and independent practice

Prompt 1

One-hot encode classes cat, dog, rabbit when dog is observed. Check: [0,1,0] if that order is declared.

Exam bridge

Draw/explain an artificial neuron and describe at a high level how a network learns from a labelled example. Check: diagram has x, w, Σ+b, activation, output; explain a loss and updates based on error. Avoid claiming a neuron stores training examples.

High-value traps and corrections

Integrated syllabus-based practice - trace a neuron [8 marks]

Scenario. A sigmoid output neuron has inputs x=(2,1), weights w=(.4,-.6) and bias .2. Calculate its pre-activation and output, then state how one labelled error changes the network during learning.

Question-demand diagnosis: distinguish weighted sum from activation and explain back-propagated gradient use.

Fastest route: z=.4(2)-.6(1)+.2=.4, then sigmoid(.4)≈.599.

Worked answer: The output is about .599. Given a target, compute a loss, use the chain rule to obtain the gradient of that loss with respect to output weights, hidden weights and biases, then update parameters opposite the gradient by a learning rate. A positive error does not mean every weight increases: the gradient's sign depends on input, activation derivative and downstream contribution. Validate to detect overfitting.

Topic-specific trap: sigmoid is applied after adding the bias, not separately to every input.

  • Omitting the bias.
  • Applying activation to each input rather than the summed value.
  • Calling one-hot encoding a ranking of categories.

Final answer checklist

  • Did I show Σwᵢxᵢ+b?
  • Did I name the activation?
  • Can I distinguish weights, output and loss?
