Rapid exam refresher

A neuron computes z=sum wi xi+b then threshold/logistic/ReLU. Perceptron update w=w+eta(y-yhat)x. One-hot represents nominal categories in separate bits; binary codes are compact but can create false order.

Adapted exam practice - Explain a binary neural classifier. [15]

(a) [7-9 marks]

(a) Demand: separate score/activation. Quickest route: calculate z then apply function. Answer: threshold is hard decision, logistic smooth, ReLU max(0,z), with saturation/dead-unit limits. Trap: activate inputs before weighting.

(b) [7-8 marks]

(b) Demand: update and encode safely. Quickest route: error times eta times input; one-hot category. Answer: correct weights/bias after error and one-hot nominal values. Trap: ordinal numeric category code.
