Most Repeated Question Families

Frequency counts refer to the three available local papers. A family includes closely related prompts, while the original variations below make clear what you still need to know.

Priority 1 - ML Task Types, Labels, And Suitable Algorithms

Evidence: Archive frequency 3/3; current-format support 2/2. This is the clearest recurring definition family.

Appears as:

  • 2019/20 - Q2(a) - distinguish classification and regression; give an application and algorithm for each.
  • 2021/22 - Q1(a) - distinguish classification, regression, and clustering; give an application and algorithm for each.
  • 2023/24 - Q1(a) - identify dependent and independent variables, identify the supervised task, and explain how the dataset would change for clustering.
  • 2023/24 - Q1(b) - define classification, regression, and clustering; state supervised/unsupervised, an application, and a different algorithm for each.
  • 2023/24 - Q1(c) - decide whether kNN can solve both a chlorinated/non-chlorinated prediction and a percentage prediction.

Consolidated most-asked question:

Given a dataset or real-world problem, identify whether it is classification, regression, or clustering; state whether labels are available; identify the input and output variables; then justify a suitable algorithm and application.

Reusable answer: Classification is supervised learning that predicts a discrete class from labelled examples, such as spam versus non-spam; a decision tree can learn feature-based splits to predict the class. Regression is supervised learning that predicts a continuous numeric value, such as house price; linear regression learns the relationship between inputs and a numeric output. Clustering is unsupervised learning that groups similar unlabelled examples, such as customer segments; k-means repeatedly assigns examples to cluster centres and updates the centres. In a supervised dataset, independent variables are the input features and the dependent variable is the target to predict; clustering removes that target column.

Priority 2 - Evaluation, Confusion Matrices, ROC, Cross-Validation, And Hyperparameters

Evidence: Archive frequency 3/3 for ROC/evaluation; current-format support 2/2 for confusion matrices, cross-validation, ROC, and grid search.

Appears as:

  • 2019/20 - Q4(a)-(b) - construct and interpret learning curves; discuss their use for multi-class classification, regression, and non-probabilistic classifiers.
  • 2019/20 - Q4(c)-(d) - construct and interpret ROC curves; discuss their use for multi-class classification, regression, and non-probabilistic classifiers.
  • 2021/22 - Q2(a) - make a confusion matrix and calculate misclassification rate, TNR, precision, and recall.
  • 2021/22 - Q2(b) - define cross-validation and apply it to regression.
  • 2021/22 - Q2(c) - compare binary classifiers using ROC curves, including labelled axes and ideal performance.
  • 2021/22 - Q2(d) - define a hyperparameter and use grid search to select values.
  • 2023/24 - Q2(a) - define a non-kNN hyperparameter and explain grid search.
  • 2023/24 - Q2(b) - explain 5 times 5-fold stratified cross-validation for 500 examples, including fold sizes, classifiers built, and final performance estimate.
  • 2023/24 - Q2(c) - compare binary classifiers using ROC curves, including labelled axes and ideal performance.
  • 2023/24 - Q2(d) - make a confusion matrix and calculate FNR, TNR, precision, and interpret low FNR/FPR.

Consolidated most-asked question:

Given classifier results or a modelling scenario, build the correct evaluation procedure: confusion matrix and requested measures, cross-validation setup, ROC sketch and interpretation, then explain how hyperparameters should be selected without using test data for tuning.

Reusable answer: First choose the positive class and construct a 2 by 2 confusion matrix. Then use the requested formula: precision = TP / (TP + FP), recall or TPR = TP / (TP + FN), TNR = TN / (TN + FP), FNR = FN / (FN + TP), and FPR = FP / (FP + TN). ROC plots TPR on the y-axis against FPR on the x-axis across thresholds; the ideal point is top-left. Cross-validation repeatedly trains on folds and tests on the held-out fold, then averages the scores; stratification keeps class proportions similar in every fold. A hyperparameter is chosen before fitting, such as tree depth or an SVM C value; grid search evaluates combinations using validation or cross-validation and selects the best configuration.

Do not miss the newer-paper detail: 5 times 5-fold CV on 500 examples gives 100 examples per fold, 400 training examples per run, 25 trained classifiers, and a mean performance estimate across the 25 held-out results.

Priority 3 - Nearest Neighbours, Clustering, Distance Measures, Scaling, And Choosing k

Evidence: Archive frequency 3/3; current-format support 2/2. The exact algorithm comparison changes, but instance similarity is a central recurring block.

Appears as:

  • 2019/20 - Q2(b) - select k for kNN regression and discuss the impact of distance weighting.
  • 2019/20 - Q3(b) - explain a scale-invariant similarity measure using a diagram and equation.
  • 2021/22 - Q3(a) - compare k-means and kNN, including a brief description of each algorithm.
  • 2021/22 - Q3(b) - use an elbow plot to choose k for k-means.
  • 2021/22 - Q3(c) - give and calculate a distance metric for discrete attributes and one for continuous attributes.
  • 2021/22 - Q3(d) - show why kNN often needs normalisation and apply z-normalisation.
  • 2023/24 - Q1(c) - explain kNN for both classification and regression; describe three nearness measures with equations; give two rescaling approaches.
  • 2023/24 - Q3(d)-(e) - compare k-means with hierarchical clustering and illustrate the elbow method.

Consolidated most-asked question:

Explain how a distance-based method uses similarity, decide whether kNN or a clustering method suits the task, choose or justify k, and explain why preprocessing is necessary before distance calculations.

Reusable answer: kNN is a supervised, lazy method: for classification it predicts the majority class among the k nearest labelled examples; for regression it averages or distance-weights their numeric targets. k-means is unsupervised: it assigns unlabelled examples to the nearest centroid and updates centroids until stable. Use a distance suitable for the features, such as Euclidean distance for continuous values and Hamming distance for discrete values. Scale features before distance-based learning so large-unit features do not dominate; z-normalisation uses z = (x - mean) / standard deviation, while min-max scaling maps values into a fixed range. The elbow method selects the point where increasing k gives only small further reductions in within-cluster variation.

Keep the distinctions separate: kNN versus k-means; k-means versus hierarchical clustering; classification versus regression kNN; distance weighting versus unweighted averaging; z-normalisation versus min-max scaling.

Priority 4 - Generalisation, Bias/Variance, Overfitting/Underfitting, Dimensionality, And Learning Curves

Evidence: Archive frequency 3/3; current-format support 2/2. Expect a definition plus a diagnosis, sketch, mitigation, or comparison.

Appears as:

  • 2019/20 - Q2(c) - explain hypothesis language using diagrams, including underfitting and overfitting.
  • 2019/20 - Q3(a) - define the curse of dimensionality and explain a mitigating heuristic with an ML example.
  • 2019/20 - Q4(a)-(b) - construct, compare, and discuss the applicability of learning curves.
  • 2021/22 - Q1(b) - define the curse of dimensionality and give a method to reduce its effect.
  • 2021/22 - Q1(c) - define and sketch overfitting and underfitting in both classification and regression.
  • 2023/24 - Q3(a) - explain bias and variance, relate them to overfitting/underfitting, and diagnose the current model.
  • 2023/24 - Q3(b) - compare under-sampling and over-sampling for imbalanced data; define dimensionality and the curse of dimensionality; suggest solutions.

Consolidated most-asked question:

Diagnose whether a model or dataset is underfitting, overfitting, high-bias, high-variance, high-dimensional, or imbalanced; use an appropriate diagram or learning curve; then propose a justified remedy.

Reusable answer: Underfitting is high bias: the model is too simple and performs poorly on both training and test data. Overfitting is high variance: the model fits training noise well but generalises poorly, so training performance is much better than test performance. A learning curve plots training and validation performance against training-set size and helps diagnose both cases. The curse of dimensionality means the feature space becomes sparse as the number of dimensions grows, making distance and data coverage less meaningful; reduce features, use feature selection or dimensionality reduction, collect more relevant data, or use methods less sensitive to distance. For imbalance, under-sampling removes majority examples while over-sampling duplicates or synthesises minority examples; both require care to avoid losing information or overfitting.

Priority 5 - Decision Trees, Entropy, Information Gain, And Tree Overfitting

Evidence: Archive frequency 3/3; current-format support 2/2. The newest paper makes entropy and information-gain calculation especially important.

Appears as:

  • 2019/20 - Q3(c) - define pure inductive learning and give detailed decision-tree learning pseudocode and a sample tree.
  • 2019/20 - Q3(d) - explain why decision-tree learning can be unstable and give a modification that reduces instability.
  • 2021/22 - Q4(c) - define entropy and information gain.
  • 2021/22 - Q4(d) - give detailed pseudocode for learning a classification decision tree.
  • 2021/22 - Q4(e) - describe a method to combat decision-tree overfitting.
  • 2023/24 - Q4(a) - explain entropy and information gain with equations.
  • 2023/24 - Q4(b) - calculate entropy and information gain for a vowel/consonant split, showing all steps.

Consolidated most-asked question:

Explain or calculate how a classification decision tree chooses a split using entropy and information gain, then describe the induction process and how to control instability or overfitting.

Reusable answer: Entropy measures class impurity: H(S) = -sum p(c) log2 p(c). Information gain is the impurity reduction after a split: IG(S, A) = H(S) - sum (|Sv| / |S|) H(Sv). At each node, a decision-tree learner tests candidate attributes, chooses the split with highest information gain, partitions the examples, and recurses until a stopping condition or pure node is reached. Trees can be unstable because small training-data changes can produce a different early split; pre-pruning, post-pruning, minimum samples per leaf, maximum depth, or ensembles can reduce overfitting and instability.

Priority 6 - Regression Models And Error Metrics

Evidence: Archive frequency 3/3; current-format support 2/2. Error-metric calculations recur in both newer papers.

Appears as:

  • 2019/20 - Q6(a) - advise whether linear, logistic, or polynomial regression suits a tree-growth task; explain task type and data requirements.
  • 2019/20 - Q6(b) - describe batch gradient descent for multiple linear regression, including initialisation, updates, convergence, and empirical error cost.
  • 2021/22 - Q1(d) - give a domain-independent error measure and one in the dependent variable's units; calculate both and compare usefulness.
  • 2023/24 - Q3(c) - compare regression and classification evaluation; calculate and give full names for MSE, RMSE, and MAE.

Consolidated most-asked question:

For a numeric prediction task, choose a suitable regression approach, distinguish it from classification, and calculate or compare regression error measures with their appropriate interpretation.

Reusable answer: Regression predicts a continuous number, while classification predicts a discrete class. MSE is mean squared error, the average of squared residuals; it penalises larger errors strongly but is in squared units. RMSE is the square root of MSE, so it is in the same units as the target. MAE is mean absolute error, the average absolute residual; it is also in target units and is less sensitive to outliers than MSE/RMSE. Linear regression fits a linear relationship; polynomial regression can model curvature but can overfit; logistic regression is used for classification probabilities, not ordinary continuous-value prediction. Batch gradient descent repeatedly updates all weights in the direction that reduces the empirical error until convergence.

Priority 7 - Neural-Network Basics, Activation Functions, And Encoding

Evidence: Archive frequency 3/3 at a broad level; current-format support 2/2 for activation functions and encoding.

Appears as:

  • 2019/20 - Q6(c) - describe an algorithm to build a linear classifier with multiple inputs, including the perceptron learning rule.
  • 2021/22 - Q4(a) - compare threshold, logistic, and ReLU activation functions.
  • 2021/22 - Q4(b) - define one-hot encoding with an example.
  • 2023/24 - Q4(c) - explain a McCulloch-Pitts neuron with labelled diagram and equations.
  • 2023/24 - Q4(d) - compare logistic and ReLU activation functions.
  • 2023/24 - Q4(e) - compare binary and one-hot encoding, with examples and when each is needed.

Consolidated most-asked question:

Explain how a basic artificial neuron or perceptron produces an output, compare activation functions, and show how categorical data or labels should be encoded for a model.

Reusable answer: A neuron computes a weighted sum plus bias, z = sum wi xi + b, then applies an activation function to produce an output. A threshold function produces a hard 0/1 output, logistic maps values smoothly into 0 to 1, and ReLU returns 0 for negative inputs and the input for positive values. One-hot encoding represents a category using one binary position per possible category, for example red = [1,0,0], green = [0,1,0], blue = [0,0,1]; it is suitable for nominal categories because it does not imply an ordering. Binary encoding can use fewer bits but may create artificial relationships between categories. The perceptron learning rule adjusts weights after an error so predictions move toward the correct class.

Distinct Lower-Frequency Questions

These are in the archive but occur only in 2019/20. They are worth knowing as backup material, but should come after the repeated families above.

Lazy Versus Eager Learning

Evidence: Archive frequency 1/3; current-format support 0/2. Appears in 2019/20 - Q1(c).

Explain lazy and eager ML in a changing spam-detection scenario, including strengths, weaknesses, suitability, and an example algorithm from each category.

Reusable answer: Lazy learners store training examples and defer generalisation until prediction time; kNN is an example. They adapt easily to new data but can be slower when predicting and require storage. Eager learners build a general model during training; decision trees are an example. They predict quickly but may need retraining as the data distribution changes. For frequently changing spam, a lazy approach can incorporate new labelled examples easily, though the choice should also consider prediction volume and retraining cost.
