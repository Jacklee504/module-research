Rapid exam refresher

Bayes P(C|x)=P(x|C)P(C)/P(x). A Bayesian network factorises a joint distribution via conditional independence. Naive Bayes assumes features independent given class; use priors, likelihoods and smoothing.

Adapted exam practice - Classify forum messages with Naive Bayes. [15]

(a) [7-9 marks]

(a) Demand: compare posteriors. Quickest route: class prior times conditional word probabilities. Answer: estimate P(class) and P(word|class), multiply likelihoods per class and select largest posterior; use smoothing to avoid zeroes. Trap: multiply marginal P(word).

(b) [7-8 marks]

(b) Demand: explain compact representation. Quickest route: full joint exponential, parent conditionals, assumptions. Answer: store P(Xi|parents Xi), saving values where conditional independence is defensible. Trap: any graph makes variables independent.
