1. Core ML Concepts

FrontBackEvidence
What is supervised learning?Learning from labelled examples where each input has a known target/output.2021/22, 2023/24
What is unsupervised learning?Finding structure or patterns in unlabelled data, without a known target/output.2021/22, 2023/24
What are independent variables?The input features used by the model to make a prediction.2023/24
What is the dependent variable?The target/output the model is trying to predict in supervised learning.2023/24
What is classification?Supervised learning that predicts a discrete class label, such as spam or not spam.2021/22, 2023/24
What is regression?Supervised learning that predicts a continuous numeric value, such as house price.2021/22, 2023/24
What is clustering?Unsupervised learning that groups similar unlabelled examples, such as customer segments.2021/22, 2023/24
How would a supervised dataset change for clustering?Remove the target/output column; the algorithm groups rows using only their input features.2023/24

2. Evaluation And Model Selection

FrontBackEvidence
What is a hyperparameter?A setting chosen before training that controls the learning process or model structure, such as maximum tree depth.2021/22, 2023/24
What is grid search?Trying a defined set of hyperparameter combinations and choosing the one with the best validation or cross-validation score.2021/22, 2023/24
What is cross-validation?Repeatedly training on part of the data and evaluating on a held-out part, then averaging the performance results.2021/22, 2023/24
What is stratification in cross-validation?Keeping approximately the same class proportions in each fold as in the full dataset.2023/24
What do TP, FP, TN, and FN mean?TP: positive correctly predicted positive. FP: negative wrongly predicted positive. TN: negative correctly predicted negative. FN: positive wrongly predicted negative.2021/22, 2023/24
What is a ROC curve?A graph of TPR on the y-axis against FPR on the x-axis across different classification thresholds.2019/20, 2021/22, 2023/24
Where is ideal performance on a ROC curve?At the top-left: TPR = 1 and FPR = 0.2021/22, 2023/24

3. kNN, k-Means, Distance, And Scaling

FrontBackEvidence
What is k-nearest neighbours (kNN)?A supervised algorithm that predicts using the k closest labelled training examples.2019/20, 2021/22, 2023/24
How does kNN perform classification and regression?For classification, it assigns the most common class among the k nearest labelled examples. For regression, it predicts the average numerical output of the k nearest examples.2019/20, 2023/24
What is k-means?An unsupervised clustering algorithm that repeatedly assigns examples to the nearest centroid, recalculates each centroid, and stops when the clusters no longer change significantly.2021/22, 2023/24
What is a centroid?The mean position of all examples currently assigned to a cluster.2021/22, 2023/24
What is the key difference between kNN and k-means?kNN is supervised and predicts from labelled neighbours; k-means is unsupervised and groups unlabelled examples around centroids. In kNN, k is the number of neighbours; in k-means, k is the number of clusters.2021/22, 2023/24
What is hierarchical clustering?A clustering approach that builds a hierarchy of nested clusters, often by repeatedly merging the closest clusters. The result can be shown as a dendrogram.2023/24
Compare k-means and hierarchical clustering.k-means requires k to be chosen in advance and produces a fixed set of clusters. Hierarchical clustering builds a dendrogram, so the number of clusters can be chosen later by cutting the tree.2023/24
What is a distance metric?A numerical way to measure how different two examples are. A smaller distance means the examples are more similar.2021/22, 2023/24
When are Euclidean and Hamming distance suitable?Euclidean distance is suitable for continuous numeric features. Hamming distance is suitable for discrete or categorical representations.2021/22, 2023/24
Why is feature scaling needed for distance-based algorithms?Without scaling, a feature with a larger numerical range can dominate distance calculations, even if it is not more important.2021/22, 2023/24
Compare z-normalisation and min-max scaling.Z-normalisation gives a feature mean 0 and standard deviation 1. Min-max scaling maps values into a fixed range, usually 0 to 1.2021/22, 2023/24
What is the elbow method?Plot the within-cluster variation against different k values and choose the bend where increasing k gives only a small further improvement.2021/22, 2023/24

4. Generalisation, Dimensionality, And Data Problems

FrontBackEvidence
What is underfitting?A model that is too simple to capture the real pattern, so it performs poorly on both training and test data.2019/20, 2021/22, 2023/24
What is overfitting?A model that fits training noise or quirks too closely, so training performance is much better than test performance.2019/20, 2021/22, 2023/24
How can you identify underfitting and overfitting?Underfitting gives poor performance on both training and test data. Overfitting gives much better training performance than test performance.2021/22, 2023/24
What is high bias?A systematic error caused by an overly simple model; it is associated with underfitting.2023/24
What is high variance?A model that is overly sensitive to its training data and may fit noise, so it performs well on training data but poorly on new data.2023/24
What does dimensionality mean?The number of features or attributes used to describe each example in a dataset.2023/24
What is the curse of dimensionality?As the number of features grows, data become sparse and distance/data coverage become less reliable, often needing far more data.2019/20, 2021/22, 2023/24
How can the curse of dimensionality be reduced?Use feature selection or dimensionality reduction, remove irrelevant features, collect more relevant data, or use less distance-sensitive methods.2019/20, 2021/22, 2023/24
What is an imbalanced dataset?One class has far more examples than another, making a model appear accurate while missing the minority class.2023/24
Compare under-sampling and over-sampling.Under-sampling removes majority-class examples and may lose useful information. Over-sampling adds or creates minority-class examples and can cause overfitting if done carelessly.2023/24

5. Decision Trees And Regression Metrics

FrontBackEvidence
What is entropy in a decision tree?A measure of class impurity or uncertainty. A pure node has zero entropy.2021/22, 2023/24
What is information gain?The reduction in entropy after a split. A higher value means the split creates purer groups.2021/22, 2023/24
How does a decision tree choose a split?It tests candidate attributes and chooses the split with the highest information gain, then repeats on each subset.2019/20, 2021/22, 2023/24
When does decision-tree splitting stop?When a node is pure, no useful split remains, or a stopping rule such as maximum depth or minimum samples is reached.2019/20, 2021/22
How can decision-tree overfitting be reduced?Limit depth, require minimum samples per leaf, pre-prune, post-prune, or use an ensemble.2019/20, 2021/22
Compare MSE, RMSE, and MAE.MSE averages squared errors, so it heavily penalises large errors and uses squared units. RMSE is the square root of MSE, so it uses the target's units but still heavily penalises large errors. MAE averages absolute errors, uses target units, and is less sensitive to outliers.2021/22, 2023/24
How are regression and classification evaluated differently?Regression uses numerical error measures such as MSE, RMSE, and MAE. Classification uses confusion-matrix measures such as precision, recall, specificity, and ROC curves.2021/22, 2023/24

6. Neural-Network Basics And Encoding

FrontBackEvidence
What does an artificial neuron do?It combines input values using weights and a bias, then applies an activation function to produce an output.2019/20, 2023/24
What is an activation function?A function applied to a neuron's weighted input that determines its output and lets neural networks model non-linear patterns.2021/22, 2023/24
What is a threshold activation function?It outputs 1 when the weighted input reaches or exceeds a threshold; otherwise it outputs 0.2021/22
What is the logistic activation function?A smooth S-shaped function that maps any input to a value between 0 and 1.2021/22, 2023/24
What is ReLU?Rectified Linear Unit: it outputs 0 for negative inputs and the input itself for positive inputs.2021/22, 2023/24
Compare logistic and ReLU activation functions.Logistic smoothly maps inputs to values between 0 and 1. ReLU outputs 0 for negative inputs and the input itself for positive inputs.2021/22, 2023/24
What is one-hot encoding?Representing each category with its own binary position, for example red = [1,0,0], green = [0,1,0], blue = [0,0,1].2021/22, 2023/24
Compare one-hot and binary encoding.One-hot encoding uses one binary position per category and is suitable for nominal categories because it implies no order. Binary encoding uses fewer columns but can imply artificial relationships between categories. Encoding is needed because ML models require numeric inputs or outputs.2021/22, 2023/24

8. Older-Paper Backup

FrontBackEvidence
What is distance weighting in kNN?Giving closer neighbours more influence than farther neighbours, usually by using a larger weight for a smaller distance.2019/20 only
Why can decision trees be unstable?A small change in training data can change an early split, which can create a very different whole tree.2019/20 only
What does the perceptron learning rule do?After an error, it changes weights and bias so the model's next output moves toward the correct class.2019/20 only
Compare lazy and eager learning.Lazy learners store examples and generalise at prediction time; kNN is an example. Eager learners build a model during training; a decision tree is an example.2019/20 only
What is conditional independence and the Naive Bayes assumption?Two events are conditionally independent given C when knowing one gives no extra information about the other once C is known. Naive Bayes assumes features are conditionally independent given the class label.2019/20 only
What is the Markov property?The current state contains all information needed for the next state or decision; the earlier history adds nothing once the current state is known.2019/20 only
What do Q-learning's learning rate, discount factor, and exploration rate control?Learning rate: how strongly new experience updates Q-values. Discount factor: how much future rewards matter. Exploration rate: how often the agent tries actions instead of its best-known action.2019/20 only
