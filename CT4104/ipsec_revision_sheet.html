CT4104 overview

CT4104 Topic Guide

IPSec

Connect IP-layer protection, security associations and mode choice to the network scenario.

Rapid exam refresher

  • An SA specifies SPI, peer/selectors, algorithms and keys; it is unidirectional.
  • ESP provides confidentiality and commonly integrity/authentication; AH authenticates selected headers but conflicts with NAT and does not encrypt.
  • Transport mode protects payload; tunnel mode wraps original packet and is normal gateway VPN design.
  • IKEv2 authenticates/negotiates SAs; sequence/window gives anti-replay.

Paper evidence and scope

No local CT4104 papers exist: practice is syllabus-based.

Medium practice — 15 marks

Gateways protect 10.0.0.0/24↔10.1.0.0/24. (a) [5] choose mode/protocol. (b) [5] describe packet/SAs. (c) [5] IKE/replay.

Answer for every part

(a)

Answer: ESP tunnel mode protects site-to-site traffic while outer headers route gateways. Trap: choosing host transport mode for two networks.

(b)

Answer: encrypted inner original packet retains private addresses; each direction has separate SA/SPI and selectors. Trap: claiming one bidirectional SA.

(c)

Answer: IKEv2 authenticates peers/derives keys; ESP sequence numbers and replay window reject old packets. Trap: calling encryption replay protection.

Hard practice — 15 marks

A host-to-host design behind NAT chooses AH. (a) [5] failure. (b) [5] redesign. (c) [5] limitation.

Answer for every part

(a)

Answer: NAT rewrites fields AH authenticates, so verification fails. Trap: blaming encryption.

(b)

Answer: use ESP with NAT traversal where policy allows. Trap: disabling integrity.

(c)

Answer: endpoint compromise or wrong selectors can still expose traffic. Trap: claiming VPN secures application authorisation.
