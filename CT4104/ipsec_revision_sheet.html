IPSec

Connect IP-layer protection, security associations and mode choice to the network scenario.

Rapid exam refresher

  • SA is one-way with SPI/keys/anti-replay.
  • ESP protects confidentiality/integrity, AH header authentication conflicts with NAT.
  • transport versus tunnel changes protected bytes.

Purpose, scope and examiner demand

IPSec is named CT4104 scope and is a core example of a cryptographic network protocol.

Exam focus by part

  • SA is one-way with SPI/keys/anti-replay.
  • ESP protects confidentiality/integrity, AH header authentication conflicts with NAT.
  • transport versus tunnel changes protected bytes.

Question-demand diagnosis and answer plan

Identify endpoints and traffic; choose transport or tunnel mode; explain IKE/security associations and ESP/AH-style protection; state operational limits.

Question-type cues

  • Application cue: Hide internal addresses in site-to-site VPN.
  • Analysis cue: AH fails through NAT.

Definitions, notation and discriminating comparisons

  • Security association: agreed protection parameters and keys.
  • IKE: negotiates/authenticates and establishes keys.
  • ESP: commonly provides confidentiality and integrity protection.
  • Tunnel mode: encapsulates an entire original IP packet.
  • Transport mode: protects payload between end hosts.

Step-by-step methods and solution routes

  1. Draw gateways/end hosts and untrusted network.
  2. Select tunnel mode for gateway-to-gateway VPN, transport when appropriate for hosts.
  3. Explain IKE establishing authenticated parameters/keys.
  4. Explain packet protection and what endpoint compromise still exposes.

Reasoning checkpoints

  1. Use and justify: SA is one-way with SPI/keys/anti-replay.
  2. Use and justify: ESP protects confidentiality/integrity, AH header authentication conflicts with NAT.
  3. Use and justify: transport versus tunnel changes protected bytes.

Worked examples and method extensions

Two office gateways use IKE to establish security associations, then ESP tunnel mode wraps traffic across the internet. Outsiders cannot read the protected payload; a compromised office endpoint can still misuse data after decapsulation.

Hard practice — question demand

AH fails through NAT.

Plan / choice of method

Model the failure or boundary first, then apply these page-specific concepts in order: SA is one-way with SPI/keys/anti-replay.; ESP protects confidentiality/integrity, AH header authentication conflicts with NAT.; transport versus tunnel changes protected bytes. Finish by checking the final state against the deadline, security property, consistency contract, or performance requirement.

Worked answer

NAT rewrites AH-protected header fields. Use ESP with NAT traversal or routed path while keeping auth/rekey/replay controls.

Mark-winning points

Credit requires the complete method sequence, explicit verification of the conclusion, and the limiting assumption/trade-off—not merely the recommended technology.

Common trap

Omitting key establishment.

Topic-specific traps and diagnosis

  • Claiming encryption fixes endpoint compromise.
  • Omitting key establishment.
