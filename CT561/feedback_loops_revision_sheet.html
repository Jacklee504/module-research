CT561 Topic Guide

Feedback Loops

Feedback explains why a system’s own output changes the causes that produced it.

Exam-use protocol

Before writing, identify the command word: calculate/trace requires an ordered derivation; explain requires a definition, mechanism and assumption; compare/design requires matched criteria, a justified choice and a limitation. The topic-specific recall and worked routes below are the material to adapt—not text to copy blindly.

Part-by-part recall: definitions, assumptions and mechanics

Definitions: a + link moves variables in same direction, - opposite; an even number of negative links is reinforcing, odd is balancing. Feedback is circular causation, not “good/bad”. Question cue: draw every link sign, trace a perturbation around each named loop and identify delay/side effect.

Worked practice 1 — paper-derived polarity

Question demand: Backlog raises pressure, pressure raises completion, completion lowers backlog. Plan/choice: multiply signs/trace increase. Worked answer: +,+,- yields balancing: a backlog increase ultimately increases its reduction. Mark-winning points: arrows and narrated trace. Common trap: “negative” means harmful.

Worked practice 2 — paper-derived workload synthesis

Question demand: Analyse overtime policy that raises completion but creates fatigue that slows work. Plan/choice: identify intended balancing loop and delayed reinforcing side effect. Worked answer: pressure->overtime->completion->backlog is balancing; overtime->fatigue->time/task->completion can reinforce backlog after delay. Mark-winning points: polarity and policy consequence. Common trap: omit delayed loop.

Purpose and relevance

Causal-loop diagrams reveal system structure before numbers are chosen. They are useful for explaining growth, correction, delays and unintended consequences.

What a question really asks — answer plan

Name variables as measurable nouns. Mark each direct link + or −, trace a closed path, then classify it as reinforcing or balancing and narrate the mechanism in words.

Key terms and rules

  • Positive link: cause rises, effect rises above what it otherwise would; cause falls, effect falls.
  • Negative link: cause rises, effect falls below what it otherwise would.
  • Reinforcing (R): amplifies change; an even number of negative links.
  • Balancing (B): resists a gap or target; an odd number of negative links.
  • Delay: effect occurs later; it can cause oscillation or overshoot.

Method derivation

  1. State the question: growth, goal-seeking, or side effect?
  2. Connect variables with signed arrows, using “all else equal”.
  3. Count negative links around each closed loop.
  4. Label R/B and explain one run of the loop.
  5. Identify likely delays and where a policy might change structure.

Worked practice 3 — foundational calculation

Problem: More infections create more infectious people; more infectious people create more new infections.

Answer: Both links are positive, so this is an R loop: infections increase the infectious population, which increases contact opportunities and hence infections. It is not “positive” because it is good; polarity describes direction.

Question interpretation and independent practice

Prompt 1

As inventory rises, the inventory gap to a target falls; a larger gap increases ordering. Classify the loop. Check: one negative link, therefore balancing.

Exam bridge

Draw a workload-pressure-quality loop for a project and one delayed unintended side effect of adding staff. Check: label links/loops, explain the causal story, and avoid treating “more pressure” as automatically a negative arrow.

High-value traps and corrections

  • Using “positive = desirable” or “negative = harmful”.
  • Labelling a loop without showing signs.
  • Leaving variables vague, such as “management”.

Final answer checklist

  • Each arrow has a polarity.
  • I can trace and narrate every loop.
  • I have considered delays and side effects.
