Rapid exam refresher

A link is + for same-direction change and - for opposite. A loop is reinforcing with even negative links, balancing with odd; trace an increase all around. Feedback exposes dynamic behaviour, side effects and policy resistance.

Answer route

  1. Identify calculation, representation, comparison, design or evaluation.
  2. State the equation, algorithm or diagram before application.
  3. Finish with a specific limitation, assumption or trade-off.

Adapted exam practice - Analyse claims-backlog loops. [15]

(a) [7-9 marks]

(a) Demand: trace polarity. Quickest route: backlog -> pressure -> capacity -> completion -> backlog. Answer: one negative link makes a balancing loop that counteracts backlog growth. Trap: positive because most links are plus.

(b) [7-8 marks]

(b) Demand: close a side-effect loop. Quickest route: pressure -> rushed work -> rework -> backlog. Answer: this is reinforcing; pair capacity with quality control. Trap: list an effect that never returns to source.
