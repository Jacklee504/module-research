CT561 Supporting Topic Guide

Vensim, Validation and Policy Analysis

Use this as supporting material for design and discussion parts. The local papers favour actual model construction and policy consequences over a standalone validation essay.

What the papers actually reward

  • Write a valid Vensim-style stock-flow equation with units, initial values and causal links.
  • Use the time/shadow variable when a differential equation contains t. 2017/18 Q2(a)
  • Sketch and explain a policy scenario, such as a changed staff target or quarantine/vaccination setting. 2018/19 Q4(c), 2024/25 Q2(c), 2025/26 Q2(c), Q4(d)
  • Discuss policy trade-offs from feedback loops, not just the best-looking outcome. 2018/19 Q2(c), 2019/20 Q2(c), 2025/26 Q3(c)

Vensim modelling checks

  • Every stock must use INTEG(net flow, initial value).
  • Every rate multiplied by time must give the stock unit.
  • Use a lookup/effect graph for a nonlinear empirical relationship, such as student-staff ratio affecting attrition.
  • Use SMOOTH or a first-order delay when the paper asks for expected losses, smoothing or an adjustment delay.
  • Use a control flag as a 0/1 multiplier when a policy can be activated/deactivated.

Validation answer framework

Use this only when the question asks how reliable a model or policy is. Keep it linked to the actual structure:

  1. Structure: confirm stocks, flows, signs, conservation and dimensional consistency.
  2. Parameters: explain where contact rate, delay, attrition, productivity or effect-lookup values came from and vary uncertain values.
  3. Behaviour: compare trends, turning points and plausible extreme cases, not only one fitted curve.
  4. Policy: compare a baseline against alternatives using the same assumptions and report side-effects, delays and uncertainty.

Policy-analysis route from recent papers

For the 2025/26 quarantine/vaccination model, run the baseline with low quarantine and low vaccination, then change one parameter at a time. Compare attack rate, infection peak and timing. Explain mechanism: quarantine reduces transmission; vaccination removes susceptible people. Do not claim that a lower peak alone is automatically best if the policy requires unavailable resources or only delays the peak.

For a workforce target shock, plot actual Staff, Desired Staff, Hires and Expected Quits. Explain the effect of adjustment time and any recruitment pipeline on overshoot and settling time.

Common errors

  • A historical fit alone does not validate causal structure.
  • Reducing DT improves numerical approximation; it does not validate the model.
  • One simulation run is not a policy recommendation.
  • Do not discuss policy without naming the flow, parameter or feedback it changes.
