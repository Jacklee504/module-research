Practice question -- increasing independent events (16 marks)

Inspired by: 2021/22 Question 1(f) and 2019/20 Question 1(e).

(a) Define limsup An. [4 marks]

Answer: ∩N=1∞∪n≥NAn, the event that infinitely many An occur. Trap: use ∪N∩n≥NAn, which is liminf.

(b) If An is increasing and P(A1)>0, what is limsup An? [5 marks]

Answer: because increasing means An⊆An+1, every point in ∪An is in all later sets; hence limsup An=∪An and P(limsup)=lim P(An). Trap: confuse increasing with independent.

(c) Explain where independence would enter a Borel--Cantelli calculation. [7 marks]

Answer: for independent An, divergence of ∑P(An) gives P(limsup An)=1 by the second Borel--Cantelli lemma; convergence gives probability zero without independence. Trap: use the divergence conclusion without independence.
