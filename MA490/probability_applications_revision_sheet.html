MA490 Topic Guide

Probability Applications

Translate event language into measurable sets before calculating.

Purpose

Handle event sequences, Bernoulli-style spaces and Borel-Cantelli arguments with the correct hypotheses.Exam use: Event translation, limsup/liminf form, series calculation, independence requirement and almost-sure conclusion are explicit.

Question plan

  1. Name each event An and write the target as limsup or liminf when appropriate.
  2. Check measurability and whether independence is actually given.
  3. Compute or bound the series ΣP(An).
  4. State the exact Borel-Cantelli direction being used.
  5. Question interpretation: Translate verbal events into sets, decide independence versus disjointness, and identify limsup/liminf before invoking Borel-Cantelli or continuity.

Definitions

limsup A_n is the event that infinitely many An occur. First Borel-Cantelli: if ΣP(An)<∞, then P(limsup An)=0. With independence, divergence gives probability one in the second lemma.Rapid recall: limsup A_n means infinitely often, intersection_m union_{n>=m}A_n; liminf means eventually always, union_m intersection_{n>=m}A_n; independent events satisfy P(A intersect B)=P(A)P(B).

Proof method

For the first lemma, bound the probability of a tail union by its tail sum, then let the tail start tend to infinity. Avoid claiming the converse without independence.Exam workflow: Write the event algebra first, use complements when simpler, and attach every probabilistic theorem to its independence or summability hypotheses.

Worked simple example

If P(An)=2−n, then ΣP(An) is finite, so only finitely many An occur almost surely.

Practice 1 — infinitely many Bernoulli successes and failures [9 marks]

Prompt. In independent Bernoulli trials with 0<p<1, prove that successes and failures each occur infinitely often almost surely. Question-demand diagnosis. Apply the second Borel–Cantelli lemma separately to two independent event sequences. Fastest route. Note both probability series diverge and each trial family is independent. Topic-specific trap. “Infinitely often” is a limsup event, not an assertion about every sufficiently late trial.

For independent Bernoulli trials with success probability p in (0,1), let A_n be success at trial n. Since sum P(A_n)=infinity and the events are independent, the second Borel-Cantelli lemma gives P(A_n infinitely often)=1. For failures the same argument uses 1-p, so almost surely both successes and failures occur infinitely often.

Graduated exam bridges

1. Basic: What does P(limsup An)=0 say in words? Check: infinitely many occurrences has probability zero.

2. Exam: Can you infer P(limsup An)=1 from ΣP(An)=∞ alone? Check: no, independence or a suitable substitute is needed.

Practice 2 — finite occurrence without independence [8 marks]

Prompt. If P(An)=2−n, prove An occurs only finitely often almost surely without assuming independence. Question-demand diagnosis. Identify the direction of Borel–Cantelli that needs summability only. Fastest route. Sum the geometric series and invoke the first lemma for limsup An. Topic-specific trap. Probability zero for infinitely many occurrences is not the same as logical impossibility.

Paper-style synthesis: if P(A_n)=2^{-n}, show only finitely many A_n occur a.s., without independence. Check sum P(A_n)=1<infinity; the first Borel-Cantelli lemma gives P(limsup A_n)=0.

Mistakes

  • Confusing “probability zero” with impossibility.
  • Using the second Borel-Cantelli lemma without independence.
  • Reading limsup as eventual occurrence.
  • Recovery rule: Disjoint non-null events cannot be independent: their intersection has probability 0 while the product is positive.
