Practice question -- ternary test (12 marks)

Inspired by: 2022/23 and 2023/24 Question 1(j).

(a) Does (0.202)3 belong to the Cantor set? [4 marks]

Answer: yes: its displayed ternary expansion uses only 0 and 2. Trap: read the digits as decimal.

(b) Does (0.12)3 belong? [4 marks]

Answer: no: its first ternary digit 1 puts it in the removed middle third; no endpoint alternative applies. Trap: inspect only the final digit.

(c) Give a non-endpoint Cantor-set element. [4 marks]

Answer: (0.020020002...)3, with infinitely many 0s and 2s but not eventually all 0 or all 2, lies in the set and is not a removed-interval endpoint. Trap: give 1/3, which is an endpoint with an alternate expansion.
