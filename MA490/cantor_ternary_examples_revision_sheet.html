Cantor-set and Ternary Examples

Read the construction as a digit rule, while treating this as a historical variant.

Purpose

Decide Cantor-set membership from ternary expansions and connect the construction to measure intuition.Exam use: Digit convention, endpoint ambiguity, stage count/length, limiting measure and cardinality argument are separate.

Question plan

  1. Write a ternary expansion of the candidate point.
  2. Use an expansion containing only 0 and 2 when possible.
  3. Remember endpoints can have two expansions.
  4. For measure, track the total retained interval length at stage n.
  5. Question interpretation: For membership, choose a ternary expansion carefully at endpoints; for measure, use the stage lengths; for cardinality, construct an explicit digit map rather than relying on a picture.

Definitions

The middle-thirds Cantor set is obtained by repeatedly deleting open middle thirds. A number lies in it exactly when it has a ternary expansion using only digits 0 and 2, with endpoint ambiguity handled by choosing a valid expansion.Rapid recall: The Cantor set consists of points with a ternary expansion using only 0 and 2, allowing the alternate endpoint expansion; stage n has 2^n intervals of length 3^{-n} and total length (2/3)^n.

Proof method

At stage n there are 2n intervals, each of length 3−n, so their total length is (2/3)n. Its limit is zero, proving the Cantor set has Lebesgue measure zero.Exam workflow: Track the construction stage or ternary digits, address nonunique expansions, and separate uncountability from positive measure.

Worked simple example

1/3=0.13=0.0222…3. The second expansion uses only 0 and 2, so 1/3 belongs to the Cantor set.

Medium/hard paper-style synthesis

Show 1/4 is in the Cantor set. Since 1/4=sum_{k>=1} 2/3^{2k}, its ternary expansion is 0.020202..._3, using only 0 and 2. The Cantor set has measure at most the stage-n total (2/3)^n, whose limit is 0, so it has measure zero despite containing this and uncountably many other points.

Graduated exam bridges

1. Basic: Does 1/2 lie in the Cantor set? Check: 1/2=0.111…3, so no valid 0/2-only expansion exists.

2. Exam: Explain why endpoint ambiguity does not invalidate the digit test. Check: membership needs one permissible ternary expansion.

Hard paper-style synthesis

Paper-style synthesis: construct an injection from binary sequences to C. Check map (b_k) to sum 2b_k/3^k; distinct sequences first differ at some digit and yield distinct points, apart from endpoint ambiguity avoided by the chosen 0/2 expansion convention. Thus C is uncountable.

Mistakes

  • Forgetting non-unique expansions such as 0.13=0.0222…3.
  • Claiming the Cantor set is countable because it has measure zero.
  • Using decimal rather than ternary digits.
  • Recovery rule: A ternary endpoint may have two expansions; rejection based on the expansion containing digit 1 can be wrong if an all-0/2 alternative exists.

Checklist

  • I can state the 0/2 digit criterion.
  • I can resolve an endpoint with an alternative expansion.
  • I can compute the retained total length.
  • Final 60-second audit: Digit convention, endpoint ambiguity, stage count/length, limiting measure and cardinality argument are separate.
