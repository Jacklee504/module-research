MA490 Topic Guide

Convergence of Functions

Separate pointwise, uniform and almost-uniform claims before proving them.

Purpose

Classify function convergence and produce compact proofs or counterexamples.Exam use: Domain, candidate limit, quantifier/supremum calculation, epsilon choice and endpoint behaviour are explicit.

Question plan

  1. Find the candidate pointwise limit.
  2. For uniform convergence, inspect supx|fn−f|.
  3. For a failure, choose x depending on n.
  4. For almost-uniform convergence, first choose an exceptional set of small measure.
  5. Question interpretation: For pointwise, fix x then choose N depending on x; for uniform, make one N work for all x or calculate the supremum norm; for counterexample, choose x_n that tracks the worst case.

Definitions

Pointwise convergence fixes x before n tends to infinity. Uniform convergence requires supx|fn(x)−f(x)|→0. Almost-uniform convergence permits removal of a measurable set of arbitrarily small measure before uniform convergence.Rapid recall: Uniform convergence means sup_x |f_n-f|->0 and implies pointwise convergence; a uniform limit of continuous functions is continuous, while pointwise limits need not be.

Proof method

To disprove uniform convergence, give ε>0 and, for every N, choose n≥N and xn with error at least ε. Never let x depend on n in a pointwise proof.Exam workflow: First find the pointwise limit, then maximise the error or produce an epsilon and adversarial x_n; keep the quantifier order visible.

Worked simple example

On [0,1], fn(x)=xn converges pointwise to f with f(x)=0 for x<1 and f(1)=1, but not uniformly because fn(1)=f(1) is harmless while values close to 1 keep large error against 0.

Medium/hard paper-style synthesis

For f_n(x)=x^n on [0,1], the pointwise limit is f(x)=0 for x<1 and f(1)=1. Convergence is not uniform because each f_n is continuous but f is discontinuous; directly, for x<1 the error is x^n and sup_{x<1}x^n=1, though not attained, so sup_{[0,1]}|f_n-f|=1 for every n.

Graduated exam bridges

1. Basic: Does xn converge pointwise on [0,1]? Check: yes, to the stated discontinuous limit.

2. Exam: Give a one-line obstruction to uniform convergence to a continuous function when the pointwise limit is discontinuous. Check: a uniform limit of continuous functions is continuous.

Hard paper-style synthesis

Paper-style synthesis: on [0,a] with 0<a<1, prove x^n->0 uniformly. Check sup_{x in [0,a]}x^n=a^n->0; for epsilon choose N>log epsilon/log a, noting log a<0 when handling the inequality.

Mistakes

  • Interchanging the order of quantifiers.
  • Testing only a few fixed points for uniform convergence.
  • Confusing almost everywhere with almost uniform.
  • Recovery rule: Testing only fixed points can never disprove uniform convergence; the bad point may depend on n.

Checklist

  • I can write the quantifiers for pointwise and uniform convergence.
  • I can choose a moving bad point.
  • I know the continuous-uniform-limit theorem.
  • Final 60-second audit: Domain, candidate limit, quantifier/supremum calculation, epsilon choice and endpoint behaviour are explicit.
