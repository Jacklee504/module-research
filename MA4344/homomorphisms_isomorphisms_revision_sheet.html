MA4344 Topic Guide

Homomorphisms and Isomorphisms

Let kernels and images expose a group's structure.

Purpose

Recognise maps, calculate kernel/image, and invoke the first isomorphism theorem with the correct quotient.Exam use: Well-definedness, operation law, kernel, image, normality and quotient/image orders are all checked.

Question plan

  1. Verify φ(xy)=φ(x)φ(y).
  2. Find ker φ and im φ explicitly.
  3. State normality of the kernel and apply G/kerφ≅imφ.
  4. For finite groups, use |G|=|kerφ||imφ.
  5. Question interpretation: For homomorphism, verify operation preservation; for kernel/image, calculate as sets and use them to test injectivity/surjectivity; for quotient, state the first isomorphism theorem.

Key terms

Homomorphism, kernel, image, injective iff kernel is {e}, surjective, isomorphism, quotient. The first isomorphism theorem is G/kerφ≅imφ.Rapid recall: ker phi is normal, im phi is a subgroup, phi injective iff ker phi={e}, and G/ker phi is isomorphic to im phi.

Proof method

For a proposed isomorphism, prove it is a homomorphism and then prove bijectivity (often by identifying kernel and image). Never merely note that two groups have the same order.Exam workflow: Check the map on general products, solve phi(g)=e, describe all attained values, then verify orders in the proposed isomorphism.

Worked simple proof

Claim: φ:Z→Z6, n↦n mod 6, gives Z/6Z≅Z6. It is a homomorphism, kerφ=6Z and imφ=Z6; the first isomorphism theorem gives the result.

Medium/hard paper-style synthesis

Define phi:Z12->Z8 by phi([x]12)=[2x]8. This is not well-defined: [0]12=[12]12 but phi(0)=0 while phi(12)=24=0 mod 8, actually these agree; in general changing x by 12 changes 2x by 24, divisible by 8, so it is well-defined. Kernel solves 2x=0 mod 8, giving classes x=0,4,8; image={0,2,4,6}. Thus Z12/ker has order 4 and is isomorphic to 2Z8.

Graduated exam bridge

1. Find ker and image of φ:Z12→Z4, [x]↦[x]. Check: image is all of Z4; kernel has three elements.

2. If φ:G→H is a homomorphism of finite groups with |G|=60 and |kerφ|=5, find |imφ| and justify it. Check: 12, by the homomorphism counting formula.

Hard paper-style synthesis

Paper-style synthesis: decide whether [x]12 -> [3x]8 is well-defined. Check changing by 12 changes output by 36, not divisible by 8, so it is not; test [0]=[12] gives 0 versus 4.

Mistakes

  • Writing G/kerφ≅H without proving surjectivity.
  • Forgetting kernels are subsets of the domain.
  • Using additive notation on one side and multiplicative notation inconsistently.
  • Recovery rule: For maps on residue classes, well-definedness comes before homomorphism properties.

Checklist

  • I can find a kernel by solving φ(g)=e.
  • I know the first isomorphism theorem exactly.
  • I can convert kernel size into image size for finite groups.
  • Final 60-second audit: Well-definedness, operation law, kernel, image, normality and quotient/image orders are all checked.
