Class Equation and p-Groups

Use conjugation orbits and divisibility modulo p to force a nontrivial centre.

What repeatedly appears in the papers

The class equation, nontrivial centre of a p-group, and groups of order p2 are a three-part sequence in 2023/24 and 2024/25 Question 3(b), worth 6+5+5 marks.

How to answer

  1. Explicitly name conjugation as the action.
  2. Separate central singleton orbits.
  3. Reduce the class equation mod p, then use a centre/quotient argument.

Practice question -- p2 groups (16 marks)

Inspired by: 2024/25 Question 3(b).

(a) Prove a finite p-group has nontrivial centre. [7 marks]

Answer route: class equation mod p. Answer: every noncentral orbit has size [G:CG(y)], a nontrivial power of p, hence divisible by p. Thus p divides |Z(G)|; since e∈Z(G), |Z(G)|≥p. Trap: assert every conjugacy class has p elements.

(b) Prove a group G of order p2 is abelian. [6 marks]

Answer: |Z(G)| is p or p2. The latter is done. If |Z(G)|=p, then G/Z(G) has order p and is cyclic; a group with cyclic G/Z(G) is abelian, contradiction to Z(G)≠G. Hence G=Z(G). Trap: claim all p-groups are abelian.

(c) State CG(y). [3 marks]

Answer: {g∈G:gy=yg}. Trap: give the centre, which requires commuting with every element.
