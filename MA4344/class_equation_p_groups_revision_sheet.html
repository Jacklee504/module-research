MA4344 Topic Guide

Class Equation and p-Groups

Use conjugacy classes to force central elements.

Purpose

Prove the nontrivial-centre theorem and quickly derive the order-p² abelian result.Exam use: Centre term, representatives, centralizers, divisibility/mod-p step and final group consequence are justified.

Question plan

  1. Use conjugation as the action.
  2. Separate central elements from noncentral conjugacy classes.
  3. Apply orbit-stabiliser: class size [G:CG(x)].
  4. Reduce the class equation modulo p.
  5. Question interpretation: For class equation, identify central singleton classes and express every other class size as an index; for p-groups, reduce the equation modulo p.

Key terms

Centre Z(G), centraliser CG(x), conjugacy class Cl(x), class equation: |G|=|Z(G)|+∑[G:CG(xi)].Rapid recall: |G|=|Z(G)|+sum [G:C_G(x_i)]; noncentral conjugacy-class sizes divide |G| and exceed 1; a finite p-group has nontrivial centre.

Proof method

For a finite p-group, every noncentral conjugacy class has size divisible by p. Hence |Z(G)|≡|G|≡0 mod p, so Z(G) is nontrivial.Exam workflow: Choose noncentral class representatives, justify each class size is a positive power of p, take the class equation modulo p, then extract the structural consequence.

Worked simple proof

Claim: every group G of order p² is abelian. The centre has order p or p². If p², done. If p, then G/Z(G) has order p, hence cyclic; a group with cyclic central quotient is abelian.

Medium/hard paper-style synthesis

Let |G|=p^2. The p-group centre theorem gives |Z(G)| divisible by p and greater than 1, so |Z(G)| is p or p^2. If it were p, G/Z(G) would have order p and be cyclic. But if G/Z(G) is cyclic then G is abelian, forcing Z(G)=G, contradiction. Hence |Z(G)|=p^2 and G is abelian.

Graduated exam bridge

1. Why does a noncentral conjugacy class in a p-group have size divisible by p? Check: its size is a nontrivial power of p.

2. Prove that a group of order 49 is abelian. Check: apply the p² theorem with p=7.

Hard paper-style synthesis

Paper-style synthesis: if |G|=8 and |Z(G)|=2, what can noncentral class sizes be? Check they are powers of 2 dividing 8 and cannot be 1; the six noncentral elements must partition into sizes 2 or 4, constrained by centralizer indices.

Mistakes

  • Including central elements again in the noncentral sum.
  • Claiming every conjugacy class has p elements.
  • Using G/Z(G) cyclic without stating why that implies G abelian.
  • Recovery rule: The class equation sums one term per conjugacy class representative, not one term per noncentral element.
