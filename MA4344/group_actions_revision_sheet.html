Group Actions

How to answer

  1. State the set X and action formula.
  2. Verify identity/composition, then write the induced permutation.
  3. To prove injectivity, show its kernel is trivial.

Practice question -- regular action (14 marks)

Inspired by: 2024/25 Question 3(a).

(a) Let V=C2×C2 act on itself by left multiplication. Verify an action. [5 marks]

Answer route: associativity. Answer: e.x=x and (gh).x=(gh)x=g(hx)=g.(h.x), so this is an action. Trap: call conjugation the action without defining it.

(b) Give the corresponding map into Sym(V) and prove it injective. [6 marks]

Answer: φ(g):x↦gx; composition gives φ(gh)=φ(g)φ(h). If φ(g)=id, then g=φ(g)(e)=e; kernel is trivial, hence φ is injective and identifies V with a subgroup of Sym(4). Trap: say an action is automatically faithful.

(c) State the orbit of e. [3 marks]

Answer: all V, since g.e=g. Trap: confuse orbit with stabiliser.
