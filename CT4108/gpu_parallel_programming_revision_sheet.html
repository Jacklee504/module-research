CT4108 Revision

GPU and Parallel Programming

Break a computation into safe independent work while accounting for data movement and synchronisation.

Rapid exam refresher

  • Map independent index to thread/block and guard bounds.
  • Coalesced global access and shared-memory reuse matter; transfer can dominate.
  • Barriers coordinate within block; dependent global stages need kernel boundary.
  • Divergence, occupancy and bandwidth limit speed.

Paper evidence and scope

No CT4108 papers: syllabus-based.

Medium practice — 15 marks

Vector add. (a) [5] pseudocode. (b) [5] memory. (c) [5] timing.

Answers

(a): i=blockIdx*blockDim+threadIdx; if(i<N)c[i]=a[i]+b[i]. Trap: edge out-of-bounds.

(b): adjacent threads access adjacent elements for coalescing. Trap: strided unexamined access.

(c): batch transfers, synchronise before host read and include transfer in wall time. Trap: kernel-only benchmark.

Hard practice — 15 marks

Tiled matrix multiply. (a) [5] reuse. (b) [5] barriers. (c) [5] edges/divergence.

Answers

(a): cooperatively cache tiles in shared memory, accumulate registers. (b): barrier after load and before overwrite. (c): guard/pad edge tiles and avoid warp-divergent paths. Trap: missing barrier race.
