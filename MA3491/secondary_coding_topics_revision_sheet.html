Medium/hard adapted practice

(a) For a binary [5,2] code with codeword weights 0,3,3,4, write its weight enumerator and decide if it is MDS when d=3. [6 marks]

Question demand: apply the definition/calculation with working. Quickest route: Count each weight; compare M=4 with 2^(n-d+1).

Mark-aware answer: W(z)=1+2z^3+z^4. Singleton gives M<=2^3=8, so M=4 is not MDS. This is background/secondary practice, not a recurrence prediction.

Trap: Do not call every linear code with a nice enumerator self-dual.

(b) Compute a weight enumerator from a displayed generator matrix. [6 marks]

Question demand: List all qk codewords, count each Hamming weight, then sum Aizi. Quickest route: List all qk codewords, count each Hamming weight, then sum Aizi.

Mark-aware answer: For a [n,k] code over Fq, enumerate uG for every u in Fqk. If A_i words have weight i, W_C(z)=sum A_i zi; verify sum A_i=qk.

Trap: Do not count the zero word as positive weight.

(c) Explain the BCH orientation without inventing paper recurrence. [4 marks]

Question demand: State the design idea and label the evidence level correctly. Quickest route: State the design idea and label the evidence level correctly.

Mark-aware answer: A BCH code is a cyclic code chosen by prescribing consecutive roots of its generator polynomial in an extension field; the root choice gives a designed minimum distance. This is syllabus-based practice here because the local papers do not establish a repeating BCH question family.

Trap: Do not present BCH as a guaranteed recent-paper slot.
