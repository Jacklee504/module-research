Most Likely Exam Questions

Recurring past-paper question families and wording variations, without solutions.

Scope

This solution-free question bank is distilled from the six local papers: 2018-19, 2021-22, 2022-23, 2023-24, 2024-25, and 2025-26. The 2024-25 paper uses the combined code MA3491/MA539.

Its purpose is to make equivalent questions recognisable when the field, alphabet, numbers, or wording change. For example, “construct a check matrix” and “hence determine whether this word is a codeword” normally belong to one generator/check-matrix workflow, rather than two unrelated topics.

The recent four papers use five questions. The stable broad pattern is: bounds and block-code parameters; finite fields; linear codes and decoding; Hamming codes; and cyclic codes. Weight enumerators appeared in 2022-23, 2023-24, and again inside the cyclic-code question in 2025-26.

1. Bounds and block-code parameters

Sphere-packing bound - all six papers

Core prompt: State the sphere-packing bound, then use it to obtain an upper bound on the number of codewords.

Wording variations:
  • “State the sphere packing bound and use it to show that a binary code of block length 8 that can correct all single errors can have at most ... code words.” (2018-19)
  • “State the sphere packing bound, and determine which upper bound on the number of codewords in a block code with alphabet F5, block length 8, that corrects all single errors it gives.” (2021-22)
  • “State the sphere packing bound, and determine the upper bound it gives on the number of code words in a 4-ary code with block length 8 and minimum distance 3.” (2022-23)
  • The same question for a ternary code of length 8 and minimum distance 3. (2023-24)
  • State the bound, then separately determine the upper bound for a binary code with block length 10 and minimum distance 5. (2024-25)
  • The same split statement/application format for a binary code with block length 12 and minimum distance 5. (2025-26)

Same-skill signal: “corrects all single errors” and “minimum distance 3” are different descriptions of the same type of application. Alphabet size and length are deliberately varied.

Singleton bound - the three most recent papers

Core prompt: State the Singleton bound and determine an upper bound. Be ready for the proof version.

  • State the bound and apply it to a ternary code with length 8 and minimum distance 3. (2022-23)
  • The same wording for a 4-ary code with length 8 and minimum distance 3. (2023-24)
  • State the bound, prove it, then apply it to a ternary code with length 9 and minimum distance 3. (2024-25)
  • The same three parts for a binary code with length 12 and minimum distance 5. (2025-26)

Structured-code size, minimum distance, and classification

Core prompt: A code is described by a property of its words rather than by a matrix. Determine its size, parameters, minimum distance, or perfect/MDS status.

  • Four explicit words over {A,B}: determine minimum distance. (2018-19)
  • All length-9 ternary words in which every symbol occurs exactly three times: determine minimum distance. (2021-22)
  • All binary length-8 words with an equal number of 0s and 1s: find number of codewords and minimum distance. (2022-23)
  • Palindromic words of even and odd block length: find number of codewords and minimum distance. (2023-24)
  • A ternary 7-ply repetition code: determine parameters, then show whether it is perfect and MDS. (2024-25)

Lower-priority older variation: ISBN checksum questions appear in 2018-19 and 2021-22, but not in the recent five-question pattern.

2. Finite fields and polynomial arithmetic

Irreducibility or factorisation - all six papers

Core prompt: Determine whether polynomial(s) in Fq[x] are irreducible; factor any reducible ones into irreducibles.

  • “Show that the ternary polynomial ... is irreducible.” (2018-19)
  • For each polynomial in F3[x], determine whether it is irreducible; if reducible, factor it into irreducibles. (2021-22)
  • The same instruction in F5[x] for two cubics. (2022-23)
  • Factor x^6 - 1 in F3[x] into irreducibles. (2023-24)
  • Show that a supplied quadratic in F5[x] is irreducible. (2024-25)
  • Find all irreducible degree-2 polynomials in F2[x], then show a supplied degree-5 polynomial is irreducible. (2025-26)

Same-skill signal: “show irreducible,” “determine if irreducible,” and “factor into irreducibles” are one finite-field factorisation family.

Quotient-field construction and arithmetic

Core prompt: After an irreducible polynomial is supplied or established, work in the quotient field it defines.

  • Construct the field of eight elements: give elements and describe addition/multiplication. (2018-19)
  • Establish F8 = Z2[x]/(f), then calculate a product. (2021-22)
  • Establish F27 = F3[x]/(f), then calculate a product represented by degree at most 2. (2022-23)
  • Establish F16 = F2[x]/(f), then work with residue classes. (2023-24)
  • Use the supplied presentation of F25 to calculate an inverse. (2024-25)

Multiplicative inverse, order, and primitive elements

  • Calculate the inverse of x² in F8, F27, or F16, with a stated degree limit. (2021-22 to 2023-24)
  • Calculate the inverse of x + 3 in F25. (2024-25)
  • Find the order of x² + x in F16. (2023-24)
  • Define a primitive element, then prove a statement concerning inverses of powers and inverses of primitive elements. (2024-25)

One-off extensions: polynomial gcd and units in polynomial rings (2018-19); treating F4 as a vector space over F2 (2024-25).

3. Linear codes, check matrices, and decoding

Generator matrix to codewords and minimum distance - all six papers

Core prompt: A linear code is presented by a generator matrix. List/generate codewords and determine minimum distance, possibly after putting the matrix in standard form.

  • “List the codewords of C. Hence find the minimum distance.” (2018-19)
  • “Write down the code words of C. Determine the minimum distance.” (2021-22 and 2022-23)
  • “What is the minimum distance of C1?” after listing its codewords. (2023-24)
  • First construct a standard-form generator matrix and a check matrix, then determine minimum distance. (2024-25)
  • The same sequence, followed by self-duality and syndrome decoding. (2025-26)

Standard form and check matrix - all six papers

  • “Find a generator matrix in standard form ... Hence, construct a parity check matrix.” (2018-19 and 2021-22)
  • “Construct a check matrix” when the given generator matrix is already in standard form. (2022-23 and 2023-24)
  • “Construct a generator matrix in standard form”; then “Construct a check matrix.” (2024-25)

Same-skill signal: “parity check matrix” and “check matrix” are the same target. “Hence” normally means use the standard-form result from the prior part.

Check-matrix consequences and decoding

  • After constructing a check matrix, determine whether a supplied word is a codeword. (2021-22)
  • A check matrix is supplied; determine minimum distance. (2022-23 and 2023-24)
  • Construct a syndrome lookup/table and use it to decode word(s). (2018-19, 2022-23, 2023-24, 2024-25, 2025-26)
  • Determine the result of nearest-neighbour decoding. (2022-23)
  • Construct a standard array and decode received words. (2023-24)
  • Show that a code is self-dual after standard form/check-matrix work. (2024-25 and 2025-26)

Same-skill signal: “syndrome lookup table” and “syndrome table” are identical requests. Standard-array and nearest-neighbour wording are alternate representations of the same decoding theme.

4. Hamming codes

The Hamming-code sequence - all six papers

Expect this four-part sequence: define Ham(r,q); construct/write down a parity-check matrix; explain single-error correction; decode one or more words.

  • “What is the definition of the Hamming code Ham(r,q)?” appears in every paper.
  • “Write down a parity check matrix” for Ham(2,5). (2018-19 and 2021-22)
  • “Construct a parity check matrix” for Ham(2,7), Ham(2,4), or Ham(3,2). (2022-23 to 2025-26)
  • “Explain how a single error can be corrected ... Decode the word(s) ...” appears in every paper.

Recent extensions: state the parameters of Ham(r,q) and show that it is perfect. This exact extension repeated in 2024-25 and 2025-26.

5. Cyclic codes

Generator polynomial to generator/check matrix - all six papers

Core prompt: A cyclic code is specified by length, field, and generator polynomial. Construct its generator matrix, find the check polynomial, then construct or use a check matrix.

  • “Give the generator matrix ... Find the check polynomial ... Write down the check matrix and hence verify that ... is a codeword.” (2018-19)
  • The same chain, ending “determine if any of the words ... is a codeword.” (2021-22)
  • “Construct the generator matrix ... Find the check polynomial ... and hence construct a check matrix.” (2022-23 and 2023-24)
  • The same two-part construction over F4, with the field multiplication supplied. (2024-25)
  • Construct the generator and check matrices for a binary cyclic code, then use its dual in weight-enumerator parts. (2025-26)

Same-skill signal: “give” and “construct,” or “verify” and “determine if,” do not change the generator/check-polynomial/check-matrix chain.

Latest-paper extensions: show a cyclic code is MDS; prove an odd-weight binary cyclic code of odd block length contains the all-ones word, using the sum of cyclic shifts. (2024-25)

6. Secondary family: weight enumerators

This occurred in 2022-23, 2023-24, and 2025-26: define the weight enumerator, then compute it for a small supplied code. In 2025-26 it was embedded in the cyclic-code question: compute the enumerator of C⊥, state MacWilliams' identity, use it to obtain low-degree terms of the enumerator of C, then determine minimum distance.

Suggested self-test set

  1. Sphere-packing and Singleton bounds with changed alphabet/length.
  2. A structured-code size/minimum-distance question.
  3. Irreducibility/factorisation followed by quotient-field arithmetic.
  4. A finite-field inverse or multiplicative-order question.
  5. Generator matrix to standard form/check matrix/minimum distance.
  6. Syndrome or standard-array decoding.
  7. The full Hamming-code and cyclic-code construction sequences.

Add weight enumerators and the one-off proof extensions only after these repeated core families are secure.
