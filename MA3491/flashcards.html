Priority 1. Bounds And Described Codes

FrontBackEvidence
1. State the sphere-packing bound.For C ⊆ Fqn with minimum distance d and t = ⌊(d − 1)/2⌋: |C| Σi=0t C(n,i)(q − 1)i ≤ qn. The sum is the radius-t Hamming-ball size; such balls about codewords are disjoint.Q1(a), all current papers
2. Apply sphere packing; define one-error correction.Calculate t, evaluate S = Σ C(n,i)(q−1)i, then |C| ≤ ⌊qn/S⌋. “Corrects every single error” means t ≥ 1, equivalently d ≥ 3. Show the substitution and integer bound.Q1(a), all current papers
3. State the Singleton bound.|C| ≤ qn−d+1. For a linear [n,k,d] code this is k ≤ n − d + 1.Q1(b), all current papers
4. Prove the Singleton bound.Delete d−1 coordinates. Equal shortened images of distinct codewords would make them differ in at most d−1 places, impossible. Deletion is injective into Fqn−d+1, so |C| ≤ qn−d+1.2024/25–2025/26 Q1(b)
5. Find parameters of a code defined by word conditions.Count permitted words for |C|. Prove a lower bound for distance and exhibit a pair attaining it. Only write [n,k,d] after establishing linearity and |C|=qk; otherwise state length, size, distance.Q1(c), all current papers
6. Give palindrome and balanced-word parameters.|P2k,q|=qk, dmin=2; |P2k+1,q|=qk+1, dmin=1. Binary length-8 weight-4 words: size C(8,4)=70, distance 2; changes must balance 0→1 and 1→0.2022/23, 2023/24 Q1(c)
7. Repetition code: parameters, MDS, perfectness.The q-ary length-n repetition code is [n,1,n], MDS because 1=n−n+1. It is perfect only if |C| times its radius-⌊(n−1)/2⌋ sphere size is qn. Ternary length 7: radius-3 sphere is 379 and 3·379 ≠ 37, so not perfect.2024/25 Q1(c)

Priority 2. Finite Fields And Polynomial Arithmetic

FrontBackEvidence
8. Test degree-2/3 irreducibility over Fq.A degree-2 or degree-3 polynomial over a field is irreducible iff it has no root in that field. Evaluate every a ∈ Fq; a root yields x−a. Divide and continue if factorisation is requested.Q2(a), 2022/23, 2024/25
9. Prove a degree-5 polynomial over F2 irreducible.Rule out roots 0 and 1, then rule out the only irreducible quadratic x2+x+1 by division. Any nontrivial degree-5 factorisation has a factor of degree 1 or 2, so this proves irreducibility.2025/26 Q2(b)
10. Factor a polynomial over a finite field.Test all field elements for roots and divide out each linear factor. Factor the remainder by degree; a quadratic/cubic with no root is irreducible. Retain multiplicities and justify every final factor.Q2(a), 2022/23–2023/24
11. Construct Fq[x]/(p(x)).If p is irreducible of degree m, the quotient is a field of qm elements. Representatives have degree < m. Add in Fq; multiply and reduce using p(x)=0.Q2(b), all current papers
12. Multiply residue classes in a quotient field.Multiply representatives, then replace high powers using p(x)=0 until degree < deg p. Reduce coefficients in Fq throughout and state the final reduced representative.2022/23 Q2(b)(ii)
13. Find an inverse modulo p(x).Use extended Euclid to find u,v with u(x)a(x)+v(x)p(x)=1. Modulo p, [u][a]=[1], so [u]=[a]−1. Reduce u to degree < deg p and check the product if practical.Q2(b)/(c), all current papers
14. Define order and primitive element.ord(a) is least positive m with am=1. Since |F×|=|F|−1, a is primitive iff ord(a)=|F|−1. Test divisors of |F|−1 to find an order.2023/24, 2024/25 Q2
15. Prove a primitive inverse is primitive.(a−1)n=(an)−1, so (a−1)n=1 iff an=1. Thus a and a−1 have the same order. If a has order |F|−1, so does its inverse.2024/25 Q2(c)
16. Restrict scalars F4→F2.If F4=F2(a), {1,a} is an F2-basis. An F4-basis {e1,…,en} becomes F2-basis {e1,…,en,ae1,…,aen}. Expand coefficients as u+va for spanning and independence.2024/25 Q1(d)
17. Prove (a+b)p=ap+bp in characteristic p.Expand by the binomial theorem. For 0<j<p, the prime p divides C(p,j), so intermediate terms vanish in characteristic p. The endpoints remain.2025/26 Q2(d)

Priority 3. Linear Codes, Decoding, And Hamming Codes

FrontBackEvidence
18. Put G in standard form.Use row operations over the stated field until G=[Ik|A]. Row operations change the basis of the row space, not the code. Reduce arithmetic in Fq.2024/25–2025/26 Q3(a)
19. Construct H and test membership.From G=[Ik|A], take H=[−AT|In−k]. Then GHT=0, and row vector v is in C iff vHT=0. H is (n−k)×n.Q3(b), all current papers
20. Find dmin from codeword weights.List all nonzero linear combinations of generator rows, calculate their weights, and take the least. For a linear code, dmin is the minimum nonzero codeword weight. Exhibit a word attaining it.2022/23–2023/24 Q3(a)
21. Find dmin from H columns.dmin is the smallest number of linearly dependent columns of H. No zero column gives d≥2; no proportional pair gives d≥3. Exhibit a dependent set for equality. Include all nonzero scalar multiples over Fq.Q3(c)/Q4(a), all current papers
22. Prove self-duality.Show C⊆C⊥, e.g. GGT=0. Then dim C⊥=n−dim C. If dim C=n/2, the included subspaces have equal dimension, so C=C⊥.2024/25–2025/26 Q3(d)
23. Give syndrome decoding.For received r, calculate s=rHT. Choose minimum-weight coset leader e with eHT=s; decode to r−e. In nonbinary codes, syndrome ahj identifies error aej, including position and magnitude.Q3(b)/(e), all current papers
24. Standard array versus nearest neighbour.In a standard array, locate r and decode to its top-row column word. Nearest-neighbour decoding gives codeword(s) at minimum Hamming distance. They agree when the chosen leader has minimum weight; state a tie if present.2022/23–2023/24 Q3(a)(iii)
25. Define Ham(r,q) and give parameters.Let n=(qr−1)/(q−1), and H have one representative from each 1-dimensional subspace of Fqr as columns. Ham(r,q)={c∈Fqn:cHT=0}; its parameters are [n,n−r,3].Q4, all current papers
26. Construct a Hamming parity-check matrix.Choose one nonzero vector from every 1-dimensional subspace of Fqr; never include scalar multiples twice. There are (qr−1)/(q−1) columns. No two are proportional, supporting dmin=3.Q4(b), all current papers
27. Correct one Hamming-code error.If r=c+aej, then rHT=ahj. Find the unique proportional column and scalar a, then correct to r−aej. State corrected word, location, and magnitude if asked.Q4(c), all current papers
28. Prove Ham(r,q) is perfect.d=3 makes radius-1 balls disjoint. Each has 1+n(q−1)=qr words; the code has qn−r words. The total qn−rqr=qn is the whole ambient space, so every word lies in exactly one ball.2024/25–2025/26 Q4(e)

Priority 4. Cyclic Codes And Enumerators

FrontBackEvidence
29. Construct G from a cyclic generator polynomial.In Fq[x]/(xn−1), let monic g divide xn−1. If deg g=n−k, coefficient vectors of g,xg,…,xk−1g form the k×n generator matrix.Q5, all current papers
30. Construct cyclic h(x) and H.h(x)=(xn−1)/g(x). The dual generator is h*(x)=h(0)−1xdeg hh(x−1). Rows from h*,xh*,…,xn−k−1h* form H; verify GHT=0.Q5, all current papers
31. Prove the odd-weight binary cyclic theorem.Sum all n cyclic shifts of an odd-weight codeword u. The sum remains in C. Every coordinate contains every entry of u once, so equals wt(u)=1 mod 2. Thus the all-ones word is in C.2024/25 Q5(b)
32. Define and compute a weight enumerator.WC(z)=Σc∈Czwt(c). List all codewords, calculate weights, and collect equal exponents. Constant term is 1 and WC(1)=|C| checks the count.2022/23, 2023/24, 2025/26 Q5
33. State MacWilliams’ identity and find distance.For binary C length n: WC⊥(z)=|C|−1(1+z)nWC((1−z)/(1+z)). Apply it in the required direction. Minimum distance is the least positive exponent with nonzero coefficient.2025/26 Q5(d)–(f)

34. Define Hamming distance and prove it is a metric.d(x,y) counts unequal coordinates. It is nonnegative, zero exactly when x=y, and symmetric. Coordinatewise 1x≠z≤1x≠y+1y≠z; sum to obtain the triangle inequality.2018/19 Q1(a)
35. State ISBN-10 and ISBN-13 checks.ISBN-10: 10d1+9d2+…+d10≡0 (mod 11), with X=10. ISBN-13: alternating weights 1,3,…,1 yield sum ≡0 (mod 10). Substitute an unknown and solve.2018/19, 2021/22 Q1(b)
36. What are units in F[x]?Exactly F×, the nonzero constants. If fg=1, deg f+deg g=0, so both have degree 0; every nonzero constant has scalar inverse. In a Euclidean domain, a unit u has uv=1 for some v.2018/19 Q2(c)
