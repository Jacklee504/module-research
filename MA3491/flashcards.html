Priority 1. Bounds And Described Codes

FrontBackEvidence
State and apply the sphere-packing and Singleton bounds. Give the Singleton proof.

For a q-ary code C of length n, minimum distance d, and t = ⌊(d − 1)/2⌋:

|C| Σi=0t C(n,i)(q − 1)i ≤ qn.

Substitute q, n, d, calculate the sphere size, divide into qn, and take an integer upper bound. “Corrects all single errors” means t = 1 and d ≥ 3.

Singleton: |C| ≤ qn−d+1. Delete d − 1 coordinates. Equal deleted images would come from two words differing in at most d − 1 places, impossible; the injective image has at most qn−d+1 words.

Q1(a)–(b), 2022/23–2025/26; proof in 2024/25–2025/26
How do you find size, distance, and perfect/MDS status for a code described by conditions on words?

Count legal words, then exhibit two legal words as close as possible. Binary length-8 balanced words: |C| = C(8,4) = 70 and dmin = 2. P2k,q: qk words and distance 2; P2k+1,q: qk+1 words and distance 1. The 2025/26 X/Y constraint has Σi=04C(4,i)² = C(8,4) = 70 and distance 2.

A q-ary repetition code has [n,1,n] and is MDS because |C| = q = qn−d+1. It is perfect only if its radius-⌊(n − 1)/2⌋ balls exactly cover qn words. For the ternary 7-ply code, the radius-3 sphere has 1 + 7·2 + C(7,2)·22 + C(7,3)·23 = 379 words, so 3·379 ≠ 37.

Priority 2. Finite Fields

FrontBackEvidence
Give an exam-safe method for irreducibility, factorisation, and quotient-field construction.

A degree-2 or degree-3 polynomial over a field is irreducible exactly when it has no root in that field. Test every element of Fq; for factorisation, divide out roots and continue until all factors are irreducible. For degree 5 over F2, rule out degree-1 factors and x2 + x + 1; every proper factorisation has a factor of degree 1 or 2.

If p(x) is irreducible of degree m, Fq[x]/(p) is a field of qm elements. Use residue-class representatives of degree < m; add modulo q, multiply, then reduce with p(x) = 0.

Q2(a), Q2(b)(i), 2022/23–2025/26
How do you find an inverse in a quotient field, and prove the recent field-theory extensions?

Find u, v with u(x)a(x) + v(x)p(x) = 1. Then [u] = [a]−1. The order of a ∈ F× is least positive m with am = 1; a primitive element has order |F| − 1. Since (a−1)n = (an)−1, inverse preserves order and primitiveness.

If char F = p, expand (a + b)p. The intermediate C(p,j) are divisible by p, hence zero in F, so it equals ap + bp. For restriction of scalars, {1,a} is an F2-basis of F4; if {e1,…,en} is an F4-basis, expand coefficients as ui + via to prove {e1,…,en, ae1,…,aen} is an F2-basis.

Priority 3. Linear Codes, Decoding, And Hamming Codes

FrontBackEvidence
Given G, how do you obtain H, test membership, find distance, and prove self-duality?

Row-reduce over the stated field to G = [Ik | A]. Use H = [−AT | In−k], so GHT = 0. A row vector v is in C iff vHT = 0. For a linear code, dmin is the least nonzero word weight, or the least number of dependent columns of H.

For C = C⊥, show C ⊆ C⊥, for example with GGT = 0, and show dimensions agree: dim C⊥ = n − k, so equality follows if k = n/2.

Q3 and Q4(a), all current papers; self-dual in 2024/25–2025/26
Give a complete syndrome-decoding answer, and distinguish standard-array and nearest-neighbour wording.

For received row vector r, compute s = rHT. Choose a minimum-weight coset leader e with eHT = s, then return r − e. In nonbinary codes identify both error position and nonzero scalar magnitude.

In a standard array, locate r and decode to the top-row codeword in its column. Nearest neighbour means the codeword(s) at minimum Hamming distance; state a tie if it occurs.

Q3 decoding, all current papers
Define Ham(r,q), construct H, correct one error, state parameters, and prove perfection.

Let n = (qr − 1)/(q − 1). Take one nonzero representative from each 1-dimensional subspace of Fqr as a column of H. Ham(r,q) = {c ∈ Fqn : cHT = 0} and has [n, n − r, 3].

A single error aej has syndrome ahj; identify its column/scalar, subtract it. Radius-1 balls have 1 + n(q − 1) = qr words, and qn−r codewords, so the disjoint balls cover qn words.

Q4, all current papers; full 20 marks in 2024/25–2025/26

Priority 4. Cyclic Codes And Weight Enumerators

FrontBackEvidence
Given a cyclic-code length and generator polynomial, how do you construct G and H?

Work in Fq[x]/(xn − 1). A monic g(x) divides xn − 1. If deg g = n − k, coefficient vectors of g, xg, …, xk−1g form G. Calculate h(x) = (xn − 1)/g(x). A check matrix generates C⊥: use h*(x) = h(0)−1xdeg hh(x−1) as its dual generator polynomial; its n − k shifts are the rows of H. Verify GHT = 0.

For the odd-weight binary theorem, sum all cyclic shifts of u. Every coordinate sums wt(u) = 1 mod 2, hence the all-ones word is in C.

Q5, all current papers; odd-weight theorem 2024/25
Define the weight enumerator, state binary MacWilliams’ identity, and read distance from it.

WC(z) = Σc∈Czwt(c). Enumerate all codewords, including the constant term 1. For binary C of length n:

WC⊥(z) = |C|−1(1 + z)n WC((1 − z)/(1 + z)).

Apply in the requested direction, expand only as far as needed, then take dmin as the least positive exponent with nonzero coefficient. Keep WC and WC⊥ distinct.

Q5(a), 2022/23 and 2023/24; Q5(c)–(f), 2025/26

Priority 5. Legacy Backup

FrontBackEvidence
State the older-paper backup ideas that no longer recur in the current format.

Hamming distance on An is the number of positions at which x and y differ. It is a metric: nonnegative, zero exactly when x = y, symmetric, and coordinatewise triangle inequality.

For ISBN-10 digits d1…d10, use 10d1 + 9d2 + … + d10 ≡ 0 (mod 11), using X for 10 if needed. For ISBN-13, use alternating weights 1, 3, …, 1 on the 13 digits and require the sum ≡ 0 (mod 10). A unit u in a Euclidean domain has uv = 1 for some v; U(R) is a multiplicative group. In F[x], units are exactly nonzero constants since deg(fg) = deg f + deg g.
