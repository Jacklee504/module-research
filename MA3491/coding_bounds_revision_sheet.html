Coding Bounds and Block-Code Parameters

Turn a code question into q, n, M and d before choosing a bound.

Rapid refresher

Core ruleExam distinction
t=floor((d-1)/2). Sphere packing: M sum_{i=0}^t C(n,i)(q-1)^i <= q^n. Singleton: M <= qn-d+1.Perfect means equality in sphere packing; MDS means equality in Singleton.

Medium/hard adapted practice

Paper family: Bounds are Q1 in every 2018/19-2024/25 paper; sphere packing and Singleton are both explicit in 2022/23-2024/25.

(a) For a ternary code n=8,d=3, give both upper bounds. [8 marks]

Question demand: apply the definition/calculation with working. Quickest route: Set t=1. Calculate the ball volume 1+8(2)=17, then apply each formula.

Mark-aware answer: Sphere packing gives M <= floor(38/17)=385. Singleton gives M <= 36=729. The sphere-packing bound is tighter here.

Trap: Do not use d instead of t in the ball radius.

(b) Prove the Singleton bound for a q-ary (n,M,d) code. [6 marks]

Question demand: Delete d-1 fixed coordinates and use injectivity of the remaining words. Quickest route: Delete d-1 fixed coordinates and use injectivity of the remaining words.

Mark-aware answer: Puncture any d-1 coordinates. If two codewords became equal, their original distance would be at most d-1, contradiction. Thus M distinct shortened words lie in qn-d+1 possibilities, so M<=qn-d+1.

Trap: Do not delete d coordinates; injectivity may then fail.

(c) Decide whether a code meeting the sphere-packing bound is perfect. [4 marks]

Question demand: State the equality criterion and radius t. Quickest route: State the equality criterion and radius t.

Mark-aware answer: A code is perfect exactly when radius-t Hamming balls about its codewords are disjoint and cover the entire ambient space, equivalently equality holds in the sphere-packing bound.

Trap: MDS refers to Singleton equality, not sphere-packing equality.
