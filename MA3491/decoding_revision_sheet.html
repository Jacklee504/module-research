MA3491 Topic Guide

Syndromes, Cosets and Decoding

The syndrome depends only on the error, so it identifies a chosen coset leader.

Purpose

Decoding turns a received word into the nearest plausible codeword.Exam use: Matrix orientation, mod-field arithmetic, syndrome-to-leader map, correction and zero-syndrome verification are shown.

Question plan

  1. Compute s=HrT.
  2. Match s to a syndrome-table error leader e.
  3. Output c=r−e (same as r+e in binary).
  4. State the correction guarantee from d.
  5. Question interpretation: For decode, compute syndrome first, map it to a declared coset leader, correct, then verify the corrected word is a codeword.

Formulas

If r=c+e and HcT=0, then HrT=HeT. Unique correction is guaranteed up to t=⌊(d−1)/2⌋ errors.Rapid recall: s(r)=Hr^T=He^T because Hc^T=0; equal syndromes identify a coset, and standard-array decoding chooses a minimum-weight representative when one is unique.

Derivation

Linearity gives H(c+e)T=HcT+HeT=HeT. Each coset e+C has one syndrome; choosing its lowest-weight representative implements nearest-neighbour decoding.Exam workflow: Label columns of H by bit position, calculate mod 2, flip the selected position, and recompute syndrome zero as an audit.

Worked example

For H=[1 1 1] over F2, r=111 has syndrome 1. Choose leader e=001, giving c=110, a codeword. This table has several weight-one leaders with the same syndrome, so this particular code does not uniquely correct every one-bit error.

Medium/hard paper-style synthesis

Use H with columns 001,010,011,100,101,110,111 and receive r=1011010. XOR columns 1,3,4,6 gives 001 xor 011 xor 100 xor 110=000, so r is already a codeword. If r'=1011011, its syndrome is column 7=111; under single-error decoding flip bit 7 to recover r. The conclusion depends on the at-most-one-error assumption.

Graduated exam bridge

1. With the above H, find the syndrome of 101. Check: 0, so it is a codeword.

2. Build a syndrome table for a given H with distinct nonzero columns and decode a received word. Check: explain why column i is the syndrome of an error in position i.

Hard paper-style synthesis

Paper-style synthesis: if syndrome equals column 3 but the channel may introduce two errors, explain the ambiguity. Check e3 and any two-error pattern whose two columns XOR to column 3 share the syndrome; nearest-neighbour correction is a decoding choice, not proof of the true error.

Mistakes

  • Subtracting the syndrome from r instead of an error vector.
  • Assuming any code can correct one error.
  • Not specifying a leader when syndromes collide.
  • Recovery rule: A nonzero syndrome identifies a coset, not automatically the physical error unless the leader assumption is justified.

Checklist

  • I can compute H rT.
  • I distinguish syndrome from error.
  • I state the t-error guarantee.
  • Final 60-second audit: Matrix orientation, mod-field arithmetic, syndrome-to-leader map, correction and zero-syndrome verification are shown.
