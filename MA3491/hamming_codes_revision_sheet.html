MA3491 Topic Guide

Binary Hamming Codes

Distinct nonzero columns in H make each single-bit error announce its position.

Purpose

Hamming codes are a compact construction of perfect single-error-correcting binary codes.Exam use: Parameters, column convention, syndrome arithmetic, flipped bit, parity recheck and perfect-code count appear.

Question plan

  1. Set n=2m−1 and k=n−m.
  2. Make H whose columns are every nonzero m-bit vector once.
  3. Use C=ker H; row-reduce H to derive a G if requested.
  4. Decode a one-error word from its syndrome column.
  5. Question interpretation: For construct, use each nonzero m-bit column once; for decode, read the syndrome as a column label under the stated ordering; for perfect, verify the sphere count.

Formulas

Binary Hamming code: [2m−1, 2m−1−m, 3]. It has 2n−m words and t=1; sphere packing is an equality.Rapid recall: Binary Hamming codes have [2^m-1,2^m-1-m,3]; distinct nonzero H columns correct one error, and 2^k(1+n)=2^n.

Derivation

No column of H is zero and no two columns agree, so a nonzero codeword cannot have weight 1 or 2; d≥3. Every nonzero syndrome is a column, so every one-bit error has a distinct syndrome. Counting gives 2k(1+n)=2n, hence perfect and d=3.Exam workflow: Freeze column order, derive G in systematic form if requested, calculate syndrome by XOR, correct one bit and check Hc^T=0.

Worked example

For m=3, n=7. Take H with columns 001,010,011,100,101,110,111. A syndrome 101 points to position 5, so flip bit 5.

Medium/hard paper-style synthesis

For m=3 choose H columns 001,010,011,100,101,110,111. If r=1101000, syndrome is 001 xor 010 xor 100=111, so flip bit 7 to get c=1101001. Recheck: 001 xor 010 xor 100 xor 111=000. The [7,4,3] code has 16 codewords and ball size 8, giving 16*8=128=2^7, hence perfect.

Graduated exam bridge

1. Give [n,k,d] for m=4. Check: [15,11,3].

2. Construct H for m=3, prove it corrects one error, and verify the sphere-packing equality. Check: include both distinct-column and counting arguments.

Hard paper-style synthesis

Paper-style synthesis: prove d_min=3 from the columns of H. Check no zero column rules out weight 1 and no repeated columns rules out weight 2; columns 001 xor 010 xor 011=0 exhibit a weight-3 codeword.

Mistakes

  • Including the zero column.
  • Using n=2m rather than 2m−1.
  • Reading syndrome bits in a different order from H.
  • Recovery rule: The binary value of a syndrome names a bit only if the column ordering uses that convention; otherwise locate the matching column directly.

Checklist

  • I can build H.
  • I can recover n and k.
  • I can explain perfect single-error correction.
  • Final 60-second audit: Parameters, column convention, syndrome arithmetic, flipped bit, parity recheck and perfect-code count appear.
