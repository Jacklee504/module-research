Binary Hamming Codes

Distinct nonzero columns in H make each single-bit error announce its position.

Rapid refresher

Core ruleExam distinction
Ham(r,q) has parity-check columns one representative of each 1-D subspace of Fq^r. Binary length 2^r-1, dimension n-r, d=3.For one error ae_j, syndrome is a times column j; locate j and correct it.

Medium/hard adapted practice

Paper family: Hamming codes are Q4 in every 2018/19-2024/25 paper, including construction, single-error decoding and perfection in 2024/25.

(a) Construct H for binary Ham(3,2) and decode a nonzero syndrome. [8 marks]

Question demand: apply the definition/calculation with working. Quickest route: List all seven nonzero 3-bit columns. Match syndrome to its column and flip that coordinate.

Mark-aware answer: H has each nonzero vector in F2^3 once. If s equals column j, the received word has a single error in position j; flip that bit and recheck syndrome 0. It corrects one error because d=3.

Trap: Do not include the zero column or duplicate a nonzero column.

(b) State the parameters of Ham(r,q) and prove its minimum distance is 3. [6 marks]

Question demand: Use one representative per 1-D subspace for length; rule out weights 1 and 2 from H columns; exhibit/argue a dependent triple. Quickest route: Use one representative per 1-D subspace for length; rule out weights 1 and 2 from H columns; exhibit/argue a dependent triple.

Mark-aware answer: The length is n=(qr-1)/(q-1), dimension n-r, and d=3. No codeword has weight 1 because no H column is zero; none has weight 2 because no two columns are scalar multiples. Three suitable projective columns are dependent, giving a weight-3 codeword, hence d=3.

Trap: For q>2, columns are projective representatives, not all nonzero vectors.

(c) Show why a Hamming code is perfect. [4 marks]

Question demand: Use t=1 and count radius-one balls against qn. Quickest route: Use t=1 and count radius-one balls against qn.

Mark-aware answer: Each radius-one ball has 1+n(q-1)=qr words. With qn-r codewords, their total is qn. Since d=3 makes balls disjoint, they cover the space and the code is perfect.

Trap: d=3 corrects one error; it does not correct two.
