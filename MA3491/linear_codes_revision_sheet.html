MA3491 Topic Guide

Linear Codes: G, H and Minimum Distance

Use the generator matrix to create codewords and the parity-check matrix to test them.

Purpose

Linear-code questions link matrix algebra over Fq to size, membership and error detection.Exam use: Field, dimensions, convention, generated words, parity orthogonality and distance/error capability are consistent.

Question plan

  1. Row-reduce G and read k=rank(G).
  2. Put G in standard form [Ik|A] where useful.
  3. Use H=[−AT|In−k] so GHT=0.
  4. Enumerate nonzero codewords for small k to find d.
  5. Question interpretation: For encode use uG; for membership or decode use Hc^T; for distance exploit linearity so d_min is minimum nonzero codeword weight.

Formulas

C={uG:u∈Fq k}; |C|=qk. A word v lies in C exactly when HvT=0. For linear C, d=min{wt(c):c∈C,c≠0}.Rapid recall: An [n,k,d]_q linear code has q^k words; GH^T=0; in systematic form G=[I_k|P], H=[-P^T|I_{n-k}].

Derivation

Distinct messages give distinct uG when G has rank k, so there are qk words. Orthogonality GHT=0 makes every generated word satisfy the checks. Difference of two codewords is a codeword, so minimum pairwise distance is minimum nonzero weight.Exam workflow: State row-vector convention, perform all arithmetic in F_q, enumerate only independent messages if small, and cross-check every codeword with H.

Worked example

Over F2, G=[1 0 1; 0 1 1]. Then C={000,101,011,110}, so k=2, d=2. Here A=[1;1], hence H=[1 1 1]; each codeword has zero syndrome.

Medium/hard paper-style synthesis

Over F_2 take G=[[1,0,1,1],[0,1,1,0]]. Messages 00,10,01,11 give 0000,1011,0110,1101 with weights 0,3,2,3, so d_min=2. With P=[[1,1],[1,0]], H=[P^T|I_2]=[[1,1,1,0],[1,0,0,1]], and GH^T=0.

Graduated exam bridge

1. Test whether 111 is in the example code. Check: H·111T=1 mod 2, so no.

2. Given a standard-form G over F3, construct H and find d with a clear finite enumeration. Check: use −AT, not simply AT.

Hard paper-style synthesis

Paper-style synthesis: how many errors can this code detect and correct? Check d=2 gives detection up to d-1=1 and guaranteed correction floor((d-1)/2)=0; a nonzero syndrome detects one error but cannot uniquely correct every one.

Mistakes

  • Doing ordinary real-number arithmetic.
  • Counting rows of a non-full-rank G as k.
  • Calling the least row weight d without checking combinations.
  • Recovery rule: Minimum distance includes pairs of distinct codewords; only linearity permits replacing that search by minimum nonzero weight.

Checklist

  • I can form H and check GHT=0.
  • I know |C|.
  • I can justify d for a linear code.
  • Final 60-second audit: Field, dimensions, convention, generated words, parity orthogonality and distance/error capability are consistent.

Past-paper note

Generator/check matrices, standard form, membership and minimum distance are among the most stable 2018–2025 themes.
