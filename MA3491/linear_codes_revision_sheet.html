Medium/hard adapted practice

Paper family: Generator/check matrices, standard form and minimum distance are Q3 every year 2018/19-2024/25.

(a) For G=[I2|A] over F3, explain how to construct H and test a received word r. [8 marks]

Question demand: apply the definition/calculation with working. Quickest route: Use H=[-A^T|I], then compute rH^T; zero iff r is a codeword.

Mark-aware answer: The rows of G span C. Since GH^T=0, every codeword has syndrome zero. Thus r belongs to C exactly when rH^T=0; row-reduce G first if it is not systematic.

Trap: Do not use ordinary real row reduction; reduce mod 3.

(b) Show how to find minimum distance from a generator matrix of a linear code. [6 marks]

Question demand: Enumerate nonzero uG (or reason by row combinations) and take smallest Hamming weight. Quickest route: Enumerate nonzero uG (or reason by row combinations) and take smallest Hamming weight.

Mark-aware answer: Because C is linear, d(C) equals the minimum nonzero codeword weight: d(c,c')=wt(c-c') and c-c' is a nonzero codeword. Generate all nonzero uG over the stated field and choose the least weight.

Trap: Minimum distance is not the smallest row weight unless all combinations were considered.

(c) Test whether a code is self-dual from dimensions and orthogonality. [4 marks]

Question demand: Check GHT=0 or row orthogonality, then compare dimensions. Quickest route: Check GHT=0 or row orthogonality, then compare dimensions.

Mark-aware answer: For C subset C-perp, every generator row is orthogonal to every codeword. If additionally dim C=n/2, the inclusion and equal dimensions imply C=C-perp, so C is self-dual.

Trap: Orthogonality alone gives self-orthogonal, not necessarily self-dual.
