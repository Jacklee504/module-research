MA3491 Topic Guide

Arithmetic in Finite Fields

Add coefficients mod p; multiply polynomials; reduce only using the defining relation.

Purpose

Accurate field arithmetic underpins inverse, order and coding calculations.Exam use: Base field, defining relation, expansion, every reduction and multiplication-back check are visible.

Question plan

  1. Write the modulus relation f(α)=0.
  2. Add/multiply in Fp[x].
  3. Reduce powers of α and coefficients mod p.
  4. For an inverse, use Euclid or solve a product equation.
  5. Question interpretation: For add, reduce coefficients; for multiply, expand then reduce by the defining polynomial; for inverse, solve with extended Euclid in F_p[x].

Formulas

In Fq, a≠0 implies aq−1=1, hence a−1=aq−2. The nonzero elements form a cyclic group of order q−1.Rapid recall: In F_p[x]/(f), nonzero classes form a field only when f is irreducible; equality means polynomial congruence modulo f, not evaluation at a number.

Derivation

Multiplication by a nonzero a permutes Fq ×; multiplying every element gives a·P=P, so aq−1=1. In a quotient, replace each occurrence of αm from f(α)=0.Exam workflow: Reduce coefficients after each operation, replace the leading power using f(x)=0, and verify an inverse by multiplying back to 1.

Worked example

In F4 with α2+α+1=0, α2=α+1. Then (α+1)α=α2+α=1, so (α+1)−1=α.

Medium/hard paper-style synthesis

In F_2[x]/(x^3+x+1), let alpha be the class of x, so alpha^3=alpha+1. Compute (alpha^2+1)(alpha^2+alpha)=alpha^4+alpha^3+alpha^2+alpha. Since alpha^4=alpha(alpha+1)=alpha^2+alpha and alpha^3=alpha+1, the sum is (alpha^2+alpha)+(alpha+1)+alpha^2+alpha=alpha+1.

Graduated exam bridge

1. In this F4, calculate (α+1)2. Check: α2+1=α.

2. In F8 with α3=α+1, find an inverse of α2+1. Check: use the Euclidean algorithm or test the seven nonzero elements and show the reduction.

Hard paper-style synthesis

Paper-style synthesis: find (alpha+1)^{-1}. Check (alpha+1)(alpha^2+alpha)=alpha^3+alpha=1 using alpha^3=alpha+1, so the inverse is alpha^2+alpha.

Mistakes

  • Treating α as an integer.
  • Reducing with the wrong sign in odd characteristic.
  • Using Fermat’s exponent p−2 instead of q−2.
  • Recovery rule: Over F_2, subtraction equals addition; do not carry signs or integer coefficients into the reduced polynomial.
