Cryptography - Most Asked Exam Questions

Exam-question families from the supplied CS402 papers, preserving recurring subpart structure, marks, proof requirements, constructions, and calculation variants.

How To Use This Document

Source scope: all supplied CS402 papers were checked: 2025/26, 2024/25, 2023/24, 2022/23, 2021/22, 2018/19, and 2017/18.

Current format: 2018/19 onward uses answer all four questions, 25 marks each, with workings required. The latest three current-format papers, 2025/26, 2024/25, and 2023/24, are treated as the primary evidence. The 2017/18 ten-question paper is a legacy backup section.

2025/26 update: the new paper strengthens predictability. Q1 is still classical ciphers, Q2 is perfect security plus LFSRs, Q3 is RSA plus Fermat testing, and Q4 is cyclic groups, Diffie-Hellman, ElGamal, and elliptic curves. The main weighting change is that LFSRs rise to 15 marks in Q2 and elliptic-curve group law/order-2 points rise to 10 marks in Q4.

PDF verification: rendered pages were inspected as well as extracted text. This matters for symbols such as Zn*, the space symbol _ = 26, matrix layout, inequalities, and mark allocations.

Priority 1 - Classical Ciphers And Key Spaces

Frequency: 6/6 current-format papers. In the latest three papers it is the whole of Q1: 75 marks total.

Appears as:

  • 2025/26 Q1(a) - shift cipher over 27-letter alphabet; plaintext symbol O corresponds to ciphertext symbol X; determine first word of plaintext [7].
  • 2025/26 Q1(b) - Hill cipher over Z27, ciphertext AZMZ, key [[5,7],[4,7]]; find plaintext [9].
  • 2025/26 Q1(c) - decide whether [[4,7],[2,17]] can be used as a Hill key over Z27, with justification [4].
  • 2025/26 Q1(d) - 1-dimensional affine cipher over Z150; count keys [5].
  • 2024/25 Q1(a) - shift cipher over 27-letter alphabet; known `TREASURE -> WUHDVXUH`; decode `EULOOLDQWCZRUN` [5].
  • 2024/25 Q1(b) - Hill cipher over `Z_27`, ciphertext `LPDG`, key `[[3,7],[2,5]]`; find plaintext [10].
  • 2024/25 Q1(c) - state Kerckhoff's principle [5].
  • 2024/25 Q1(d) - 1-dimensional affine cipher over `Z_900`; count keys [5].
  • 2023/24 Q1(a) - shift cipher with plaintext `_` corresponding to ciphertext `Y`; decode `JCRYGRY_C` [5].
  • 2023/24 Q1(b) - Hill cipher over `Z_27`, ciphertext `ZLV_`, key `[[3,1],[1,1]]`; find plaintext [10].
  • 2023/24 Q1(c) - describe Vigenere and encrypt `BEATLES` with key `FAB` [10].
  • 2022/23 Q1(a) - shift cipher with plaintext `_` corresponding to ciphertext `E`; determine first word of `RFCTEKTWEXFREQTQ` [5].
  • 2022/23 Q1(b) - Hill cipher over `Z_27`, ciphertext `GM_L`, key `[[5,1],[1,1]]`; find plaintext [10].
  • 2022/23 Q1(c) - define brute force attack and feasible scenario [5].
  • 2022/23 Q1(d) - affine cipher over `Z_360`; count keys, give a number not a formula [5].

Distinct variants to retain:

  • Shift decoding: known plaintext/ciphertext symbol; sometimes asks complete plaintext, sometimes first word only. Work in Z27 when _ = 26 is supplied. 2025/26 has shift 9 and first word FREEDOM.
  • Hill decryption: compute K-1 mod 27 and multiply ciphertext pairs. The plaintexts checked are COOL, EXAM, HELP, MAYO, and FINE for 2025/26, 2024/25, 2023/24, 2022/23, and 2021/22.
  • Hill key validity: new in the latest paper as a separate subpart. A Hill key over Zn is valid exactly when its determinant is a unit modulo n. For 2025/26, det([[4,7],[2,17]]) = 54 == 0 mod 27, so it is not valid.
  • Affine key counting: 1-dimensional over Zn has phi(n)n keys. Latest/counting values: Z150 -> 6000, Z900 -> 216000, Z360 -> 34560, Z450 -> 54000, Z55 -> 2200.
  • Affine key solving: 2018/19 asks to solve `(a,b)` from `E -> T` and `S -> V`; answer `(a,b)=(4,3)` over `Z_27`.
  • Vigenere: 2023/24 asks description plus actual encryption; `BEATLES` with key `FAB` gives `GEBYLFX`.
  • Short theory: Kerckhoff's principle and brute force attacks recur as 5-mark conceptual subparts.

Complete answer frame: Always state the alphabet and modulus first. For shift questions, compute the shift from the known mapping and subtract it from each ciphertext symbol. For Hill decryption, show determinant, modular inverse of determinant, inverse matrix, pairwise multiplication, and final text. For Hill key validity, show whether the determinant is invertible modulo 27. For affine key counts, state that a must be a unit and b is arbitrary, so the count is phi(n)n. For Kerckhoff, say security should survive public knowledge of the system except the secret key.

Priority 2 - Perfect Security, Symmetric Cryptosystems, And Shannon

Frequency: 6/6 current-format papers. The latest three papers still put this at the start of Q2, but 2025/26 moves the remaining Q2 marks into LFSRs.

  • 2025/26 Q2(a)(i) - briefly describe what a perfectly secure symmetric cryptosystem is [3].
  • 2025/26 Q2(a)(ii) - state without proof Shannon's theorem on perfectly secure cryptosystems [4].
  • 2025/26 Q2(a)(iii) - do perfectly secure cryptosystems exist; provide brief justification [3].
  • 2024/25 Q2(a) - state without proof Shannon's theorem on perfectly secure cryptosystems [5].
  • 2024/25 Q2(b) - for finite non-empty `P,C,K` with perfect security, show `|K| >= |C| >= |P|` [10].
  • 2023/24 Q2(a) - formally define a symmetric cryptosystem [5].
  • 2023/24 Q2(b) - describe perfectly secure symmetric cryptosystem; do they exist; justify [5].
  • 2023/24 Q2(c) - state and prove Shannon's theorem on perfect security [15].
  • 2022/23 Q2(a)-(c) - same definition/perfect-security/Shannon theorem pattern [25].
  • 2021/22 Q2(a)-(b) - symmetric cryptosystem and perfect security definitions [10].
  • 2018/19 Q2(a) - state Shannon's theorem without proof [5].

Distinct variants to retain:

  • Definition card: `P,C,K`, maps `e_k: P -> C`, `d_k: C -> P`, and `d_k(e_k(p))=p`.
  • Perfect security definition: observing ciphertext does not change plaintext probabilities.
  • Existence/example: one-time pad with uniformly random one-use key of message length.
  • Shannon statement: inequality and/or equality-characterisation form depending on wording.
  • Proof: must use perfect-security probabilities and counting/injectivity; do not write "by Shannon" as the proof.

Proof strategy: First prove `|C| >= |P|`: for each key, decryptability makes `e_k: P -> C` injective. Then prove `|K| >= |C|`: fix a plaintext `p` with positive probability. For every ciphertext `c` with positive probability, perfect security implies `p` remains possible after observing `c`, so some key sends `p` to `c`. A fixed key sends fixed `p` to only one ciphertext, so distinct ciphertexts require at least `|C|` keys. State all positivity and finiteness hypotheses explicitly.

Priority 3 - RSA And Public-Key Cryptography

Frequency: 6/6 current-format papers. RSA key generation appears every year; validity/security/encryption variants rotate.

  • 2025/26 Q3(a) - describe RSA key generation, encryption, and decryption [5].
  • 2025/26 Q3(b) - decide whether (187,7), (289,15), (143,3) are valid RSA keys, with justification [6].
  • 2025/26 Q3(c) - encrypt m=3 with public key (187,7) [4].
  • 2025/26 Q3(d) - explain why efficient integer factorisation would render RSA insecure [5].
  • 2024/25 Q3(a) - describe RSA key generation, encryption, and decryption [5].
  • 2024/25 Q3(b) - decide whether `(299,17)`, `(323,9)`, `(385,55)` are valid RSA keys, with justification [6].
  • 2024/25 Q3(c) - encrypt `m=23` with public key `(77,17)` [5].
  • 2023/24 Q3(a) - compare symmetric and public-key cryptosystems with example, advantage, disadvantage [5].
  • 2023/24 Q3(b) - describe RSA key generation, encryption, and decryption [5].
  • 2023/24 Q3(d) - evaluate claim that efficient primality testing would break RSA [5].
  • 2022/23 Q3(a) - advantages and disadvantages of symmetric and public-key cryptosystems [4].
  • 2022/23 Q3(b) - describe RSA [5].
  • 2022/23 Q3(c) - explain why `(187,15)`, `(289,13)`, `(385,77)` are not valid RSA keys [6].
  • 2021/22 Q3(c)-(d) - invalid RSA keys and primality-testing claim [11].
  • 2018/19 Q3(b),(d) - RSA key generation and encryption of `m=23` under `(77,17)` [15].

Complete answer frame: For RSA description, choose distinct primes p,q, set n=pq, compute phi(n), choose e coprime to phi(n), and compute d=e-1 mod phi(n). Encrypt by c=me mod n; decrypt by m=cd mod n. For validity, factor n, check it is a product of two distinct primes, compute phi(n), and check gcd(e,phi(n))=1. 2025/26 validity answers: (187,7) valid, (289,15) invalid because 289=172, and (143,3) invalid because gcd(3,120)=3. Repeated encryption answers include 37 mod 187 = 130 and 2317 mod 77 = 67. For the security claim, say yes for efficient factorisation: factoring n reveals p,q, hence phi(n), hence d.

Priority 4 - Number Theory, Primality, And Cyclic Groups

Frequency: 6/6 current-format papers. This family is spread across Q3/Q4 and often supports RSA/protocol calculations.

  • 2025/26 Q3(e) - describe the Fermat primality test [5].
  • 2025/26 Q4(a) - define cyclic group and state Gauss's characterisation of those n >= 1 for which Zn* is cyclic [5].
  • 2024/25 Q3(d) - define pseudoprime and Carmichael number [4].
  • 2024/25 Q4(a) - describe Fermat's primality test [5].
  • 2024/25 Q4(b) - describe fast exponentiation [5].
  • 2023/24 Q3(c) - describe fast exponentiation [5].
  • 2023/24 Q3(e) - Carmichael number 1105 and Fermat test; agree with Bob or Alice [5].
  • 2023/24 Q4(c) - define cyclic group, state Gauss's characterisation, decide whether `Z_315^*` is cyclic [5].
  • 2022/23 Q4(a) - same cyclic/Gauss pattern for `Z_169^*` [5].
  • 2022/23 Q4(b) - fast exponentiation [5].
  • 2021/22 Q4(a) - same cyclic/Gauss pattern for `Z_242^*` [5].
  • 2018/19 Q4(a)-(c) - Euler totient theorem, Fermat test, Carmichael numbers [15].

Complete answer frame: Fast exponentiation needs binary expansion/repeated squaring and reduction modulo `n` after each multiplication. Fermat's test must mention the `gcd(a,n)>1` early composite case and that passing a base is not a proof of primality. A pseudoprime is composite but passes for a base. A Carmichael number is composite and passes for every coprime base; it can still be caught if the chosen base shares a factor with it. For cyclic groups, quote Gauss exactly: `Z_n^*` is cyclic iff `n=1,2,4,p^k,2p^k` for odd prime `p`.

Priority 5 - LFSRs And Stream Ciphers

Frequency: 6/6 current-format papers. 2025/26 makes this a larger Q2 priority: definition, connection polynomial, and a 9-mark least-period calculation.

  • 2025/26 Q2(b)(i) - explain what is meant by an LFSR of length L [3].
  • 2025/26 Q2(b)(ii) - define the connection polynomial of an LFSR [3].
  • 2025/26 Q2(c) - length-3 LFSR with C(X)=1+X2+X3, initial values s0=1, s1=0, s2=1; determine least period [9].
  • 2024/25 Q2(d) - explain what is meant by a linear feedback shift register of length `L` [5].
  • 2023/24 Q4(a) - length-2 LFSR known plaintext/ciphertext; find connection polynomial [5].
  • 2023/24 Q4(b) - length-4 LFSR with `C(X)=1+X+X^2+X^4`; initial values `s_0=s_2=1`, `s_1=s_3=0`; least period [5].
  • 2022/23 Q3(d)-(e) - same known-stream and period variants [10].
  • 2021/22 Q2(c) - define LFSR, discuss whether connection polynomial determines it, give singular length-3 example [10].
  • 2021/22 Q2(d) - same length-4 period calculation [5].
  • 2018/19 Q2(c)-(d) - define LFSR and period for length-3 `C(X)=1+X+X^3` [15].

Complete answer frame: Define length, state bits, recurrence, and connection polynomial. With C(X)=c0+c1X+...+cLXL and c0=cL=1, use sn+L=c0sn+c1sn+1+...+cL-1sn+L-1 over Z2. For known-stream questions, recover keystream by si=xi+yi mod 2, then fit the recurrence. For period questions, generate full states until the same L-bit state reappears. The 2025/26 example C(X)=1+X2+X3 uses sn+3=sn+sn+2 and has least period 7. The repeated 2021/22-2023/24 length-4 example also has least period 7.

  • 2024/25 Q4(c) - Diffie-Hellman in `Z_61^*`, generator `2`, secrets `a=5`, `b=7`; shared key [8].
  • 2024/25 Q4(d) - describe ElGamal key generation, encryption, decryption [6].
  • 2023/24 Q4(d) - Diffie-Hellman in `Z_29^*`, generator `2`, secrets `a=5`, `b=4`; shared key [5].
  • 2022/23 Q4(c) - describe ElGamal [5].
  • 2022/23 Q4(d) - Diffie-Hellman in `Z_59^*`, generator `2`, secrets `a=3`, `b=4`; shared key [5].
  • 2021/22 Q4(c)-(d) - ElGamal plus the same `Z_59^*` Diffie-Hellman calculation [10].
  • 2018/19 Q3(c) - Diffie-Hellman in `Z_25^*`, generator `2`, secrets `a=6`, `b=3` [5].

Complete answer frame: In Diffie-Hellman, the shared key is gab in the stated group. Latest answers: 815 mod 121 = 54, 235 mod 61 = 29, and 220 mod 29 = 23. For ElGamal, give the actual maps: public key (G,g,h=gb), ciphertext (c1,c2)=(gr, m hr), decryption m=c2(c1b)-1.

Priority 7 - Elliptic Curves

Frequency: 6/6 current-format papers. The latest paper raises this to 10 marks and combines the group law with real-curve order-2 points.

  • 2025/26 Q4(d)(i) - for a real elliptic curve y2=x3+ax+b, describe geometrically or algebraically the addition operation making E an abelian group [5].
  • 2025/26 Q4(d)(ii) - for a=-1, b=0, find all points P with P+P=O [5].
  • 2024/25 Q4(e) - curve `y^2=x^3+2x+3` over `Z_7`; determine `E(Z_7)` including `O`; find all order-2 points [6].
  • 2023/24 Q4(e) - real curve `y^2=x^3+3x`; find all `P` with `P+P=O`; find one `Q` with `Q+Q != O` [5].
  • 2022/23 Q4(e) - curve `y^2=x^3+2x^2+2x` over `Z_5`; determine points and identify an order-2 element [5].
  • 2021/22 Q4(e) - same real-curve order-2/example-point question [5].
  • 2018/19 Q4(d) - describe elliptic-curve addition over `Q` geometrically or algebraically [10].

Complete answer frame: For finite fields, test every x, compute the right-hand side, list all square roots y, and include O. Order-2 points have y=0, because (x,y)=-(x,y)=(x,-y). For the 2025/26 real curve y2=x3-x=x(x-1)(x+1), all points with P+P=O are O, (-1,0), (0,0), and (1,0). 2024/25 gives E(Z7)={O,(2,1),(2,6),(3,1),(3,6),(6,0)} and order-2 point (6,0). 2022/23 gives E(Z5)={O,(0,0),(1,0),(2,0),(3,1),(3,4),(4,2),(4,3)} with order-2 points (0,0),(1,0),(2,0). For the real curve y2=x3+3x, the non-identity order-2 point is (0,0), and (1,2) is a valid point with non-zero double.
