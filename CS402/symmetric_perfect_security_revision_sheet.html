Rapid refresher

Core ruleExam distinction
A symmetric cryptosystem is (P,C,K,E,D) with Dk(Ek(p))=p. Perfect secrecy means P(P=p|C=c)=P(P=p). An LFSR recurrence is over F2.One-time pad is perfectly secret with uniform independent key of message length; stream ciphers combine a keystream, block ciphers transform fixed blocks.

Medium/hard adapted practice

Paper family: Q2 in 2018/19-2024/25 repeatedly tests cryptosystem/perfect-security definitions, Shannon's theorem, stream/block ciphers and LFSR period or recovery.

(a) State Shannon's key-space condition and use it to assess a proposed perfectly secure system. [8 marks]

Question demand: apply the definition/calculation with working. Quickest route: Define the conditional-probability criterion; then compare |K|, |C| and |P| and state the missing distribution assumption.

Mark-aware answer: For perfect secrecy with every ciphertext possible, Shannon gives |K| >= |C| >= |P|. The OTP attains this when each key is uniform and used once: for any c and p exactly one key k=c-p maps p to c, with equal probability.

Trap: A long key alone is not enough: reuse or a non-uniform key breaks the OTP argument.

(b) An LFSR has connection polynomial 1+X+X3 and initial bits 001. Generate enough terms to find its least period. [6 marks]

Question demand: Write the recurrence from the polynomial, tabulate states, and stop only when the complete initial state reappears. Quickest route: Write the recurrence from the polynomial, tabulate states, and stop only when the complete initial state reappears.

Mark-aware answer: Use si+3=si+1+si over F2. Record successive 3-bit states; the least period is the first return to 001, not the first repeated output bit.

Trap: A repeated single bit does not establish an LFSR period.

(c) Contrast a stream cipher with a block cipher in one operational use case. [4 marks]

Question demand: State input unit, keystream/block transformation, then one suitable use and limitation. Quickest route: State input unit, keystream/block transformation, then one suitable use and limitation.

Mark-aware answer: A stream cipher combines plaintext with a keystream symbol by symbol and suits low-latency streams, but keystream reuse is dangerous. A block cipher transforms fixed-size blocks and is normally used with a mode of operation for longer messages.

Trap: Do not call a mode of operation itself a block cipher.
