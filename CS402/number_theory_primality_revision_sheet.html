Core ruleExam distinction

Medium/hard adapted practice

Paper family: Fast exponentiation, cyclic unit groups, Fermat testing and Carmichael reasoning recur in Q4 of 2021/22, 2022/23, 2023/24 and 2024/25.

(a) Use Fermat's test to analyse a composite n and explain the Carmichael caveat. [8 marks]

Question demand: apply the definition/calculation with working. Quickest route: First calculate gcd(a,n). If it is >1, n is composite; otherwise calculate an-1 by squaring and state what the result establishes.

Mark-aware answer: If gcd(a,n)>1, a is a witness to compositeness. If gcd=1 and an-1 is not 1 mod n, it is also a witness. Equality only means this base passes; for Carmichael n every coprime base passes, but non-coprime choices may still reveal a factor.

Trap: Do not conclude prime from one successful Fermat congruence.

(b) Compute 713 mod 19 using fast exponentiation. [6 marks]

Question demand: Square 7 repeatedly and select powers from 13=8+4+1. Quickest route: Square 7 repeatedly and select powers from 13=8+4+1.

Mark-aware answer: 72=11, 74=7, 78=11 mod 19. Hence 713=78747=11·7·7=7 mod 19.

Trap: Do not multiply thirteen copies of 7 or forget a reduction.

(c) State Gauss's criterion for when Z*n is cyclic. [4 marks]

Question demand: Give the complete form, then use it only for the requested n. Quickest route: Give the complete form, then use it only for the requested n.

Mark-aware answer: Z*n is cyclic exactly when n=1,2,4,pk, or 2pk for an odd prime p and k>=1. Factor n first before applying the list.

Trap: Do not infer cyclicity merely because n is prime-like or odd.
