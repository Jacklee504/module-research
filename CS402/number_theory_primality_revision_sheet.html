Number Theory and Primality

Make modular calculations auditable and distinguish a test from a proof.

Purpose

Number theory supplies the engine for RSA and protocols. The high-value habit is to write a short chain of justified congruences: factor/exponent decomposition, repeated squaring, reductions, and a clear conclusion about what the result does—or does not—prove.Exam use: Hypotheses, exponent decomposition, modular reductions and the exact strength of the conclusion are explicit.

What the question asks, and plan

  1. State modulus and relevant theorem assumptions, especially coprimality.
  2. For aᵇ mod n, make a repeated-squaring table and combine only needed powers.
  3. For primality, apply the named test exactly and label its conclusion.
  4. For a counterexample, show the congruence then define pseudoprime/Carmichael accurately.
  5. Question interpretation: For compute, expose the binary exponent decomposition; for test, state whether the outcome proves composite or only fails to prove prime; for inverse, show extended Euclid.

Terms and formulas

  • Congruence: a≡b mod n iff n divides a−b.
  • Inverse: a⁻¹ mod n exists iff gcd(a,n)=1; find it by extended Euclid.
  • Fermat's little theorem: prime p and p∤a imply a^(p−1)≡1 mod p.
  • Euler: coprime a,n implies a^φ(n)≡1 mod n.
  • Fermat pseudoprime to base a: composite n with a^(n−1)≡1 mod n. Carmichael: composite passing this for every base coprime to it.
  • Rapid recall: a has an inverse mod n exactly when gcd(a,n)=1; Fermat and Euler reduce powers only under their hypotheses, while a Fermat pass is not a primality proof.

Derivation and method

Repeated squaring rewrites an exponent in binary. To calculate 7¹³ mod 15, build powers 7, 7², 7⁴, 7⁸ and multiply those for 13=8+4+1. A Fermat pass cannot prove a number prime because composites can be pseudoprimes; a failed congruence does prove compositeness. This one-way conclusion is often the key sentence.Exam workflow: Build powers a,a^2,a^4,... in a table, multiply only the powers selected by the binary expansion, and attach the logical conclusion to the final residue.

Fully worked simple example

Compute 7¹³ mod 15. 7²=49≡4; 7⁴≡4²=16≡1; 7⁸≡1. Hence 7¹³=7⁸·7⁴·7≡1·1·7=7 mod 15. For a Fermat test, 15 is composite and 2¹⁴ mod 15=4, not 1, so base 2 detects compositeness; this is a conclusive failure, not a primality proof procedure.

Medium/hard paper-style synthesis

Find 17^{-1} mod 43 and then 17^{41} mod 43. Euclid gives 43=2*17+9, 17=9+8, 9=8+1, hence 1=2*43-5*17, so 17^{-1}=38. Since 43 is prime, 17^42=1 and therefore 17^41=17^{-1}=38 mod 43. The theorem use is valid because gcd(17,43)=1.

Two graded prompts

1. Foundation — 6 marks

Find 3¹³ mod 17 by repeated squaring. Exam bridge: powers/reductions (4), correct combination (2). Check: 13=8+4+1 and result is 12.

2. Exam bridge — 8 marks

State Fermat's test and explain why passing it for one base does not establish primality. Check: give hypotheses, the pass condition, and the pseudoprime caveat; a failed test has the stronger conclusion.

Hard paper-style synthesis

Paper-style synthesis: test 341 with Fermat base 2 and interpret the result. Check: 341=11*31 and 2^10=1 mod 341, so 2^340=(2^10)^34=1; 341 passes this base despite being composite, demonstrating a base-2 pseudoprime rather than primality.

Practice question - Fermat evidence, not proof [8 marks]

Inspired by: CS402 2024/25 Q3(d) and Q4(a-b).

Supplied data and task. Use fast exponentiation to test n=341 to base 2, given that 341=11·31 and 210=1 mod 341. State precisely what the result establishes, and define a Carmichael number. [8 marks]

Question-demand diagnosis: the calculation is short, but most credit is for the logical direction of Fermat's test. Fastest route: write 340=34·10, substitute the supplied congruence, then distinguish the known factorisation from the test result.

Worked answer: 2340=(210)34=134=1 mod 341. Thus 341 passes Fermat's congruence to base 2. Because 341=11·31 is supplied, it is composite; it is therefore a base-2 Fermat pseudoprime. A pass alone would not prove primality, because this example is composite. In contrast, if a coprime base produced a residue other than 1, that would prove n composite. A Carmichael number is a composite n for which an-1=1 mod n for every a coprime to n.

Topic-specific trap: do not define a pseudoprime without naming its base, and do not call every composite that passes one base Carmichael.

Common mistakes

  • Applying Fermat/Euler without checking its hypothesis.
  • Reducing an exponent modulo φ(n) when the base is not coprime to n.
  • Calling a probable-prime test a proof.
  • Skipping intermediate reductions and losing arithmetic marks.
  • Recovery rule: When a test returns 1, write 'passes this base' unless a separate theorem supplies a proof of primality.

Checklist

  • Theorem and assumptions named?
  • Exponent decomposition shown?
  • Pass/fail conclusion stated at correct strength?
  • Inverse validated by gcd?
  • Final 60-second audit: Hypotheses, exponent decomposition, modular reductions and the exact strength of the conclusion are explicit.
