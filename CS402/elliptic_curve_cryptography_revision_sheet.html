Elliptic-Curve Cryptography

Work in a finite field, respect exceptional cases, and make the group law visible.

Purpose

ECC questions usually ask you to enumerate or combine points on a small curve. The aim is not real-world parameters: show finite-field arithmetic, identify inverse/order-two points, and connect the point group to a discrete-logarithm public-key construction.Exam use: Curve membership, exceptional case, inverse, reduced coordinates and an independent substitution check all appear.

What the question asks, and plan

  1. Write the curve and field: y²=x³+ax+b mod p, with the stated prime p.
  2. For listing, tabulate squares/right-hand sides and retain matching residues.
  3. For addition, first test exceptional cases: identity, inverse points, or doubling.
  4. Calculate slope with a modular inverse, then x- and y-coordinates, reducing each modulo p.
  5. Question interpretation: For list, test every field element; for add or double, identify the exceptional case before using a slope; for order, show the successive multiples until O.

Terms and formulas

  • Identity O: P+O=P; inverse of (x,y) is (x,−y mod p).
  • Order two: non-identity P with 2P=O; over odd p, this means y=0.
  • Addition, P≠Q: λ=(y₂−y₁)(x₂−x₁)⁻¹, x₃=λ²−x₁−x₂, y₃=λ(x₁−x₃)−y₁ mod p.
  • Doubling: λ=(3x₁²+a)(2y₁)⁻¹ mod p, then use the same coordinate formulas.
  • ECC intuition: public Q=dP; recover d from P,Q is the elliptic-curve discrete-log problem for secure parameters.
  • Rapid recall: On y^2=x^3+ax+b over F_p, -P=(x,-y); P+(-P)=O; doubling uses lambda=(3x^2+a)(2y)^{-1}, unless y=0, when 2P=O.

Derivation and method

The usual real-number chord-and-tangent construction becomes algebra in a finite field: division means multiply by an inverse modulo p. If Q=−P, the vertical line gives O, so no slope inverse is needed. If y=0, P is its own inverse and has order two. These cases should be checked before applying a generic formula.Exam workflow: Check that supplied points lie on the curve, compute each inverse with a one-line congruence, and substitute the result back into the curve equation.

Fully worked simple example

On y²=x³+2x+2 mod 17, take P=(5,1). Double it: λ=(3·25+2)(2)⁻¹=77·9≡9·9≡13 mod 17. Then x₃=13²−10=159≡6; y₃=13(5−6)−1=−14≡3. Thus 2P=(6,3). Every inverse and reduction is shown, so the method can be checked.

Medium/hard paper-style synthesis

On y^2=x^3+2x+2 mod 17 with P=(5,1), the starter gives 2P=(6,3). Now compute 3P=2P+P: lambda=(1-3)(5-6)^{-1}=(-2)(-1)^{-1}=2 mod 17. Hence x_3=2^2-6-5=-7=10 and y_3=2(6-10)-3=-11=6, so 3P=(10,6). Verify 6^2=36=2 and 10^3+20+2=1022=2 mod 17.

Two graded prompts

1. Foundation — 6 marks

On an odd-prime field curve, explain why a point (x,0) has order two. Exam bridge: inverse definition (3), conclude P=−P and P+P=O (3). Check: do not claim O has order two.

2. Exam bridge — 9 marks

Given a stated curve and two points P,Q, calculate P+Q and list the exceptional case you checked first. Check: slope inverse (3), coordinates (4), modular reductions and exceptional-case statement (2).

Hard paper-style synthesis

Paper-style synthesis: on y^2=x^3+x+1 over F_5, list all points and identify every order-two point. Check squares are {0,1,4}; the affine points are (0,1),(0,4),(2,1),(2,4),(3,1),(3,4),(4,2),(4,3), plus O, and there is no affine point with y=0, hence no order-two point.

Practice question - point arithmetic and order [9 marks]

Inspired by: CS402 2024/25 Q4(e), which asks for finite-field point enumeration and order-two points.

Supplied data and task. On E/F7: y2=x3+2x+3, verify P=(2,1), compute 2P, then decide whether P has order 2. Also identify the criterion for all order-two points on this curve. [9 marks]

Question-demand diagnosis: this is a membership check, a doubling calculation and a conceptual classification. Fastest route: verify 1=8+4+3=15=1 mod 7; then use the doubling slope and separately use y=0 for order two.

Worked answer: P lies on E as above. Its doubling slope is lambda=(3·22+2)(2·1)-1=14·2-1=0 mod 7, because 2-1=4. Therefore x(2P)=0-2-2=-4=3 and y(2P)=0(2-3)-1=-1=6, so 2P=(3,6). This is not O, so P is not order two. Over an odd prime field a non-identity point is its own inverse exactly when (x,y)=(x,-y), equivalently 2y=0 and hence y=0. Therefore the order-two points are precisely the curve points (x,0), found by solving x3+2x+3=0 mod 7.

Topic-specific trap: lambda=0 is a valid slope; it does not mean the result is O. O arises when adding inverse points, or when doubling a point with y=0.

Common mistakes

  • Using ordinary division instead of a modular inverse.
  • Forgetting O or treating P+(−P) with the generic slope formula.
  • Using the wrong sign in the y-coordinate formula.
  • Confusing point order with field size.
  • Recovery rule: A zero denominator is a case split, not an invitation to divide: decide whether the points are inverses or whether a tangent is vertical.

Checklist

  • Curve/field and point membership stated?
  • Exceptional cases checked first?
  • Each inverse justified?
  • Coordinates reduced modulo p?
  • Final 60-second audit: Curve membership, exceptional case, inverse, reduced coordinates and an independent substitution check all appear.
