MA342 Topic Guide

Subspaces and Constructions

Build and use subspace, product, final and quotient topologies.

Purpose

Translate a construction into its defining open sets and then prove the requested property from that definition.Exam use: The 2025/26 paper asks for subspace topology in Q1(c), a 4-mark subspace example in Q1(d), final topology in Q3(a), and two quotient arguments worth 8 marks in Q4(c-d).

Question plan

  1. Name the construction and its underlying set.
  2. Write the defining rule for opens or a basis.
  3. Use the universal map only when its continuity criterion is relevant.
  4. For a proposed quotient, identify the continuous surjection and then exploit a property preserved by continuous images if a contradiction is requested.
  5. Question interpretation: For subspace, intersect with ambient opens; for final or quotient topology, test all defining-map preimages; for a quotient obstruction, start from “continuous and onto”.

Definitions

For Y⊆X, the subspace topology is {Y∩U:U open in X}. A basis for X×Y consists of U×V with U,V open. Given topological spaces Xi, a set Y and maps fi:Xi→Y, the final topology on Y is {U⊆Y:fi-1(U) is open in Xi for every i}; it is the finest topology making all fi continuous. The quotient topology is the final topology for one surjection q:X→Y.Rapid recall: Subspace means ambient intersection; product means basis rectangles; final and quotient mean defining-map preimages.

Proof method

For subspaces, express the target set as Y∩U. For final and quotient topologies, pull the set back along every defining map; never assume images of open sets are open. A quotient map is continuous and surjective, so compactness and connectedness pass from domain to codomain.Exam workflow: Identify the inclusion or defining maps, write the preimage/basis rule, and name any continuous-image invariant used.

Worked simple example

If X=R and Y=[0,1], then [0,1/2)=Y∩(-1,1/2), so it is open in the subspace Y.

Medium/hard paper-style synthesis

The subspace topology on [0,1] inherited from standard R is not discrete. If it were discrete, {1/2} would be open, so {1/2}=[0,1]∩U for some standard-open U⊆R. But any open U containing 1/2 contains an interval around 1/2 and hence other points of [0,1], a contradiction.

Graduated exam bridges

1. Foundation [4 marks]: Is the standard subspace topology on [0,1] discrete? Check: no; the singleton {1/2} is not relatively open.

2. Exam style [3 marks]: Define the final topology induced on Y by maps fi:Xi→Y. Check: U is open exactly when every fi-1(U) is open; call it the finest such topology.

Hard paper-style synthesis

Standard R cannot be a quotient of the Cantor set C. A quotient presentation would supply a continuous surjection q:C→R. Since C is compact, its continuous image q(C)=R would be compact, contradicting the non-compactness of R.

Practice question - circle and Cantor quotients [8 marks]

Inspired by: MA342 2025/26 Q4(c-d). Task. (a) Briefly explain why S1 is a quotient of [0,1]. [5 marks] (b) Decide, with justification, whether standard R is a quotient of the Cantor set C. [3 marks]

Demand diagnosis and fastest route: for the positive example give the endpoint-identifying quotient map; for the negative example use compactness of continuous images.

Worked answer: Define q:[0,1]→S1 by q(t)=e2πit. It is continuous and onto, identifies exactly 0 and 1, and is closed because its domain is compact and its codomain Hausdorff. Hence q is a quotient map and S1 is homeomorphic to [0,1]/(0~1). In contrast, if a quotient map p:C→R existed, it would be a continuous surjection. The Cantor set is compact, so p(C)=R would be compact, but standard R is not compact. Therefore R is not a quotient of C.

Topic-specific trap: a quotient map is not merely a set-theoretic surjection; use its continuity in the compactness obstruction.

Mistakes

  • Using U∩Y but forgetting U must be open in X.
  • Claiming every subset of a product is a basis element.
  • Replacing quotient preimages by images.
  • Recovery rule: The image of an open set under a quotient map need not be open unless its full saturated preimage is open.

Checklist

  • I can compute a subspace topology.
  • I can state a product basis.

  • I can use the quotient definition in the correct direction.
  • Final 60-second audit: Construction, defining preimage/basis rule, ambient versus subspace openness and saturation are visible.
