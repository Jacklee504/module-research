1. Topology on a set Asked 3/3 years

Explanation: A topology is a collection of subsets of \(X\) that are declared to be open. The collection must satisfy three rules.
Exam answer:

A topology on a set \(X\) is a collection \(\mathcal T\) of subsets of \(X\) such that:

  1. \(\varnothing\in\mathcal T\) and \(X\in\mathcal T\);
  2. the union of any collection of sets in \(\mathcal T\) belongs to \(\mathcal T\);
  3. the intersection of any finite collection of sets in \(\mathcal T\) belongs to \(\mathcal T\).

The elements of \(\mathcal T\) are called open sets.

Finite set with two distinct topologies

\[ X=\{1,2,3,4\}. \] \[ \mathcal T_1=\{\varnothing,X\}, \qquad \mathcal T_2=\{\varnothing,\{1\},X\}. \]

These are distinct because \(\{1\}\in\mathcal T_2\), but \(\{1\}\notin\mathcal T_1\).

2. Standard topology on \(\mathbb R\)

Explanation: A set is open when every point in it has a small open interval around it that remains completely inside the set.
Exam answer:

The standard topology on \(\mathbb R\) is the collection of all sets \(U\subseteq\mathbb R\) such that, for every \(x\in U\), there exists \(\varepsilon>0\) for which

\[ (x-\varepsilon,x+\varepsilon)\subseteq U. \]

Short version: The standard topology on \(\mathbb R\) consists of all unions of open intervals.

3. Cofinite topology Asked 2/3 years

Explanation: A set is open if it is empty or leaves out only finitely many elements of \(X\).
\[ \mathcal T_{\mathrm{cof}} = \{\varnothing\} \cup \left\{ U\subseteq X: X\setminus U\text{ is finite} \right\}. \]
Exam answer: The cofinite topology on \(X\) consists of the empty set and every subset \(U\subseteq X\) whose complement \(X\setminus U\) is finite.

Cofinite versus discrete topology on \(\mathbb Z\)

They do not coincide.

The set of even integers is open in the discrete topology because every subset is open.

It is not open in the cofinite topology because its complement, the set of odd integers, is infinite.

Cofinite versus standard topology on \(\mathbb R\)

They do not coincide.

The interval \((0,1)\) is open in the standard topology, but it is not open in the cofinite topology because \(\mathbb R\setminus(0,1)\) is infinite.

4. Subspace topology Asked 3/3 years

Explanation: Take an open set from \(X\) and keep only the part that lies inside \(A\).
\[ \mathcal T_A = \{A\cap U:U\in\mathcal T\}. \]
Exam answer: A subset \(V\subseteq A\) is open in the subspace topology on \(A\) if \(V=A\cap U\) for some open set \(U\) in \(X\).

5. Discrete and non-discrete subspaces Asked 3/3 years

Key idea: A topology is discrete if every subset is open. It is enough to show that every singleton \(\{x\}\) is open.

\(\mathbb Z\) inside standard \(\mathbb R\)

The subspace topology on \(\mathbb Z\) is discrete.

For every \(n\in\mathbb Z\),

\[ \{n\} = \mathbb Z \cap \left( n-\frac12, n+\frac12 \right). \]

The interval is open in \(\mathbb R\), so \(\{n\}\) is open in \(\mathbb Z\). Therefore every singleton, and hence every subset of \(\mathbb Z\), is open.

\(\mathbb Q\) inside standard \(\mathbb R\)

The subspace topology on \(\mathbb Q\) is not discrete.

Every open interval around a rational number \(q\) contains rational numbers other than \(q\). Therefore the singleton \(\{q\}\) is not open in \(\mathbb Q\).

\([0,1]\) inside standard \(\mathbb R\)

The subspace topology on \([0,1]\) is not discrete.

For example, the singleton \(\left\{\frac12\right\}\) is not open because every open interval around \(\frac12\) contains other points of \([0,1]\).

Subspace Discrete? Reason
\(\mathbb Z\subseteq\mathbb R\) Yes Each integer can be isolated by a small open interval.
\(\mathbb Q\subseteq\mathbb R\) No Every interval around a rational contains other rationals.
\([0,1]\subseteq\mathbb R\) No Points such as \(\frac12\) cannot be isolated.

6. Base for a topology

Explanation: A base is a collection of basic open sets from which every open set can be built by taking unions.
Exam answer:

A collection \(\mathcal B\) of open subsets of \(X\) is a base for a topology \(\mathcal T\) if every open set \(U\in\mathcal T\) is a union of elements of \(\mathcal B\).

Equivalently, if \(U\) is open and \(x\in U\), then there exists \(B\in\mathcal B\) such that \[ x\in B\subseteq U. \]

7. Lower limit topology on \(\mathbb R\) Asked 2/3 years

Explanation: The basic open intervals are \([a,b)\), rather than the standard open intervals \((a,b)\).
Exam answer: A base for the lower limit topology on \(\mathbb R\) is
\[ \mathcal B = \left\{ [a,b): a,b\in\mathbb R,\ a<b \right\}. \]

Show that \([0,1)\) is open and closed

Worked answer

The set \([0,1)\) is open because it is itself a basic open set in the lower limit topology.

Its complement is

\[ \mathbb R\setminus[0,1) = (-\infty,0)\cup[1,\infty). \]

Both \((-\infty,0)\) and \([1,\infty)\) are unions of basic open sets of the form \([a,b)\).

Therefore the complement of \([0,1)\) is open, so \([0,1)\) is closed.

Closure of \((0,1)\)

In the lower limit topology,
\[ \overline{(0,1)} = [0,1). \]
Justification

Every basic neighbourhood \([0,\varepsilon)\) of \(0\) meets \((0,1)\), so \(0\) belongs to the closure.

The point \(1\) does not belong to the closure because \([1,2)\) is an open neighbourhood of \(1\) that is disjoint from \((0,1)\).

Every point outside \([0,1]\) also has a basic open neighbourhood that does not meet \((0,1)\).

8. Neighbourhood of a point

Explanation: A set \(N\) is a neighbourhood of \(x\) if it contains an open set around \(x\).
Exam answer: A subset \(N\subseteq X\) is a neighbourhood of \(x\) if there exists an open set \(U\) such that
\[ x\in U\subseteq N. \]
The set \(N\) does not itself have to be open.

9. Interior \(A^\circ\)

Explanation: A point belongs to the interior of \(A\) if there is an open set around it that stays completely inside \(A\).
\[ A^\circ = \left\{ x\in A: \exists U\text{ open with }x\in U\subseteq A \right\}. \]
Equivalent statement: \(A^\circ\) is the largest open subset of \(A\).

Show that \(A\) is a neighbourhood of \(x\) if and only if \(x\in A^\circ\)

Worked answer

Suppose first that \(A\) is a neighbourhood of \(x\). Then there exists an open set \(U\) such that \(x\in U\subseteq A\). Therefore \(x\in A^\circ\).

Conversely, suppose that \(x\in A^\circ\). Then there exists an open set \(U\) such that \(x\in U\subseteq A\). Therefore \(A\) is a neighbourhood of \(x\).

10. Closure \(\overline A\)

Explanation: A point belongs to the closure of \(A\) if every open set around it meets \(A\).
\[ \overline A = \left\{ x\in X: \text{every open }U\text{ containing }x \text{ satisfies }U\cap A\neq\varnothing \right\}. \]
Equivalent statement: \(\overline A\) is the smallest closed subset of \(X\) that contains \(A\).

If every neighbourhood of \(x\) meets \(A\), show that \(x\in\overline A\)

Worked answer

Every open set \(U\) containing \(x\) is a neighbourhood of \(x\).

By assumption, every neighbourhood of \(x\) meets \(A\). Therefore \(U\cap A\neq\varnothing\).

Hence, by the definition of closure, \(x\in\overline A\).

11. Accumulation points

Explanation: A point \(x\) is an accumulation point of \(A\) if every open set around \(x\) contains a point of \(A\) other than \(x\).
A point \(x\in X\) is an accumulation point of \(A\) if, for every open set \(U\) containing \(x\), \[ U\cap\left(A\setminus\{x\}\right)\neq\varnothing. \]

If \(A\) has no accumulation point in \(X\), show that \(A\) is closed

Worked answer

Let \(x\in X\setminus A\).

Since \(A\) has no accumulation points, \(x\) is not an accumulation point of \(A\). Therefore there exists an open set \(U\) containing \(x\) such that

\[ U\cap\left(A\setminus\{x\}\right)=\varnothing. \]

Since \(x\notin A\), this means \(U\cap A=\varnothing\). Therefore \(U\subseteq X\setminus A\).

Thus every point of \(X\setminus A\) has an open neighbourhood contained in \(X\setminus A\). Hence \(X\setminus A\) is open, and therefore \(A\) is closed.
