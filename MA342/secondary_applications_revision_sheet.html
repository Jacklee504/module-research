Question plan

  1. State the theorem or invariant being applied.
  2. Check its hypotheses in the concrete setting.
  3. Give only the requested consequence; do not replace a proof question with a slogan.
  4. Question interpretation: Treat each named theorem as a conditional tool: state its hypotheses before using an Euler characteristic, fixed-point, or surface conclusion.

Definitions

For a suitable finite triangulation, the Euler characteristic is χ=V−E+F. Brouwer fixed point: every continuous map from a closed ball to itself has a fixed point. The topological proof of the FTA uses global properties of maps on the complex plane.Rapid recall: For a connected planar embedding V-E+F=2; Brouwer guarantees a fixed point for continuous self-maps of a closed disk; triangulation counts require edges/faces with their incidence assumptions.

Proof method

For a triangulation, count vertices, edges and faces carefully and use the stated Euler relation. For theorem applications, explicitly map the data to each hypothesis before drawing the conclusion.Exam workflow: Translate the object into the theorem's setting, count without double-counting, and separate a theorem application from heuristic geometry.

Worked simple example

A tetrahedron has V=4, E=6, F=4, so χ=4−6+4=2, as expected for a sphere-like surface.

Medium/hard paper-style synthesis

Prove a simple connected planar graph with V>=3 satisfies E<=3V-6. Each face boundary has at least 3 edges, so 3F<=2E because each edge borders two faces. Euler gives F=2-V+E. Thus 3(2-V+E)<=2E, hence E<=3V-6. Therefore K_5, with E=10>9 when V=5, is nonplanar.

Graduated exam bridges

1. Foundation: Compute χ for a triangle filled by one face. Check: 3−3+1=1.

2. Exam style: Let f:[0,1]→[0,1] be continuous. Explain why f has a fixed point. Check: this is the one-dimensional fixed-point consequence; alternatively use g(x)=f(x)−x and IVT.

Hard paper-style synthesis

Paper-style synthesis: show every continuous f:[0,1]->[0,1] has a fixed point. Check g(x)=f(x)-x is continuous, g(0)>=0 and g(1)<=0; the intermediate value theorem supplies c with g(c)=0. This is a one-dimensional Brouwer instance.

Practice question - topological fixed point [8 marks]

Inspired by: MA342 2024/25 Q4(a). Task. Show every continuous f:[0,1]→[0,1] has a fixed point. [8 marks]

Demand diagnosis and fastest route: turn the fixed-point condition into a zero of a continuous real function and apply IVT.

Worked answer: Let g(x)=f(x)-x. This is continuous. Since f(0)∈[0,1], g(0)=f(0)≥0. Since f(1)∈[0,1], g(1)=f(1)-1≤0. If either endpoint is zero we have a fixed point; otherwise IVT gives c∈(0,1) with g(c)=0. Therefore f(c)=c.

Topic-specific trap: continuity and the codomain restriction are both needed to obtain the opposite endpoint signs.

Mistakes

  • Counting a shared edge twice in a triangulation.
  • Applying Brouwer when the map does not send the closed ball to itself.
  • Spending core-revision time on older applications without current lecture evidence.
  • Recovery rule: Euler's formula uses faces of a particular planar embedding and needs the connected-version constant 2; adjust for disconnected graphs.
