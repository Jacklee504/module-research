Random Graphs

Rapid refresher

Core ruleExam distinction
G(n,p): each of N=n(n-1)/2 edges independent with probability p; E|E|=Np and degree is Bin(n-1,p). G(n,m) fixes exactly m edges.G(n,p) has random edge count; G(n,m) does not. Independence belongs to G(n,p) edges.

Medium/hard adapted practice

Paper family: Erdos-Renyi G(n,p)/G(n,m), edge counts and degree probabilities recur strongly in 2017/18-2024/25.

(a) For G(10,0.2), find expected edges and probability a chosen vertex has degree 0. [8 marks]

Question demand: apply the definition/calculation with working. Quickest route: Use N=45; for isolation multiply the nine independent absent-edge probabilities.

Mark-aware answer: E|E|=45(0.2)=9. P(deg(v)=0)=(1-0.2)9=0.89. State that this is a model expectation, not an observed count.

Trap: Do not use p as the expected degree; it is an edge probability.

(b) Find the probability that G(n,p) has exactly m edges. [6 marks]

Question demand: There are N=n(n-1)/2 independent potential edges, so use a binomial probability. Quickest route: There are N=n(n-1)/2 independent potential edges, so use a binomial probability.

Mark-aware answer: P(|E|=m)=C(N,m)pm(1-p)N-m, where N=n(n-1)/2. Explain that each chosen m-edge set has probability pm(1-p)N-m.

Trap: This formula is not for G(n,m), where |E|=m with probability 1.

(c) Compare G(n,m) and G(n,p) in one sentence plus one consequence. [4 marks]

Question demand: State what is fixed and what fluctuates. Quickest route: State what is fixed and what fluctuates.

Mark-aware answer: G(n,m) chooses uniformly among graphs with exactly m edges, whereas G(n,p) independently includes each edge and has a binomial edge count. Thus expected-density calculations in G(n,p) do not impose an exact observed m.

Trap: Do not mix the two model names after defining them.
