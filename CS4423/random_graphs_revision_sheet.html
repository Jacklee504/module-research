Random Graphs

Separate the model definition from the probability calculation it implies.

Purpose and relevance

Erdős–Rényi models give a baseline for network structure. Random-graph questions recur strongly and match the official outcome on random graph generators and properties.Exam use: Model, number of trials/objects, occurrence probability, expectation formula and interpretation are stated.

What a question really asks — answer plan

Name the model first: G(n,m) fixes m edges; G(n,p) independently includes each possible edge with p. Identify the random variable, use the correct number of possible edges, then interpret expectation or probability.Question interpretation: First identify G(n,p) versus G(n,m); then translate the requested count into indicator variables or a binomial distribution before substituting.

Prerequisites, vocabulary and formulas

  • Possible undirected edges N=C(n,2)=n(n−1)/2.
  • G(n,p): M∼Binomial(N,p), E[M]=Np; degree ∼Binomial(n−1,p), E[k]=(n−1)p.
  • G(n,m): each m-edge subset is equally likely; edge probability m/N.
  • Giant component: a component containing a positive fraction of vertices.
  • Rapid recall: In G(n,p), |E| is Binomial(N,p) with N=n(n-1)/2, E|E|=Np, and a vertex degree is Binomial(n-1,p); a fixed k-edge pattern appears with factor p^k.

Step-by-step method

  1. Write n, m or p and N=C(n,2).
  2. Choose binomial/expectation or counting method.
  3. Substitute, retain units (edges/degree/probability).
  4. Say what independence means and whether it fits the application.
  5. Exam workflow: Count eligible labelled objects, multiply by the probability each occurs, and use linearity of expectation without assuming indicators are independent.

Worked starter question and model answer

Question: For G(5,0.2), find expected edges and expected degree.

Model answer: N=10, so E[M]=10×0.2=2 edges. E[k]=(5−1)×0.2=0.8. These are averages across generated graphs, not guaranteed values in one graph.

Medium/hard paper-style synthesis

In G(6,1/2), N=15, so E|E|=15/2 and Var(|E|)=15/4. There are C(6,3)=20 vertex triples; each forms a triangle with probability (1/2)^3, hence the expected number of triangles is 20/8=2.5. Independence between different triangles is not needed for this expectation.

Graduated practice

Prompt 1

In G(6,3), what is the probability a particular edge is present? Check: 3/C(6,2)=3/15=0.2.

Exam bridge

Contrast G(n,m) and G(n,p), then derive expected edge count and discuss realism. Check: fixed versus random edge count, correct N, and a limitation such as independent edges miss clustering/community structure.

Hard paper-style synthesis

Paper-style synthesis: in G(8,1/4), find the expected isolated vertices. Check a fixed vertex is isolated with probability (3/4)^7, so expectation is 8(3/4)^7; do not multiply by an extra independence factor.

Common mistakes

  • Using n² instead of C(n,2).
  • Confusing fixed m with expected m.
  • Reading expectation as certainty.
  • Recovery rule: Expected count may be non-integer; it is an average over graphs, not a promised count in one graph.

Final checklist

  • Did I state the model?
  • Is the sample space right?
  • Did I interpret the result?
  • Final 60-second audit: Model, number of trials/objects, occurrence probability, expectation formula and interpretation are stated.
