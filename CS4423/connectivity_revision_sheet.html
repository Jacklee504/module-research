Rapid refresher

Core ruleExam distinction
Undirected connected means a path between every pair. Strongly connected means directed paths both ways; weakly connected ignores directions.SCCs partition a digraph; contracting them yields an acyclic condensation graph.

Medium/hard adapted practice

Paper family: Weak/strong connectivity, components and directed-network interpretation recur in 2017/18-2024/25 papers.

(a) Classify a directed graph as weakly/strongly connected and explain a witness. [8 marks]

Question demand: apply the definition/calculation with working. Quickest route: Run reachability with directions from a vertex and in the reversed graph, or give directed path counterexamples; then ignore directions for weak connectivity.

Mark-aware answer: A missing directed path u to v disproves strong connectivity. If the underlying undirected graph has one component, the graph is weakly connected. State the actual witness pair/path.

Trap: Do not use an undirected path as evidence of strong connectivity.

(b) Describe an algorithm to find strongly connected components. [6 marks]

Question demand: Use two DFS passes (Kosaraju) or state Tarjan; explain the role of the reverse graph. Quickest route: Use two DFS passes (Kosaraju) or state Tarjan; explain the role of the reverse graph.

Mark-aware answer: Run DFS on G and order vertices by finishing time. Run DFS on the reversed graph starting from unvisited vertices in decreasing finishing time; each DFS tree is one SCC. The condensation is acyclic.

Trap: A single DFS only gives reachability from a start, not all SCCs.

(c) Interpret a bow-tie diagram of a directed web graph. [4 marks]

Question demand: Name SCC, IN, OUT and tendrils using reachability direction. Quickest route: Name SCC, IN, OUT and tendrils using reachability direction.

Mark-aware answer: The core is a giant SCC. IN can reach the core but is not reached from it; OUT is reached from the core but cannot return; tendrils attach without the corresponding core path. State directions explicitly.

Trap: Do not label every weak component as an SCC.
