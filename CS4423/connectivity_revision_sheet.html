CS4423 Topic Guide

Connectivity and Directed Networks

Be explicit about whether travel must follow edge direction.

Purpose and relevance

Connectivity determines whether vertices can reach one another. Directed networks require the distinction between weak and strong connectivity; both recur in the local archive.Exam use: Direction convention, searches/reachability witnesses, component membership and condensation interpretation agree.

What a question really asks — answer plan

State whether the graph is directed. For weak components, ignore directions; for strong components, require mutual directed reachability. Support each component claim with paths or a traversal argument.Question interpretation: For connected components ignore no directions unless told; for directed graphs distinguish weak from strong connectivity and prove each reachability claim.

Prerequisites, vocabulary and formulas

  • Connected: undirected path between every pair.
  • Weakly connected: connected after directions are ignored.
  • Strongly connected: directed paths both u→v and v→u for every pair in the component.
  • Bow-Tie: SCC core with IN, OUT, tendrils and disconnected parts.
  • Rapid recall: An undirected graph is connected when every pair has a path; a digraph is strongly connected when both directed reachabilities hold, and weakly connected when its underlying undirected graph is connected.

Step-by-step method

  1. Mark edge directions and identify candidate reachability groups.
  2. For weak components, replace arrows with lines.
  3. For SCCs, run/reason with reachability from a vertex and back to it.
  4. Classify remaining vertices relative to a core only if the diagram supports it.
  5. Exam workflow: Run a search from a candidate vertex, repeat on the transpose for strong connectivity, and exhibit unreachable ordered pairs or component sets when the property fails.

Worked starter question and model answer

Question: A→B, B→A, B→C. Find weak and strong components.

Model answer: Ignoring arrows gives one weak component {A,B,C}. A and B form an SCC because each reaches the other; C alone is an SCC because C cannot return to B.

Medium/hard paper-style synthesis

For arcs A->B, B->C, C->A, C->D, D->E, E->D, the underlying graph is connected, so the digraph is weakly connected. SCCs are {A,B,C} and {D,E}: vertices in the first reach the second through C->D, but E cannot reach A. The condensation has one arc {A,B,C}->{D,E} and is acyclic.

Graduated practice

Prompt 1

Does one directed path A→C prove A and C are strongly connected? Check: no; C→A is also required.

Exam bridge

Find SCCs and draw a Bow-Tie-style interpretation. Check: give reachability evidence, distinguish IN/OUT from the SCC, and do not force every directed graph into a full Bow-Tie taxonomy.

Hard paper-style synthesis

Paper-style synthesis: what single added arc makes the digraph strongly connected? Check E->A (or D->A) creates a return route from the second SCC to the first, so every vertex reaches every other.

Practice question - SCCs and a repair arc [8 marks]

Scenario. A directed service graph has arcs A→B, B→C, C→A, C→D, D→E, E→D. Find its strongly connected components and one minimum change making it strongly connected. [8 marks]

Demand diagnosis and fastest route: give mutual-reachability evidence before drawing a condensation graph. The components are visible as cycles linked one way.

Worked answer: {A,B,C} is an SCC because its directed cycle makes every pair mutually reachable. {D,E} is an SCC for the same reason. C→D gives a condensation edge {A,B,C}→{D,E}, but no path returns, so the whole graph is only weakly connected. Adding E→A (or D→A) gives a return from the second SCC to the first. Every first-component vertex reaches the second via C→D, and every second-component vertex reaches the first via the new arc, so the amended digraph is strongly connected.

Topic-specific trap: an undirected path after ignoring arrows proves weak, not strong, connectivity.

Common mistakes

  • Ignoring direction for strong connectivity.
  • Calling a DAG strongly connected.
  • Using “reachable from” as if it meant mutually reachable.
  • Recovery rule: One directed path A to B does not establish strong connectivity; the reverse reachability must also be shown.

Final checklist

  • Did I specify weak or strong?
  • Have I shown return paths?
  • Is any Bow-Tie label justified?
  • Final 60-second audit: Direction convention, searches/reachability witnesses, component membership and condensation interpretation agree.
