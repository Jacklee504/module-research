CS4423 Topic Guide

Bipartite, Affiliation and Laplacian Networks

Keep two node types separate, then project or reconstruct with care.

Purpose and relevance

Affiliation networks model membership between two kinds of entity; projections expose one-mode relationships. They appeared as newer local material, alongside Laplacian reconstruction, so treat them as current-syllabus coverage rather than a long repeat claim.Exam use: Node modes, matrix order, diagonal/weight convention, degree matrix and zero row-sum check are explicit.

What a question really asks — answer plan

Identify the two disjoint sets and write the incidence matrix B. For a projection, say which set is retained and whether weights count shared affiliations. For a Laplacian, use L=D−A and recover off-diagonal adjacency carefully.Question interpretation: For project, state which mode is retained and whether weights count shared affiliations; for Laplacian, preserve vertex order and distinguish D-A from adjacency.

Prerequisites, vocabulary and formulas

  • Bipartite: V=U∪W with edges only U–W.
  • Incidence matrix B: Bᵢⱼ=1 when Uᵢ is affiliated with Wⱼ.
  • One-mode projections: BBᵀ and BᵀB; off-diagonals count shared neighbours.
  • Laplacian: L=D−A; Lᵢᵢ=deg(i), Lᵢⱼ=−Aᵢⱼ for i≠j.
  • Rapid recall: For incidence matrix B, one-mode projections are BB^T and B^TB (with diagonal often removed); the combinatorial Laplacian is L=D-A and L1=0.

Step-by-step method

  1. List U and W separately; construct B with stated order.
  2. Multiply/select a projection and interpret its diagonal/off-diagonal entries.
  3. For L, read degrees from diagonal and Aᵢⱼ=−Lᵢⱼ off diagonal.
  4. Check symmetry and zero row sums for a simple undirected Laplacian.
  5. Exam workflow: Label matrix rows and columns, multiply entrywise as shared-neighbour counts, then explain diagonal and weight conventions.

Worked starter question and model answer

Question: Students S1,S2 attend events E1,E2; S1 attends both, S2 only E2. What is the student projection?

Model answer: B=[[1,1],[0,1]], so BBᵀ=[[2,1],[1,1]]. Ignoring diagonal self-counts, S1–S2 has weight 1 because they share E2.

Medium/hard paper-style synthesis

Let people p1,p2,p3 attend groups g1,g2 with B=[[1,1],[1,0],[0,1]]. Then BB^T=[[2,1,1],[1,1,0],[1,0,1]]. Removing the diagonal gives weighted person projection A=[[0,1,1],[1,0,0],[1,0,0]], degrees (2,1,1), and L=[[2,-1,-1],[-1,1,0],[-1,0,1]]. Each row sum is 0, providing a quick check.

Graduated practice

Prompt 1

If Lᵢⱼ=−1 for i≠j in a simple graph, what is Aᵢⱼ? Check: 1: there is an edge.

Exam bridge

Construct an affiliation matrix, its projection and a graph from a Laplacian. Check: state node orders, interpret projection weights, use L=D−A, and check row sums.

Hard paper-style synthesis

Paper-style synthesis: find the eigenvalue-0 multiplicity of that projection and interpret it. Check the projected graph is connected, so the multiplicity is 1; vector (1,1,1)^T spans the nullspace.

Common mistakes

  • Joining nodes from the same bipartition directly in B.
  • Treating projection diagonal as an ordinary edge weight.
  • Forgetting Laplacian off-diagonals are negative adjacency.
  • Recovery rule: A projection diagonal records affiliation counts, not self-loops unless the question explicitly keeps it.

Final checklist

  • Are the two node sets explicit?
  • Did I state the projection meaning?
  • Does L have zero row sums?
  • Final 60-second audit: Node modes, matrix order, diagonal/weight convention, degree matrix and zero row-sum check are explicit.
