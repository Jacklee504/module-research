Networks - Most Asked Exam Questions

Question families drawn from the seven supplied papers. This page preserves the recurring marks, multi-part structure, and current-format variants without treating a past-paper pattern as a guarantee.

How To Use This Document

Source scope: all local CS4423 papers were checked: 2025/26, 2024/25, 2023/24, 2022/23, 2021/22, 2018/19, and 2017/18.

Current-format evidence: 2024/25 and 2025/26 are the primary papers. Both are two-hour papers with seven compulsory questions, total marks 14, 15, 15, 14, 14, 14, 14. The 2022/23 and 2023/24 papers are useful bridge evidence: four compulsory 25-mark questions, with the same core families embedded in longer questions.

Official-scope boundary: the official module page also includes market and document networks. These are covered below, but the archive does not support treating them as current-format favourites.

Priority 1 - BFS, Predecessors, And All Shortest Paths

Frequency: 7/7 papers. This is the only clearly universal question family in the archive.

  • 2025/26 Q4, 14 marks: describe BFS for distances [5], then start at Node 0, determine every shortest-path predecessor, and list all shortest paths to Node 7 [9].
  • 2024/25 Q4, 14 marks: the same 5 + 9 structure, including every predecessor and all shortest paths from Node 0 to Node 7.
  • 2023/24 Q1(b)-(d), 15 marks: distances from a root [4], all predecessors and all shortest paths [7], then a BFS spanning tree [4].
  • 2022/23 Q1(b)-(d), 15 marks: algorithm description [7], trace the distance algorithm [4], and construct a rooted spanning tree [4].
  • 2021/22 Q1(c)-(d), 7 marks: algorithm description [3], then a spanning tree and shortest distances [4].
  • 2018/19 Q1(c), 10 marks: algorithm description, spanning tree, distances, predecessors, and all shortest paths to a stated target.
  • 2017/18 Q1(a), 10 marks: algorithm description plus a spanning tree and root-to-all distance calculation.

Answer frame: Separate the algorithm from the trace. For the algorithm, state input graph and root, initial distances, frontier or queue processing, discovery rule, and output. In the trace, record levels or distances first; then record all neighbours that can be predecessors at the previous level. A single BFS tree loses marks if the question asks for every shortest path.

Priority 2 - Graph Foundations, Matrices, Bipartite Graphs, And Trees

Frequency: graph-theoretic basics appear throughout the archive. The latest two papers place a large share of their marks on matrices, bipartite structure, trees, and related constructions.

  • 2025/26 Q1, 14 marks: adjacency matrix to sketch [4], order/size and spanning-tree size [5], degree sequence [2], graphical degree sequence [3].
  • 2025/26 Q2, 15 marks: bipartite sketch and two-colouring [5], reorder nodes into a zero-block adjacency matrix [5], then construct a projection [5].
  • 2025/26 Q3, 15 marks: Pruefer-code degree reasoning [5], code-to-tree construction [5], and a labelled isomorphic tree [5].
  • 2024/25 Q1, 14 marks: simple connected graph and tree constraints [5], adjacency matrix [4], and permutation-matrix block form [5].
  • 2024/25 Q2, 15 marks: affiliation-network definition and bipartite reason [5], two-colouring [5], and a graph projection [5].
  • 2024/25 Q5, 14 marks: reconstruct a tree from a Laplacian [2], tree-to-Pruefer code [6], and code-to-degree-sequence/tree construction [6].

Answer frame: For a matrix question, define the vertex order before writing entries. For bipartite questions, state the two parts and verify each edge crosses the partition. For Pruefer work, show the smallest-leaf removal or attachment sequence, rather than writing only the final code or tree. Treat Laplacian reconstruction as a 2024/25 variant, not a guaranteed repeat.

Priority 3 - Centrality

Frequency: explicit conventional centrality appears in every paper from 2018/19 onward. The exact measure changes, but degree, closeness, and betweenness are the stable core.

  • 2025/26 Q5, 14 marks: degree and normalised degree [4], distances and closeness comparison [5], then shortest-path pairs through one node and betweenness [5].
  • 2024/25 Q3, 15 marks: NetworkX-style graph input, normalised degree [3], distance matrix and diameter [3], closeness for every node [3], and a closeness-versus-degree counterexample [3].
  • 2023/24 Q2, 25 marks: degree [5], closeness [5], betweenness [5], bipartiteness [3], and eigenvector centrality [7].
  • 2022/23 Q2, 25 marks: normalised degree [5], closeness [5], betweenness [5], and eigenvector centrality [10].
  • 2021/22 Q2, 15 marks: definitions and examples for degree, closeness, and betweenness centrality, each [5].
  • 2018/19 Q2, 20 marks: degree [5], eigenvector centrality and Perron-Frobenius [5], closeness [5], and betweenness [5].

Answer frame: Draw or relabel the graph before calculating. For closeness, make a distance row and state the normalisation convention used. For betweenness, list node pairs, then account for the number of shortest paths when a pair has more than one. End comparison questions with an intuitive graph-structure explanation.

Priority 4 - Erdos-Renyi Random Graphs

Frequency: 6/7 papers, from 2018/19 onward. Both latest papers dedicate 14 marks to this family.

  • 2025/26 Q6, 14 marks: define G_ER(n,m) and G_ER(n,p) and give empty-graph parameters [4]; probability of the complete graph in both models [5]; choose p so expected edge count is half the maximum [5].
  • 2024/25 Q6, 14 marks: define both models and give complete-graph parameters [4]; probability of exactly m edges [5]; then a die-based degree probability [5].
  • 2023/24 Q3, 25 marks: both generators and exactly-m-edge probability [5], expected size [5], die-based degree probability [5], then Watts-Strogatz construction and comparison [10].
  • 2022/23 Q3, 25 marks: both generators and exactly-m-edge probability [8], degree probability [5], giant component [5], and Watts-Strogatz [7].
  • 2021/22 Q3, 15 marks: G(n,m) [3], G(n,p) plus probability [4], coin-based degree probability [4], and giant component [4].
  • 2018/19 Q3, 20 marks: both models as distributions [10], then degree distribution, expected average degree, and die-based degree probability [10].

Answer frame: State the model distinction before calculating. In G_ER(n,m), every graph with exactly m edges is equally likely; in G_ER(n,p), each possible edge is included independently with probability p. Use E[|E|] = p * n(n-1)/2 for expected size, and a binomial probability for a chosen node's degree in the independent-edge model.

Priority 5 - Watts-Strogatz, Clustering, Transitivity, And Path Length

Frequency: 6/7 papers, from 2018/19 onward. This family normally combines one definition or calculation with a comparison question.

  • 2025/26 Q7, 14 marks: characteristic path length and small-world behaviour [4], graph transitivity and its value for G_ER(n,p) [5], then Watts-Strogatz properties relative to Erdos-Renyi and an (n,d)-circle graph [5].
  • 2024/25 Q7, 14 marks: node and graph clustering [4], clustering in G_ER(n,p) and its sparse-limit consequence [5], then the same Watts-Strogatz comparison [5].
  • 2023/24 Q3(d)-(e), 10 marks: construct an (n,d,p)-Watts-Strogatz graph [5] and compare clustering/path length across models [5].
  • 2022/23 Q3(d), 7 marks: construct Watts-Strogatz and explain its distinguishing properties.
  • 2021/22 Q4(a)-(b), 8 marks: sketch a circle graph and count edges [3], then construct Watts-Strogatz and compare its properties [5].
  • 2018/19 Q4(a), 10 marks: node/graph clustering, random-graph clustering, sparse-limit consequence, and Watts-Strogatz comparison.

Answer frame: Keep the three models distinct. The circle graph has high local structure and longer paths; Erdos-Renyi has short paths but low clustering when average degree stays constant; Watts-Strogatz combines comparatively high clustering with short characteristic path length after some rewiring. State the required definition before using it in a derivation.

Priority 6 And Coverage - Pruefer, Directed, Market, And Web Networks

Pruefer codes: 5/7 papers, starting in 2021/22 and prominent in both latest papers. Practise code-to-tree, tree-to-code, degree-sequence inference, and labelled isomorphism. In 2025/26 this is a full 15-mark question.

Directed networks: 2017/18, 2018/19, and 2021/22-2023/24 test weak and strong connectivity, strongly connected components, and the Bow-Tie diagram. It is absent from 2024/25 and 2025/26, so maintain coverage but revise it after the higher-return current core.

Markets and web networks: 2017/18 has the strongest evidence: game theory, a transport-network Nash equilibrium, matching and market-clearing prices, Bow-Tie, and PageRank. This directly supports official outcomes on markets and document networks, but it does not make them likely modern question slots.

Final Paper-Focused Rule

Prepare the recurring core first: BFS, centrality, Erdos-Renyi, Watts-Strogatz, graph foundations, bipartite projections, and Pruefer codes. Then cover directed, market, and document-network material from current teaching. The archive strongly supports the former as revision priorities; it does not authorise dropping the latter from the syllabus.
