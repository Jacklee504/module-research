BFS and Shortest Paths

Explore level by level to obtain unweighted shortest-path distances.

Purpose and relevance

BFS is the safest recurring local pattern and directly supports the official traversal outcome. In an unweighted graph it finds minimum-hop distance from a source.Exam use: Neighbour order, every queue transition, distances, predecessors and the requested reconstructed path agree.

What a question really asks — answer plan

Name the source, show queue/levels, record each first discovery’s predecessor, then report distances and BFS tree. Say “shortest in edges”, not necessarily lowest weight.Question interpretation: For traverse, obey the stated neighbour order; for shortest path, record predecessor as well as distance; for justify, invoke the layer invariant.

Prerequisites, vocabulary and formulas

  • Queue: FIFO frontier; predecessor: vertex that first discovers another.
  • dist(s)=0; first-discovered v from u gets dist(v)=dist(u)+1.
  • Predecessor edges form a BFS tree of the reachable component.
  • For positive weighted edges, use Dijkstra, not ordinary BFS.
  • Rapid recall: BFS uses a FIFO queue and assigns unweighted distance d(s,v) when v is first discovered; vertices leave the queue in nondecreasing distance.

Step-by-step method

  1. Discover and enqueue s with distance 0.
  2. Dequeue u; scan neighbours in stated order.
  3. For each undiscovered v, set predecessor u, distance+1, enqueue.
  4. Follow predecessors backwards to reconstruct a path.
  5. Exam workflow: Maintain queue, visited, distance and predecessor columns, and reconstruct a path by following predecessors backwards.

Worked starter question and model answer

Question: A-B, A-C, B-D, C-D; start A alphabetically.

Model answer: Levels: {A}, {B,C}, {D}. B←A, C←A, D←B; distances 0,1,1,2. A-B-D is one shortest A–D path; A-C-D is another.

Medium/hard paper-style synthesis

On edges AB, AC, BD, CE, DE, EF, run BFS from A with alphabetical neighbours. Queue states: [A]; after A, [B,C] with d=1; after B, [C,D] with d(D)=2; after C, [D,E] with d(E)=2; after D no new vertex; after E, [F] with d(F)=3. Predecessors A<-B<-D and A<-C<-E<-F show a shortest A-F path A-C-E-F of length 3.

Graduated practice

Prompt 1

What is an unreachable vertex’s BFS distance? Check: ∞/undefined and no predecessor.

Exam bridge

Give BFS pseudocode and find distances, predecessors and a spanning tree. Check: FIFO queue, first discovery only, level-based correctness, and note one tree does not list all ties.

Hard paper-style synthesis

Paper-style synthesis: add edge BF and rerun only affected layers. Check F moves from distance 3 to 2 with predecessor B; no vertex can have distance below its BFS discovery layer.

Common mistakes

  • Using a stack.
  • Overwriting predecessors after first discovery.
  • Applying BFS to arbitrary weighted edges.
  • Recovery rule: Mark a vertex visited when it is enqueued, not when dequeued, or duplicate queue entries can corrupt the predecessor tree.

Final checklist

  • Are queue order and tie-breaking visible?
  • Did I separate distances from tree edges?
  • Did I state the unweighted assumption?
  • Final 60-second audit: Neighbour order, every queue transition, distances, predecessors and the requested reconstructed path agree.

Past-paper note
