CS4423 Topic Guide

Centrality

Choose “important” according to the network role meant by the question.

Purpose and relevance

Centrality ranks vertices using different meanings of importance. It is a major repeat area and an explicit official learning outcome.Exam use: Metric choice, normalisation, distance/path evidence, tie handling and contextual interpretation are all shown.

What a question really asks — answer plan

Identify the role: direct ties, close access, route control or endorsement. State the formula, calculate visibly, rank vertices and interpret the result in context.Question interpretation: Translate 'many contacts' to degree, 'quick access' to closeness, 'broker' to betweenness and 'endorsed by important neighbours' to eigenvector centrality before calculating.

Prerequisites, vocabulary and formulas

  • Degree Cᴅ(v)=deg(v), optionally /(n−1).
  • Closeness C꜀(v)=(n−1)/Σᵤd(v,u).
  • Betweenness Cᴮ(v)=Σₛ≠v≠ₜσₛₜ(v)/σₛₜ.
  • Eigenvector: Ax=λx; important neighbours contribute more.
  • Rapid recall: Degree is local; closeness uses reciprocal total distance; betweenness splits credit among tied geodesics; eigenvector scores satisfy Ax=lambda x and require a stated normalisation.

Step-by-step method

  1. Check direction, disconnectedness and normalisation.
  2. Compute degrees or distance table.
  3. For betweenness, list shortest paths and split tied credit.
  4. Rank and explain what the metric captures/misses.
  5. Exam workflow: Build one distance table, list every unordered endpoint pair for betweenness, split sigma_st(v)/sigma_st, then interpret the ranking in the network's language.

Worked starter question and model answer

Question: Compare degree and betweenness in A-B-C.

Model answer: Degrees are 1,2,1; B is highest. B lies on the sole A–C shortest path, so its unnormalised betweenness is 1, versus 0 for A,C: B is an intermediary.

Medium/hard paper-style synthesis

For path A-B-C-D, degrees are (1,2,2,1). Distance sums are (6,4,4,6), so normalised closeness is (1/2,3/4,3/4,1/2). Of the six unordered pairs, B lies on A-C and A-D, giving raw betweenness 2; C lies on A-D and B-D, also 2; endpoints score 0. Thus B and C tie as access points and brokers, while degree alone cannot separate them.

Graduated practice

Prompt 1

Which measure suits “brokerage”? Check: betweenness, because it counts control of shortest routes.

Exam bridge

Calculate degree, closeness and betweenness; recommend one for information brokerage. Check: show paths, handle ties, choose betweenness, and do not claim all centralities mean the same thing.

Hard paper-style synthesis

Paper-style synthesis: add edge A-D and recompute betweenness. Check the graph becomes a 4-cycle; each vertex lies on the two equal shortest paths for its opposite pair and receives 1/2 raw credit, so all tie.

Common mistakes

  • Using edge count for closeness.
  • Giving every tied shortest path full betweenness credit.
  • Ignoring direction/disconnected vertices.
  • Recovery rule: When shortest paths tie, divide the contribution; counting every path as one inflates betweenness.

Final checklist

  • Did I state the convention?
  • Can paths be reproduced?
  • Did I interpret, not merely rank?
  • Final 60-second audit: Metric choice, normalisation, distance/path evidence, tie handling and contextual interpretation are all shown.
