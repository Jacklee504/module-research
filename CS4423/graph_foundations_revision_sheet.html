CS4423 Topic Guide

Graph Foundations

Describe a network precisely before trying to analyse it.

Purpose and relevance

Graph language turns a network into an object that can be counted, represented and analysed. It is foundational to the official outcome “describe a network in graph-theoretic terms”.Exam use: Vertex order, edge convention, matrix symmetry, row sums and an independent degree-sum check are visible.

What a question really asks — answer plan

State whether it is directed, weighted, simple or bipartite; define vertices and edges; then give the requested order, size, degrees or matrix. Label every representation.Question interpretation: For represent, state simple/directed/weighted conventions; for derive a matrix or degree sequence, fix vertex order first; for prove, use the handshake identity with the right edge convention.

Prerequisites, vocabulary and formulas

  • Order n=|V|; size m=|E|.
  • Undirected: Σdeg(v)=2m. Directed: Σin-deg=Σout-deg=m.
  • Tree: connected acyclic graph.
  • Adjacency matrix: Aᵢⱼ=1 (or a weight) when i is adjacent to j.
  • Rapid recall: For a simple undirected graph sum_v deg(v)=2|E|; adjacency is symmetric with zero diagonal; a simple graph with n vertices has at most n(n-1)/2 edges.

Step-by-step method

  1. List V and E, including directions/weights.
  2. Count n and m; tabulate degrees.
  3. Use the handshaking check.
  4. Build A in one stated vertex order.
  5. Exam workflow: Write V and E, freeze an ordering, construct the adjacency list and matrix independently, then use row sums and the handshake lemma as checks.

Worked starter question and model answer

Question: V={A,B,C}, E={{A,B},{B,C}}. Give n, m, degrees and A in order A,B,C.

Model answer: n=3, m=2; degrees are 1,2,1 and sum to 4=2m. A=[[0,1,0],[1,0,1],[0,1,0]]. It is a connected tree.

Medium/hard paper-style synthesis

For V={a,b,c,d} and E={ab,ac,bc,cd}, order a,b,c,d. The adjacency rows are 0 1 1 0; 1 0 1 0; 1 1 0 1; 0 0 1 0. Degrees (2,2,3,1) sum to 8=2|E|. The graph is connected, contains triangle abc, and is not bipartite because of that odd cycle.

Graduated practice

Prompt 1

A→B, A→C, C→A: give A’s degrees. Check: in=1, out=2.

Exam bridge

Represent an attributed transport or social network and explain graph choices. Check: define vertex/edge semantics, justify direction/weight, give a labelled representation and one limitation.

Hard paper-style synthesis

Paper-style synthesis: can a simple graph have degree sequence (3,3,1,1)? Check the sum is 8, but Havel-Hakimi gives (2,0,0) after removing a 3, then (-1,-1) after removing 2; therefore it is not graphical.

Practice question - representation and feasibility [8 marks]

Inspired by: CS4423 2024/25 Q1(a-c). Scenario. Can a simple connected graph of order 5 and size 8 be a tree? Can a simple graph of order 5 have size 12? Justify both conclusions. [8 marks]

Demand diagnosis and fastest route: both are invariant checks, so use the tree edge formula and the simple-graph maximum rather than attempting sketches.

Worked answer: A tree on n vertices has n-1 edges, so a tree of order 5 has 4 edges. A connected graph of order 5 and size 8 can exist, but it cannot be a tree because 8≠4; it contains cycles. A simple graph on five vertices has at most C(5,2)=10 edges, attained only by K5. Therefore a size-12 simple graph is impossible, irrespective of connectedness. A valid size-8 example is K5 with any two edges deleted while retaining connectivity.

Topic-specific trap: the handshaking lemma alone permits degree sum 24; it does not override the pairwise-edge maximum.

Common mistakes

  • Counting an undirected edge twice.
  • Using a symmetric matrix for a directed graph.
  • Calling every connected graph a tree.
  • Recovery rule: A plausible even degree sum is necessary but not sufficient for a sequence to be graphical.

Final checklist

  • Did I define vertices and edges?
  • Are labels and directions explicit?
  • Did I check degree sums?
  • Final 60-second audit: Vertex order, edge convention, matrix symmetry, row sums and an independent degree-sum check are visible.
