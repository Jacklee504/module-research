Medium/hard adapted practice

(a) Given an undirected edge list, form A and verify the degree sum. [8 marks]

Question demand: apply the definition/calculation with working. Quickest route: Fix a vertex order; put Aij=1 exactly when {vi,vj} is an edge; read row sums.

Mark-aware answer: A is symmetric with zero diagonal for a simple loop-free graph. Sum the row degrees and check it equals twice the stated number of edges; this catches omitted or doubled edges.

Trap: Do not silently change a directed graph into an undirected one.

(b) State and prove the handshaking lemma for a simple undirected graph. [6 marks]

Question demand: Count edge incidences two ways. Quickest route: Count edge incidences two ways.

Mark-aware answer: Each edge has exactly two endpoints, so counting incidences by edges gives 2|E|. Counting them by vertices gives sumvdeg(v). Therefore sum degrees=2|E|, and in particular the number of odd-degree vertices is even.

Trap: Loops or directed edges require a stated convention.

(c) Convert an adjacency matrix to a degree list and identify an isolated vertex. [4 marks]

Question demand: Sum each row (and use symmetry only if the graph is undirected). Quickest route: Sum each row (and use symmetry only if the graph is undirected).

Mark-aware answer: For a simple undirected graph, row i sum equals deg(v_i); a zero row identifies an isolated vertex. Check the total against twice the number of 1s above the diagonal.

Trap: Counting both halves of a symmetric matrix as edges doubles the size.
