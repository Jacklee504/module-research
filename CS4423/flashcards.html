1. Graph Foundations and Bipartite Networks

FrontBackEvidence
Order and size of a graph?Order |V|: number of vertices. Size |E|: number of edges.2021/22 Q1; 2022/23-2023/24 Q1; 2024/25 Q1; 2025/26 Q1
How many edges has a spanning tree of a connected graph of order n?n − 1. Every tree on n vertices has exactly n − 1 edges.2024/25 Q1; 2025/26 Q1
Quick graphicality screen for a degree sequence?Necessary, not sufficient: every di is in {0, …, n − 1} and Σ di is even. If both pass, use Havel-Hakimi to decide.2018/19 Q1; 2025/26 Q1
Adjacency-matrix rule?After fixing a vertex order, Aij = 1 iff {i, j} is an edge; otherwise 0. For a simple undirected graph, A is symmetric with zero diagonal.2022/23-2023/24 Q1; 2024/25 Q1; 2025/26 Q1
Bipartite: definition and quick test?Vertices can be 2-coloured so every edge joins different colours. Equivalently, the graph has no odd cycle.2017/18 Q3; 2023/24 Q2; 2024/25 Q2; 2025/26 Q2
Bipartite adjacency-matrix block form?List the two parts together: A = [0 C; CT 0]. The zero diagonal blocks mean no within-part edges.2025/26 Q2
One-mode projection of a bipartite graph?Keep one part as vertices; join two of them when they share a neighbour in the other part. A weighted projection can use their number of shared neighbours.2024/25 Q2; 2025/26 Q2

2. BFS and Shortest Paths

FrontBackEvidence
What does BFS give from a root s?Distance layers from s; a BFS tree if one parent per vertex is kept; and all shortest-path predecessors if every valid parent is kept.All 7 papers; especially 2024/25-2025/26 Q4(a)
Core BFS discovery rule?Set d(s) = 0 and use a FIFO queue. On first discovery of v from u, set d(v) = d(u) + 1 and enqueue v.All 7 papers
BFS distance fact?In an unweighted graph, d(v) is the fewest edges on any path from s to reachable v.2017/18-2025/26 BFS questions
All predecessors versus one BFS-tree parent?A BFS tree chooses one parent. For all shortest paths, keep every neighbour u with d(u) = d(v) − 1 as a predecessor of v.2018/19 Q1; 2023/24 Q1; 2024/25-2025/26 Q4
How to list all shortest paths after BFS?Backtrack from the target through every stored predecessor until s; reverse each chain.2018/19 Q1; 2023/24 Q1; 2024/25-2025/26 Q4

3. Centrality

FrontBackEvidence
Degree and normalised degree centrality?CD(v) = deg(v). For a simple graph of order n, normalised degree centrality is deg(v) / (n − 1).2018/19 Q2; 2021/22 Q2; 2022/23-2025/26
Closeness centrality?For connected graph of order n, CC(v) = (n − 1) / Σu ≠ v d(v, u). Larger means shorter average distances.2018/19 Q2; 2021/22 Q2; 2022/23-2025/26
Betweenness centrality?CB(v) = Σ σst(v) / σst over unordered pairs s, t excluding v.2018/19 Q2; 2021/22 Q2; 2022/23-2025/26
Why count fractions in betweenness?If two shortest paths connect a pair and only one uses v, that pair contributes ½, not 1.2022/23 Q2; 2023/24 Q2; 2025/26 Q5
Normalised betweenness in an undirected graph?Divide raw betweenness by (n − 1)(n − 2) / 2.2018/19 Q2; 2022/23 Q2; 2023/24 Q2
Eigenvector centrality idea?A node is central when it connects to central nodes. Its score is proportional to the sum of neighbour scores, so it is an eigenvector of the adjacency matrix.2018/19 Q2; 2022/23 Q2; 2023/24 Q2
Degree versus closeness?High degree is many direct neighbours. High closeness is short routes to the whole graph. A node can be high in one and low in the other.2024/25 Q3; 2025/26 Q5

4. Random Graphs

FrontBackEvidence
GER(n, m) versus GER(n, p)?GER(n, m) chooses uniformly among graphs with exactly m edges. GER(n, p) independently includes each possible edge with probability p.2018/19 Q3; 2021/22-2025/26
Empty and complete graph parameters?Empty: m = 0 or p = 0. Complete: m = n(n − 1) / 2 or p = 1.2024/25 Q6; 2025/26 Q6
Expected number of edges in GER(n, p)?E[|E|] = p × n(n − 1) / 2.2023/24 Q3; 2025/26 Q6
Degree distribution in GER(n, p)?For a fixed vertex, deg(v) ∼ Binomial(n − 1, p). Thus P(deg(v) = k) = n − 1kpk(1 − p)n − 1 − k.2018/19 Q3; 2021/22-2024/25 degree-probability variants
Probability of exactly m edges in GER(n, p)?Nmpm(1 − p)N − m, where N = n(n − 1) / 2.2021/22 Q3; 2022/23 Q3; 2023/24 Q3; 2024/25 Q6
Giant component threshold idea?Critical scale: average degree np ≍ 1, so p is of order 1 / n.2021/22 Q3; 2022/23 Q3

5. Small-World Networks

FrontBackEvidence
Characteristic path length?The average shortest-path distance between pairs of vertices in a connected graph.2025/26 Q7
Node clustering coefficient?For node v, it is the fraction of possible edges between neighbours of v that actually exist.2018/19 Q4; 2024/25 Q7
Transitivity of a graph?3 × (number of triangles) / (number of connected triples). It is a global clustering measure.2025/26 Q7
Transitivity/clustering in GER(n, p)?It is p: conditional on two edges forming a connected triple, the closing edge exists independently with probability p.2018/19 Q4; 2024/25 Q7; 2025/26 Q7
Watts-Strogatz signature?Compared with a circle graph, limited rewiring gives much shorter paths while retaining high clustering. Compared with Erdos-Renyi, it retains higher clustering.2018/19 Q4; 2021/22-2025/26

6. Trees and Pruefer Codes

FrontBackEvidence
Pruefer code length of a labelled tree on n nodes?n − 2.2021/22 Q1; 2022/23 Q4; 2023/24 Q4; 2024/25 Q5; 2025/26 Q3
Degree from a Pruefer code?deg(v) = 1 + the number of times v appears in the code.2021/22 Q1; 2022/23 Q4; 2024/25 Q5; 2025/26 Q3
Which labels occur in a Pruefer code?Exactly the vertices with degree > 1. The number of distinct labels is the number of non-leaves.2025/26 Q3
Tree-to-Pruefer encoding routine?Repeatedly remove the smallest-labelled leaf and record its neighbour. Stop when two vertices remain.2022/23 Q4; 2023/24 Q4; 2024/25 Q5
Pruefer-code-to-tree routine?At each code entry, join it to the smallest label absent from the remaining code, remove that leaf and entry, then join the final two labels.2021/22 Q1; 2024/25 Q5; 2025/26 Q3
Labelled isomorphic but unequal trees?They have the same shape but different edge sets under the fixed labels. Give a bijection of labels that preserves adjacency.2025/26 Q3

7. Directed, Market, and Web Networks

FrontBackEvidence
Strong versus weak connectedness?Strong: every ordered pair has directed paths both ways. Weak: the underlying undirected graph is connected.2017/18 Q4; 2018/19 Q4; 2021/22-2023/24 Q4
Strongly connected components?Equivalence classes of mutual reachability: u ∼ v iff there is a directed path u → v and one v → u.2017/18 Q4; 2018/19 Q4; 2021/22-2023/24 Q4
Bow-Tie diagram core?IN → SCC → OUT, with tendrils, tubes, and disconnected components around the core.2017/18 Q4; 2018/19 Q4; 2021/22-2023/24 Q4
PageRank input and equilibrium?Input: a directed web graph. Output: node scores. Equilibrium: a score vector unchanged by the PageRank update.2017/18 Q4
Market-network coverage cue?Know Nash equilibrium, transport networks, matching, market-clearing prices, and bipartite auctions. Treat as low recent priority.2017/18 Q2-Q3; official learning outcome
