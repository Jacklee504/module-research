(a) A signed triangle has edges +,+,-. Is it balanced, and what is the quickest check? [6 marks]

Question demand: apply the definition/calculation with working. Quickest route: Multiply signs or count negative edges.

Mark-aware answer: The product is negative (one negative edge), so the triangle is unbalanced. Equivalently a balanced signed triangle has zero or two negative edges.

Trap: Do not treat this background page as evidence of a fixed upcoming question.

(b) Write one PageRank update with damping d. [6 marks]

Question demand: State teleportation plus incoming contributions divided by out-degree. Quickest route: State teleportation plus incoming contributions divided by out-degree.

Mark-aware answer: For N vertices, PR(v)=(1-d)/N+d sumu->vPR(u)/outdeg(u), with a stated dangling-node treatment. Iterate from an initial distribution until the requested tolerance.

Trap: Do not pass all rank from a dangling node nowhere.

(c) Model a transport problem as a network and name one useful metric. [4 marks]

Question demand: Specify vertices, edges, weight/direction, then tie the metric to the question. Quickest route: Specify vertices, edges, weight/direction, then tie the metric to the question.

Mark-aware answer: Represent stations as vertices and routes as edges; use directed/weighted edges if travel time differs by direction. Betweenness can identify transfer bottlenecks, while weighted shortest paths give fastest journeys.

Trap: This is background coverage; do not assert it is a recent repeated family.
