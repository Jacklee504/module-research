CS4423 Topic Guide

Small-World Networks

Explain how a few shortcuts can preserve local clustering while shrinking paths.

Purpose and relevance

The Watts–Strogatz model explains networks that are locally clustered yet globally reachable. Local papers repeatedly pair it with clustering and path length.Exam use: Baseline, rewiring rule, path-length evidence, clustering evidence and the trade-off across beta are all addressed.

What a question really asks — answer plan

Describe the starting ring lattice, the rewiring probability p, and compare low/high p. Then connect p to clustering C and characteristic path length L; never just call a graph “small world” without the comparison.Question interpretation: For explain, compare path length and clustering to a random and a regular baseline; for construct, state the rewiring convention and what remains fixed.

Prerequisites, vocabulary and formulas

  • Clustering coefficient: fraction of possible neighbour-neighbour links that exist.
  • Characteristic path length: average shortest-path distance.
  • Watts–Strogatz: ring lattice → randomly rewire each edge with probability p.
  • Small-world signature: high C relative to random graph, low L comparable to random graph.
  • Rapid recall: A small-world network combines high local clustering with short characteristic path length; Watts-Strogatz interpolates from a ring lattice (beta=0) toward a random graph as beta increases.

Step-by-step method

  1. Specify n, local neighbourhood k and p.
  2. Describe p=0 lattice and p≈1 random-like endpoint.
  3. Explain how a small p adds shortcuts.
  4. Compare C and L against appropriate baselines.
  5. Exam workflow: Compute local clustering from edges among neighbours, calculate representative shortest paths or mean length, then interpret both metrics together.

Worked starter question and model answer

Question: What changes when p increases slightly from 0?

Model answer: A few long-range edges create shortcuts, so L can fall sharply. Many local triangles remain, so C initially stays relatively high: this is the small-world region.

Medium/hard paper-style synthesis

Take the 6-cycle and add shortcut A-D. Originally d(A,D)=3; now it is 1. Distances from A change from (to B,C,D,E,F)=(1,2,3,2,1), sum 9, to (1,2,1,2,1), sum 7. One shortcut lowers access distance, but the plain cycle still has local clustering 0; therefore this graph alone demonstrates short paths, not the full small-world combination.

Graduated practice

Prompt 1

At p=0, what structure is generated? Check: the original regular ring lattice.

Exam bridge

Compare a ring lattice, Watts–Strogatz graph and Erdős–Rényi graph using C and L. Check: lattice high C/high L; random low C/low L; small-world high C with low L after limited rewiring.

Hard paper-style synthesis

Paper-style synthesis: in a ring where each vertex links to its two nearest neighbours on each side, explain why clustering is positive and what a few long-range rewirings do. Check neighbours share lattice edges, while shortcuts reduce long geodesics; excessive rewiring eventually destroys much local clustering.

Practice question - recognise a small-world comparison [8 marks]

Inspired by: CS4423 2024/25 Q7(a-c). Scenario. Compare a degree-4 ring lattice, a lightly rewired Watts-Strogatz graph, and an Erdős-Rényi graph of comparable mean degree using clustering C and characteristic path length L. [8 marks]

Demand diagnosis and fastest route: this is a matched comparison, so state both metrics for every model and explain the effect of a few shortcuts.

Worked answer: A ring lattice has high C because neighbours share nearby lattice neighbours, but high L because travelling between remote regions takes many local steps. A lightly rewired WS network retains many local triangles, so C remains relatively high, while a small number of long-range edges sharply reduces L. This is the small-world combination. An ER graph of comparable mean degree typically has short paths but much lower local clustering, because its independent edges do not preserve neighbourhood structure. Excessive WS rewiring approaches the random case and removes the local clustering advantage.

Topic-specific trap: low path length alone does not prove small-world structure; the high-clustering comparison is essential.

Common mistakes

  • Saying more rewiring always improves “small-worldness”.
  • Confusing clustering with density.
  • Ignoring the baseline comparison.
  • Recovery rule: Short average paths alone do not establish a small world; the clustering comparison is a separate required claim.

Final checklist

  • Can I state the construction?
  • Can I explain C and L?
  • Did I contrast both baselines?
  • Final 60-second audit: Baseline, rewiring rule, path-length evidence, clustering evidence and the trade-off across beta are all addressed.
