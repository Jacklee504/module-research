Fault Tolerance and Redundancy

Use the older fault-tolerance material as a principled background topic, with cautious scope.

Rapid exam refresher

  • Reliability and availability differ; redundancy needs independent faults, detection and switchover.
  • RAID-0 no redundancy; RAID-1 mirror; RAID-5 distributed parity and one disk tolerance.
  • SEC corrects one bit; SECDED detects double but normally cannot correct it; voters/common-mode faults limit NMR.

Paper evidence and scope

Lower-priority/historical: RAID/Hamming/redundancy occur 2017/18, 2018/19 and 2021/22–2023/24; current emphasis is elsewhere.

Medium practice — 15 marks

One-disk tolerance and memory errors. (a) [5] RAID. (b) [5] ECC. (c) [5] common mode.

Answers

(a): RAID-5 parity tolerates one disk; RAID-1 capacity trade-off. (b): SEC one correction; SECDED double detection. (c): shared controller/power/voter defeats replicas. Trap: RAID is backup.

Hard practice — 15 marks

Three sensors produce 100, 101 and 175°C; controller votes and stores readings on RAID-5. Later one disk fails during rebuild. (a) [5] work voting/fault response. (b) [5] explain RAID state. (c) [5] state a safe architecture improvement.

Answer for every part

(a) Demand / quickest route / worked answer / trap

Route: choose majority/median then state diagnostic. Answer: 100/101 agree within tolerance, so vote ≈100.5°C (or 101 under specified integer policy); flag/isolate 175 sensor and log disagreement. Credit: majority value 2, tolerance assumption 1, diagnostic/safe action 2. Trap: averaging 175 with healthy values.

(b)

Route: apply RAID-5 one-failure rule. Answer: array remains available after first disk failure using parity reconstruction, but is degraded; rebuild reads surviving blocks/parity onto replacement. A second disk failure before rebuild completes loses array. Credit: tolerance 2, rebuild 2, risk 1. Trap: RAID-5 survives two failures.

(c)

Route: address independence and recovery objective. Answer: add tested off-array backup/replica, independent power/controller paths and monitor rebuild; define safe controller state if no sensor majority. This reduces common-mode/rebuild-window risk, not all failures. Trap: adding disks alone is a backup strategy.
