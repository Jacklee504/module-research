Scheduling and Schedulability

Turn periodic task data into a clear feasibility argument.

Rapid exam refresher

  • RM short period fixed priority.
  • EDF earliest absolute deadline.
  • CE frames.

Purpose, scope and examiner demand

Scheduling decides which ready task runs. In an exam, calculate the stated test carefully, then explain what its pass or failure does (and does not) prove.

Exam focus by part

  • RM short period fixed priority.
  • EDF earliest absolute deadline.
  • CE frames.
  • R=C+B+Σceil(R/Tj)Cj.
  • cue sort/iterate/compare D.

Question-demand diagnosis and answer plan

  1. Record each task's execution time C, period T, and deadline D.
  2. Identify fixed priority (Rate Monotonic), dynamic priority (EDF), or a cyclic executive.
  3. Compute utilisation and apply the requested bound; if needed, build a timeline/response-time argument.
  4. State assumptions: independent pre-emptible tasks and deadline relationship.

Question-type cues

  • Application cue: EDF test (1,4),(2,5),(1,10), D=T.
  • Analysis cue: Under pre-emptive RM with no blocking, analyse τ1=(C=1,T=D=4), τ2=(C=2,T=D=5), and τ3=(C=4,T=D=20). The utilisation bound fails; determine whether τ3 nevertheless meets its deadline using response-time analysis.

Definitions, notation and discriminating comparisons

  • Utilisation: U = sum(Ci/Ti). Hyperperiod: least common multiple of periods.
  • RM: shorter period means higher fixed priority. For n periodic tasks with D=T, sufficient bound U ≤ n(21/n-1).
  • EDF: task with earliest absolute deadline runs first. On one ideal processor with D=T, U ≤ 1 is the classic feasibility condition.
  • Cyclic executive: static table of frames; overrun means work exceeds its budget.

Step-by-step methods and solution routes

Given A: C=1, T=4 and B: C=2, T=10, U=1/4+2/10=0.45. Under RM, A has higher priority. For n=2, the sufficient bound is 2(sqrt(2)-1) ≈ 0.828, so the bound passes. That proves schedulability under its assumptions; it is not a general claim about blocking, I/O, or changed deadlines.

Worked examples and method extensions

Question

Use EDF to assess tasks (C,T)=(2,5) and (3,10), with deadlines equal to periods.

Model answer

U=2/5+3/10=0.7. EDF's ideal single-processor test is U≤1, so 0.7 passes. At time 0 EDF can run the first job for 2 ms (deadline 5), then the second for 3 ms (deadline 10); both complete before their deadlines. The conclusion assumes the stated model and negligible overhead.

Exam-paper-led practice

Practice question 1 [medium/hard]

Scenario and demand: Under pre-emptive RM with no blocking, analyse τ1=(1,4), τ2=(2,5), τ3=(4,20), all D=T. The RM bound fails; decide τ3 by response-time analysis. [9 marks]

Question-demand diagnosis and fastest route: Priorities are τ1,τ2,τ3. U=.25+.4+.2=.85, above the three-task sufficient bound ≈.779, so failure is inconclusive. Iterate R3=4+ceil(R3/4)·1+ceil(R3/5)·2: 4→7→10→11→13→14→14. Thus R3=14≤20; R1=1≤4 and R2=3≤5, so all meet deadlines under the model. Trap: treating a failed RM sufficient bound as unschedulable.

Practice question 2 [medium/hard]

Scenario and demand: Construct an EDF-feasible but non-RM-feasible task set, then explain the evidence required. [8 marks]

Question-demand diagnosis and fastest route: Use a known constrained-deadline/task example only after listing C,T,D and releases; compute total utilisation, draw the relevant timeline and perform RM response-time/schedulability analysis. Credit comes from a concrete counterexample, not the assertion that EDF is “better.” Under D=T on one processor, EDF U≤1 is its classic condition; RM needs its own analysis. Trap: using only an RM bound failure, which is not proof of RM failure.

Topic-specific traps and diagnosis

  • Calling the RM bound necessary; it is normally sufficient.
  • Using U≤1 for RM as though it were EDF.
  • Ignoring release times, blocking, overhead, or D different from T.

Exam marking checklist

  • Are C, T, D and priorities labelled?
  • Is every fraction and inequality shown?
  • Did I state the model assumptions?
