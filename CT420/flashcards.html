1. Time Synchronisation And Clocks

FrontBackPapers
What is the difference between time synchronisation and timing synchronisation?Time synchronisation aligns clock values; timing synchronisation coordinates when actions occur. A system can need one, the other, or both.2017/18
Define clock accuracy, stability, offset, and skew.Accuracy is closeness to a reference; stability is consistency of the oscillator rate; offset is the instantaneous clock difference; skew is the rate at which offset changes.2024/25
What is NTP round-trip delay?With client send t1, server receive t2, server send t3, client receive t4: RTD = (t4 − t1) − (t3 − t2).2017/18–2018/19
What is the usual NTP offset calculation?For the server-minus-client convention: θ = ((t2 − t1) + (t3 − t4)) / 2. State the convention because the sign reverses under the opposite definition.2017/18–2018/19
Why is NTP robust?It can select and filter multiple sources, reject unreliable peers, use strata, and discipline the local clock. Its estimates still depend on network delay symmetry and source quality.2021/22
What should an ntpq comparison discuss?Reachability, selected peer, redundancy, stratum, delay, offset, and jitter. Do not choose using a single column alone.2017/18, 2018/19, 2021/22
What is PTP’s basic purpose?PTP distributes highly accurate time on a suitable network, usually from a selected grandmaster to slave clocks, aided by precise timestamping and delay measurement.2021/22–2025/26
What is the role of Sync, Follow_Up, Delay_Req, and Delay_Resp in two-step PTP?Sync announces timing; Follow_Up supplies the precise origin timestamp; the slave sends Delay_Req and receives Delay_Resp so path delay and clock offset can be estimated.2024/25–2025/26
Boundary clock versus transparent clock?A boundary clock synchronises upstream then serves downstream segments. A transparent clock records and corrects switch residence time; it is not the grandmaster.2021/22–2025/26
What is P2P versus E2E delay measurement in PTP?E2E estimates delay between slave and master across the path. P2P measures each adjacent link; transparent clocks can account for their own residence time. Use the scheme requested by the topology.2021/22, 2024/25–2025/26
What do the BMCA and Berkeley algorithm do?BMCA selects the best PTP master and can support failover. Berkeley polls local clocks, averages usable offsets, and issues corrections; it synchronises internally unless an external reference is included.2021/22–2025/26

2. Scheduling, Cyclic Executives And WCET

FrontBackPapers
What do C, T, and D represent for a periodic task?C is execution time (use WCET for a proof), T is period or minimum inter-arrival time, and D is relative deadline.2017/18–2025/26
What is utilisation and the hyperperiod?U = Σ(Ci/Ti). The hyperperiod is the least common multiple of the task periods, after which a periodic release pattern repeats.2017/18–2025/26
What is a cyclic executive?A static, table-driven schedule of task calls in fixed frames. It is predictable but adapts poorly to changes and must account for asynchronous interrupts and overruns.2018/19–2025/26
How should a cyclic executive detect an overrun?Record a frame or cycle start time, execute the planned tasks, compare elapsed time with the frame budget, then increment a counter and run the specified recovery or reporting action when late.2021/22–2025/26
How does Rate Monotonic assign priority?RM gives the shortest-period task the highest fixed priority. It is normally analysed for periodic, independent, pre-emptible tasks under stated deadline and blocking assumptions.2017/18–2025/26
How does EDF assign priority?Earliest Deadline First gives highest dynamic priority to the ready job with the earliest absolute deadline.2017/18, 2022/23–2023/24
What is the classic EDF feasibility condition?On one ideal pre-emptive processor for independent periodic tasks with D = T and negligible overhead, EDF is feasible when U ≤ 1.2017/18, 2022/23–2023/24
What is the RM utilisation bound?For n periodic tasks with D = T, U ≤ n(21/n − 1) is sufficient. A failure of this bound is inconclusive, not proof of an unschedulable set.2017/18, 2022/23–2025/26
What is the fixed-priority response-time recurrence?For task i, iterate Ri = Ci + Bi + Σj∈hp(i) ⌈Ri / Tj⌉Cj; it passes when the fixed point Ri ≤ Di.Scheduling method
How do you estimate WCET from code?Bound every loop and recursion, identify feasible branches, sum the longest feasible path, and include relevant interrupt, cache, I/O, or blocking effects. Average timing is not WCET.2018/19, 2021/22
What must a schedule answer show for marks?Task data, priority or policy, arithmetic, a labelled timeline over the requested interval, and the assumption under which the conclusion holds.2023/24–2025/26

3. POSIX, Mutexes And Priority Protocols

FrontBackPapers
What is a mutex or binary semaphore used for?It gives mutually exclusive access to a critical region. A task acquires it before the region and releases it promptly afterwards; the answer should define the blocking behaviour.2025/26
What is priority inversion?A high-priority task waits for a resource held by a low-priority task while medium-priority work can pre-empt the holder, extending the high-priority task’s delay.2017/18, 2023/24–2024/25
How does Priority Inheritance help?The low-priority lock holder temporarily inherits the blocked high-priority task’s priority, so medium-priority tasks cannot extend the inversion until the lock is released.2023/24–2024/25
How does the Priority Ceiling Protocol prevent deadlock?Each resource has a ceiling based on its potential users. A protocol prevents a task making an unsafe acquisition while another resource’s ceiling would create circular wait, thereby bounding blocking and avoiding deadlock.2017/18, 2021/22–2022/23
Why use memory locking in a hard real-time process?Locking resident pages prevents a page fault from causing an unbounded delay on the critical execution path. Explain it with the process-state model if asked.2017/18–2018/19, 2024/25–2025/26
What is the risk of locking memory too generously?It reduces memory available to the rest of the system, can increase pressure elsewhere, and may require privilege. Lock only the verified real-time working set.2017/18–2018/19
What does POSIX sigqueue add to a signal?It sends a signal to a process together with a value in sigval, enabling queued notification with application data under the relevant signal-handling rules.2017/18, 2022/23
Name four RTOS or POSIX-style capabilities worth justifying.Deterministic priority scheduling, high-resolution timers / clocks, signals or IPC, memory locking, synchronisation primitives, predictable I/O, and bounded interrupt handling. Tie each capability to a real-time need.2025/26
What makes code non-re-entrant?It relies on shared mutable state, such as a static variable or shared buffer, so an interrupt or concurrent call can corrupt the computation. Make state local, protect it, or redesign the interface.2018/19
What are the core parts of a priority-protocol diagram?Show the resource owner, blocked high-priority task, interfering medium-priority task, priorities over time, lock acquisition / release, and the exact point at which the protocol changes execution.2017/18, 2021/22–2024/25

4. QUIC, HTTP And Protocol Analysis

FrontBackPapers
Why was HTTP/2 developed, and what are key features?It addresses HTTP/1 inefficiencies such as many connections and poor request use. Key features include binary framing, stream multiplexing, header compression, and prioritisation; its streams still run over TCP.2024/25
What is TCP transport-level head-of-line blocking?TCP delivers one ordered byte stream. A lost earlier segment prevents delivery of later bytes, even if they belong to an unrelated HTTP/2 application stream.2023/24–2025/26
How does QUIC reduce transport-level head-of-line blocking?QUIC has independently ordered streams, so loss in one stream need not delay delivery on another. Congestion and loss can still affect the shared connection.2023/24–2025/26
How does QUIC connection establishment differ from TCP plus TLS?QUIC integrates TLS into the transport handshake over UDP and can reduce setup round trips. It does not remove RTT, packet loss, or server-processing delay.2023/24–2024/25
What does congestion control do in QUIC?It estimates congestion from signals such as loss and RTT, adjusts sending behaviour, and aims to avoid persistent overload while balancing throughput and latency.2023/24–2025/26
Throughput fairness versus latency fairness?Throughput fairness shares capacity comparably; latency fairness avoids one flow imposing excessive queueing delay on another. The balance is harder with mixed TCP and QUIC traffic.2025/26
Why encrypt QUIC transport metadata, and what trade-off follows?Encryption protects users and reduces unwanted ossification by middleboxes, but limits passive network inspection and makes operators depend more on endpoint telemetry or authorised decryption.2025/26
What do Wireshark, qLog, and qViz each contribute?Wireshark shows packet-level traffic but encrypted QUIC limits interpretation. qLog records endpoint transport events; qViz visualises qLog timelines to diagnose streams, loss, and congestion.2023/24–2025/26
What is QUIC connection migration?It lets a connection continue when the client’s network path changes, such as Wi-Fi → 5G, after path validation. It can reduce disruption but does not guarantee no freeze.2025/26
What can a resource waterfall reveal?It separates stages such as connection, request waiting / first byte, and transfer, helping distinguish server or queueing delay from a slow download. Correlate it with other evidence.2023/24

5. Soft Real-Time, QoS And Multimedia

FrontBackPapers
What components make up end-to-end delay for interactive cloud gaming?Input / capture, game or application processing, encoding, queueing, network transmission, loss recovery, decoding, buffering, and playout. The most critical components depend on the interaction loop.2024/25–2025/26
Intrinsic QoS versus perceived QoS / QoE?Intrinsic QoS is measurable delivery quality, such as delay, jitter, loss, and bitrate. Perceived QoS or QoE is the user’s experienced smoothness, responsiveness, and quality.2017/18, 2024/25
What does a jitter buffer do?It delays playout briefly to smooth packet-delay variation. A larger buffer reduces underflows but adds latency; adaptive buffers adjust this trade-off as conditions change.2024/25
What is Forward Error Correction (FEC) for VoIP?It adds redundant information so some loss can be recovered without retransmission. The cost is extra bandwidth, processing, and sometimes delay; the strategy may be media dependent or independent.2017/18–2018/19
How does adaptive-bitrate streaming work?The client estimates available conditions and selects segment representations to balance continuity, quality, rebuffering risk, and latency. It alone cannot satisfy all highly interactive real-time demands.2025/26
What is response delay in cloud gaming?The time from a user action to the visible or audible response, including processing, network, encoding / decoding, and playout delays. A good answer traces the full loop.2024/25
Why can more bandwidth fail to fix a laggy game?Input, processing, queueing, RTT, jitter, loss, encoding, and playout may dominate. Diagnose the full delay budget rather than equating bandwidth with low latency.2024/25–2025/26
What are RTP and RTCP used for?RTP carries real-time media data. RTCP carries control and feedback information; sender and receiver reports describe transmission and reception quality.2017/18
What do LCP, FID, and CLS measure?LCP measures perceived loading of the largest content; FID measures input responsiveness delay; CLS measures unexpected visual movement during loading.2023/24

6. Fault Tolerance, Hamming And Storage

FrontBackPapers
What is Hamming distance?The number of bit positions in which two codewords differ. The minimum distance determines the combinations of errors a code can detect or correct.2025/26
What does Hamming (7, 4) provide?It encodes four data bits into seven bits using parity positions. With suitable parity it corrects a single-bit error; its ability to detect additional errors depends on the exact scheme and extension stated.2021/22, 2023/24, 2025/26
RAID-0 versus RAID-1 versus RAID-5?RAID-0 stripes for performance with no redundancy; RAID-1 mirrors data; RAID-5 stripes data with distributed parity and can recover from one disk failure, with parity-write overhead.2021/22–2022/23
What is the fault → error → failure chain?A fault is a cause, an error is an incorrect internal state, and a failure is an externally visible service deviation. Name the layer a mechanism handles.Fault-tolerance method
Why does replica independence matter?Voting or redundancy only masks failures that are not shared. Common software, power, environment, specification, or voter faults can defeat every replica.2017/18–2018/19
What is backward recovery?Restore a saved consistent state after error detection, then retry or take an alternative path. External side effects must be logged or idempotent because rollback cannot unsend them.2022/23
What are FMV, GMV, FPV, and weighted averaging?They are voter rules for redundant outputs: formalised majority, generalised median, formalised plurality, and a weighted average. State the rule and calculate from the supplied data.2018/19, 2021/22

7. Logical Clocks And Causality

FrontBackPapers
What does a Lamport logical clock guarantee, and what does it miss?If event a happened-before b, then L(a) < L(b). The reverse is not enough to prove causality, so scalar timestamps cannot detect concurrent events.2022/23–2024/25
Why do vector clocks capture causality better?Each process carries one counter per process. Vector Va < Vb component-wise indicates happened-before; incomparable vectors indicate concurrency.2022/23–2024/25
