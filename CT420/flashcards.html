1. Time, Clocks And Navigation

1.1 Clock Concepts

FrontBackEvidence since 2021/22
Define clock accuracy, stability, offset, and skew.Accuracy is closeness to a reference clock; stability is consistency of an oscillator’s rate over time and conditions; offset is the instantaneous difference between clocks; skew is the rate at which that offset changes.2024/25
How does a quartz-based computer clock develop offset and skew?A quartz oscillator drives periodic timer ticks. A frequency error accumulates into clock offset; a roughly constant frequency error is skew. Temperature, ageing, and jitter change the rate, while isolated outliers usually indicate a separate disturbance or correction.2022/23
What must a skew-compensating clock handler do?On each bounded timer interrupt, add the nominal tick plus a signed correction to the stored time, normalise nanoseconds into seconds, and update the correction from a synchronisation estimate. State the sign convention and avoid unbounded work in the handler.2024/25
How does the Berkeley algorithm synchronise clocks?A coordinator polls clocks, discards unusable outliers, averages the remaining offsets, then sends each clock a correction. It synchronises a group internally; it needs an external reference if the group must track UTC.2022/23, 2024/25–2025/26

1.2 NTP

FrontBackEvidence since 2021/22
When should NTP and PTP work together, and why is NTP robust?NTP filters and selects among multiple hierarchical sources, making it robust and widely deployable for millisecond-scale time or backup reference. Use PTP, with suitable hardware and network support, where tighter synchronisation is required. Explain the accuracy target, redundancy, and failure mode.2021/22
What should an ntpq comparison discuss?Discuss the selected peer (*), reachability, redundancy, stratum, delay, offset, and jitter. reach is an octal history of successful polls. Choose using the whole picture, not one column.2021/22

1.3 PTP And Clock Selection

FrontBackEvidence since 2021/22
What is a sound PTP architecture answer?Identify the grandmaster, ordinary clocks, any boundary or transparent clocks, and the timing domain. The BMCA elects the best master and supports failover; separate domains isolate different timing uses on the same network.2021/22
How do two-step PTP messages yield delay and offset?Master sends Sync at t1; slave receives at t2; Follow_Up supplies exact t1. Slave sends Delay_Req at t3; master receives at t4. Assuming symmetric delay, d = ((t2 − t1) + (t4 − t3)) / 2 and slave offset = (t2 − t1) − d.2022/23–2025/26
Why do hardware timestamps, boundary clocks, and transparent clocks improve PTP?Hardware timestamps close to the NIC reduce variable software delay. A boundary clock synchronises upstream and serves downstream. A transparent switch adds its residence time to the correction field; it is not a grandmaster.2021/22–2025/26
P2P versus E2E delay measurement in PTP?E2E uses Delay_Req and Delay_Resp to estimate the complete master–slave path. P2P uses Pdelay messages to measure each adjacent link, with suitable switch support and asymmetry treatment.2021/22, 2024/25–2025/26

1.4 Navigation And Deterministic Networks

FrontBackEvidence since 2021/22
How do lunar GNSS and hyperbolic radio navigation find position?Both turn signal travel time into distance or range difference. GNSS uses multilateration from several timed satellite signals; hyperbolic radio navigation uses time-difference-of-arrival from a master and slaves. Discuss clock synchronisation, geometry, and whether a local differential reference is available.2021/22–2025/26
Perfect network versus deterministic network?A perfect network is an idealisation with flawless delivery. A deterministic network provides stated, bounded behaviour such as delay and jitter. Ordinary Ethernet needs controlled traffic to offer useful bounds; contention and radio conditions make Wi-Fi much less predictable.2022/23

2. Scheduling, Cyclic Executives And WCET

FrontBackEvidence since 2021/22
What do C, T, and D represent for a periodic task?C is execution time, using WCET for a proof; T is the period or minimum inter-arrival time; D is the relative deadline. State when an assumption such as D = T is used.2021/22–2025/26
What are utilisation and the hyperperiod?U = Σ(Ci/Ti). The hyperperiod is LCM(T1, T2, …), after which periodic releases repeat. Both are starting points, not a substitute for the requested analysis.2021/22–2025/26
What is a cyclic executive?A static, table-driven schedule of task calls in fixed frames. It is highly predictable, but less flexible when releases, execution times, or asynchronous events change.2021/22–2025/26
How should cyclic-executive code detect and count overruns?Record a frame or cycle start time, run the planned tasks, compare elapsed time with the frame budget, then increment an overrun counter and perform the specified recovery or reporting action when late. Keep the timing check explicit.2021/22–2025/26
How does Rate Monotonic assign priority?RM gives the shortest-period task the highest fixed priority. It is analysed for periodic, independent, pre-emptible tasks under stated deadline, overhead, and blocking assumptions.2022/23–2025/26
How do you perform the RM response-time analysis for W4?Start with W4(0) = C4. Iterate W4(k+1) = C4 + Σj∈hp(4) ⌈W4(k) / Tj⌉Cj until it stabilises or exceeds D4. Show every checkpoint.2024/25–2025/26
What does the RM utilisation bound prove?For n periodic tasks with D = T, U ≤ n(21/n − 1) is sufficient for RM schedulability. Failing the bound is inconclusive; then use response-time analysis or the requested schedule.2022/23–2025/26
How does EDF schedule, and when is it feasible?Earliest Deadline First gives the ready job with the earliest absolute deadline the highest dynamic priority. On one ideal pre-emptive processor with independent periodic tasks, D = T, and negligible overhead, EDF is feasible when U ≤ 1.2022/23–2023/24
How can a task set be EDF schedulable but not RM schedulable?Use unequal relative deadlines so the RM fixed-priority ordering creates a missed deadline while EDF can order jobs by their actual absolute deadlines. Validate the set with utilisation, a timeline, and the RM analysis—do not merely assert it.2022/23
What must a scheduling answer show for marks?List task data and assumptions; show the arithmetic; draw a labelled timeline over the requested interval; identify misses or the fixed point; and state the conclusion. A correct policy name alone is not an analysis.2021/22–2025/26
How do you estimate WCET from code?Bound every loop and recursion, identify feasible branches, sum the longest feasible path, and include relevant interrupt, cache, I/O, or blocking effects. Average execution time is not WCET.2021/22

3. POSIX, Mutexes And Priority Protocols

FrontBackEvidence since 2021/22
Name four RTOS or POSIX-style capabilities worth justifying.Choose four relevant capabilities: deterministic priority scheduling, high-resolution clocks and timers, IPC or signals, memory locking, synchronisation primitives, predictable I/O, and bounded interrupt handling. Tie each one to a real-time requirement.2025/26
What is the safe mutex pattern for a critical region?Initialise the mutex; lock(m); access the shared state in a short critical region; unlock(m) on every path. State what blocks, who owns the lock, and avoid holding it across slow or unbounded work.2025/26
What is priority inversion?A high-priority task waits for a lock held by a low-priority task while medium-priority work can pre-empt the lock holder, extending the high-priority task’s delay.2023/24–2024/25
How does Priority Inheritance solve priority inversion?The low-priority lock holder temporarily inherits the blocked high-priority task’s priority, so medium-priority tasks cannot extend the inversion until the lock is released. Draw holder, blocked task, interferer, lock and unlock points.2023/24–2024/25
How does the Priority Ceiling Protocol prevent deadlock?Each resource has a ceiling based on its potential users. The protocol blocks an unsafe acquisition before circular wait can form, bounding blocking and preventing deadlock. Show the resources, ceilings, attempted second acquisition, and resulting block.2021/22–2022/23
Why use memory locking in a hard real-time process?Locking the verified real-time working set into RAM prevents a page fault causing an unbounded delay on the critical path. Connect the call such as mlockall to the seven-state process model and the avoided blocked state.2024/25–2025/26
Why is locking memory too generously a problem?It removes pages from general reclamation, raises pressure on the rest of the system, and may require privilege. Lock only the measured real-time working set; memory locking bounds one delay source, not every source of lateness.2025/26
What do POSIX.4 signals and sigqueue add?Real-time signals can be queued and prioritised rather than silently coalesced. sigqueue(pid, sig, value) sends a signal with application data in sigval; explain delivery and handler safety within the stated process model.2022/23

4. Error Control, Storage And Recovery

FrontBackEvidence since 2021/22
What does minimum Hamming distance tell you?Hamming distance is the number of differing bit positions. A code with minimum distance dmin detects up to dmin − 1 errors and corrects up to ⌊(dmin − 1) / 2⌋ errors.2023/24–2025/26
Compare Hamming (7, 4) with 8-bit ASCII plus one parity bit.Hamming (7, 4) has dmin = 3: it corrects one-bit errors and detects two-bit errors. A single parity bit gives dmin = 2: it detects any odd number of bit errors but corrects none and misses even-numbered errors.2021/22, 2023/24–2025/26
RAID-0 versus RAID-1 versus RAID-5?RAID-0 stripes for performance with no redundancy. RAID-1 mirrors data, trading capacity for resilience and read performance. RAID-5 stripes data with distributed parity, tolerates one disk failure, and has parity-write overhead.2021/22–2022/23
How does backward recovery support dynamic software redundancy?Save a consistent checkpoint; on detected error or exception, restore it and retry with an alternative computation or replica. Record, compensate, or make external side effects idempotent—rollback cannot unsend an effect.2021/22–2022/23
What are FMV, GMV, FPV, and weighted averaging?They are voter rules for redundant outputs: formalised majority voter, generalised median voter, formalised plurality voter, and weighted averaging. State the rule first, then apply it to the supplied outputs.2021/22

5. Logical Clocks And Causality

FrontBackEvidence since 2021/22
How do Lamport clocks work, and what do they miss?Increment the local counter before each local or send event; attach it to messages; on receipt set L = max(L, Lmsg) + 1. If a happened-before b, then L(a) < L(b); the reverse does not prove causality or rule out concurrency.2022/23–2024/25
How do vector clocks capture causality?Keep one counter per process; increment the local entry before local or send events; on receipt take the component-wise maximum, then increment the receiver’s entry. Va < Vb means happened-before; incomparable vectors mean concurrent events.2022/23–2024/25

6. QUIC, HTTP And Protocol Analysis

FrontBackEvidence since 2021/22
Why was HTTP/2 developed, and what are its key features?It addresses HTTP/1 inefficiencies such as many connections and poor request use. Key features include binary framing, stream multiplexing, header compression, and prioritisation; its streams still run over TCP.2024/25
What is TCP transport-level head-of-line blocking?TCP delivers one ordered byte stream. A lost earlier segment prevents delivery of later bytes, even when those bytes belong to an unrelated HTTP/2 application stream.2023/24–2025/26
How does QUIC avoid transport-level head-of-line blocking?QUIC has independently ordered streams, so loss in one stream need not delay delivery in another. Congestion control and a shared path can still slow the whole connection.2023/24–2025/26
How does QUIC connection establishment differ from TCP plus TLS?QUIC runs over UDP and integrates TLS into its transport handshake, allowing fewer setup round trips in favourable cases. It does not remove RTT, packet loss, or server-processing delay.2023/24–2024/25
What does congestion control do in QUIC?It infers congestion from signals such as loss and RTT, adjusts sending behaviour, and seeks to avoid persistent queues while balancing throughput and latency. In an answer, connect the action to the observed symptom.2023/24–2025/26
Throughput fairness versus latency fairness?Throughput fairness shares capacity comparably. Latency fairness prevents one flow imposing excessive queueing delay on another. The trade-off is harder to reason about when TCP and QUIC share a bottleneck.2025/26
Why encrypt QUIC transport metadata?Encryption protects users and reduces unwanted middlebox ossification. The trade-off is less passive network visibility, so operators need endpoint telemetry such as qLog or authorised inspection.2025/26
What do Wireshark, qLog, and qViz each contribute?Wireshark shows packet-level traffic but encrypted QUIC limits interpretation. qLog records endpoint transport events; qViz visualises those timelines to diagnose streams, loss, and congestion.2023/24–2025/26
What can a resource waterfall reveal?It separates connection, request waiting or first byte, and transfer stages. Use it to distinguish server or queueing delay from slow download, then corroborate the diagnosis with other evidence.2023/24
What is QUIC connection migration?After path validation, a connection can continue when a client changes networks, for example Wi-Fi → 5G. It reduces disruption from address changes but does not guarantee that no freeze occurs.2025/26
How does QUIC loss recovery help a real-time application?Packet numbers, acknowledgements, and timers identify loss; required stream data is retransmitted in a new packet. Independent streams avoid transport head-of-line blocking, while congestion control limits sending under loss.2025/26

7. Soft Real-Time, QoS And Cloud Gaming

FrontBackEvidence since 2021/22
Why is latency critical in a soft real-time system?Late output can still be correct but less useful: it can cause missed interaction, stutter, or degraded control quality. Trace where latency enters the system and explain the user-visible effect rather than treating it as an abstract number.2023/24–2024/25
Intrinsic QoS versus perceived QoS or QoE?Intrinsic QoS is measured delivery quality such as delay, jitter, loss, and bitrate. Perceived QoS or QoE is the user’s experienced responsiveness, smoothness, and quality. Good metrics help explain, but do not automatically guarantee, good experience.2024/25
What does a jitter buffer do, and how do fixed and adaptive strategies differ?It delays playout to smooth packet-delay variation. A fixed buffer is simple but cannot adapt; an adaptive buffer changes depth as conditions change. Larger buffers reduce underflows but add interaction latency.2024/25
What is the end-to-end response-delay budget in cloud gaming?Trace user input, game processing, encoding, queueing, network transmission, loss recovery, decoding, buffering, and playout to the visible response. More bandwidth alone may not fix lag if processing, RTT, jitter, loss, or buffering dominates.2024/25–2025/26
How does adaptive-bitrate streaming work, and why is it insufficient by itself for interactive use?The client estimates available conditions and selects segment representations to balance continuity, quality, rebuffering risk, and latency. It cannot remove input, processing, RTT, or playout delay, so it is only one control in an interactive system.2025/26
What do LCP, FID, and CLS measure?LCP measures perceived loading of the largest content; FID measures input responsiveness delay; CLS measures unexpected visual movement during loading.2023/24
How is Cumulative Layout Shift calculated?For each unexpected shift, CLS contribution = impact fraction × distance fraction; sum the contributions. The impact fraction is the viewport fraction covered by unstable before-and-after areas, and the distance fraction is the largest movement relative to the viewport.2023/24
